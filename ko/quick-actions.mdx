## 드래그 앤 드롭

### 다섯 가지 드래그 앤 드롭 방식

Zditor는 여러 가지 드래그 앤 드롭 방식을 지원합니다.

#### 1. 파일 트리 안에서 드래그

왼쪽 파일 트리의 파일과 폴더를 트리 안에서 드래그해 작업 공간 내 위치를 바꿀 수 있습니다.

다음과 같은 경우에 유용합니다.

- 폴더 재정리
- 다른 디렉터리로 파일 이동
- 작업 공간 구조 정리

#### 2. 파일 트리에서 Markdown 문서로 드래그

왼쪽 파일 트리의 파일을 Markdown 문서로 바로 드래그할 수 있습니다.

놓은 파일은 작업 공간의 원래 위치에 있는 파일을 가리키는 **첨부 파일 노드**로 삽입됩니다. Zditor는 사본을 만들지 않습니다.

파일을 이미지, 동영상, 오디오 플레이어 또는 캔버스로 표시하려면 다음과 같이 하세요.

1. 첨부 파일을 클릭하고 **More** 메뉴를 열어 **Convert to Link**를 선택합니다.
2. 새로 생긴 링크를 클릭하고 링크 도구 모음에서 알맞은 버튼을 누릅니다. **Convert to image**, **Convert to video**, **Convert to audio**, **Convert to canvas** 중 파일 형식에 맞는 버튼만 표시됩니다.

캔버스 파일(`.excalidraw`)이라면 첨부 파일의 **More** 메뉴에서 바로 **Convert to Canvas**를 선택할 수도 있습니다.

먼저 삽입해 두고 최종 표시 방식은 나중에 정하고 싶을 때 유용합니다.

#### 3. 외부 파일을 Markdown 문서로 드래그

시스템 파일 관리자에서 파일을 Markdown 문서로 바로 드래그할 수 있습니다.

Zditor는 파일 형식에 따라 다음과 같이 삽입합니다.

- 이미지 파일 -> 이미지 노드
- 동영상 파일 -> 동영상 노드
- 오디오 파일 -> 오디오 노드
- 캔버스 파일(`.excalidraw`) -> 캔버스 노드
- 기타 파일 -> 첨부 파일 노드

Zditor는 놓은 파일마다 사본을 만들어 **Settings → Integrations → Image hosting & uploads**에 설정된 위치에 저장합니다. 로컬 자료를 노트나 문서로 가져오는 가장 빠른 방법입니다.

#### 4. Markdown 문서 간 노드 드래그

서로 다른 Markdown 문서 사이, 예를 들어 좌우 분할 창 사이에서 노드를 드래그할 수 있습니다.

문서 간에는 기본 동작이 **복사**입니다. 대상 문서에 사본이 들어가고 원본은 원래 문서에 그대로 남습니다.

다음과 같은 경우에 유용합니다.

- 초안 내용을 정식 문서로 이동
- 분할 창 간 블록 재사용
- 여러 노트에 걸친 내용 재구성

#### 5. 같은 문서 안에서 드래그

한 문서 안에서는 잘라내기와 붙여넣기 없이 블록 단위 콘텐츠를 새 위치로 드래그할 수 있습니다.

같은 문서 안에서는 기본 동작이 **이동**입니다.

다음과 같은 경우에 유용합니다.

- 문단 순서 변경
- 섹션 구조 재편
- 텍스트, 이미지, 코드 블록을 더 알맞은 위치로 이동

### 편집기의 드래그 핸들

편집 중에 블록 위로 마우스를 올리면 왼쪽 여백에 드래그 핸들이 나타납니다. 핸들에는 손잡이 옆에 블록 유형(제목은 `H1`부터 `H6`까지)이 표시됩니다. 핸들을 드래그하면 블록 전체가 이동합니다.

다음을 포함한 모든 최상위 블록에 이 핸들이 있습니다.

- 문단
- 제목
- 목록
- 인용문
- 이미지
- 동영상
- 코드 블록
- 첨부 파일
- 콜아웃
- 표
- 블록 수식

목록은 통째로 이동합니다. 목록 항목 하나만 옮기려면 `Alt-ArrowUp`과 `Alt-ArrowDown`을 사용하세요.

<Warning>
  **드래그 앤 드롭 피드백**

  다음과 같이 제대로 드래그되지 않는 노드 유형을 발견했다면:

  - 드래그할 수 없음
  - 엉뚱한 위치에 놓임
  - 놓은 뒤 내용이 비정상적으로 바뀜

  버그 신고를 보내 주세요. 부족한 부분을 계속 고쳐 나가겠습니다.
</Warning>

### 드래그 핸들이 나타나는 위치

드래그는 두 곳에서 시작할 수 있습니다.

- **왼쪽 여백**: 마우스를 올리면 나타나는 핸들로, 모든 최상위 블록에 있습니다
- **도구 모음**: 선택한 이미지, 동영상, 오디오 파일, 첨부 파일, 캔버스, 임베드, 코드 블록, 표, HTML 블록 또는 수식의 도구 모음에 있는 **Drag** 버튼

<Tip>
  드래그 앤 드롭의 핵심 가치는 구조 편집입니다. 긴 노트, 초안, 개요를 재구성할 때 잘라내기와 붙여넣기보다 훨씬 빠릅니다.
</Tip>

## 키보드 단축키

키보드 단축키는 Zditor에서 편집 속도를 높이는 가장 빠른 방법 중 하나입니다.

주로 다음과 같은 경우에 씁니다.

- 문서 저장
- 내용 검색
- 제목 수준 설정
- 굵게, 기울임꼴, 하이라이트, 인라인 코드 적용과 해제
- 목록, 인용문, 표, 코드 블록, 수식 만들기

### 꼭 알아 둘 단축키

| 단축키 | 동작 |
| --- | --- |
| `Mod-K` | 검색 열기 |
| `Mod-S` | 현재 문서 저장 |
| `Mod-F` | 현재 문서에서 검색 |
| `Mod-/` | 서식 보기와 소스 보기 전환 |
| `Mod-B` | 굵게 적용/해제 |
| `Mod-I` | 기울임꼴 적용/해제 |
| `Mod-H` | 하이라이트 적용/해제 |
| `Mod-Shift-C` | 인라인 코드 적용/해제 |
| `Mod-1`부터 `Mod-6`까지 | 제목 수준 설정 |
| `Mod-Shift-8` | 글머리 기호 목록 적용/해제 |
| `Mod-Shift-7` | 번호 매기기 목록 적용/해제 |
| `Mod-Shift-9` | 체크박스 목록 적용/해제 |
| `Mod-Shift-\` | 코드 블록 적용/해제 |
| `Mod-T` | 표 만들기 |

<Warning>
  `Mod`는 다음 키를 뜻합니다.
  <ul>
    <li><strong>macOS</strong>: `Command`</li>
    <li><strong>Windows / Linux</strong>: `Ctrl`</li>
  </ul>
</Warning>

### 단축키가 특히 유용한 경우

단축키는 다음과 같은 경우에 특히 유용합니다.

- 원하는 서식이나 구조가 이미 정해져 있을 때
- 마우스로 손을 옮겨 흐름을 끊고 싶지 않을 때
- 같은 작업을 여러 번 반복할 때

전체 목록과 **Settings → Personal → Keyboard shortcuts**에서 키 바인딩을 바꾸는 방법은 [키보드 단축키](/ko/keyboard-shortcuts)를 참고하세요.

## 트리거 메뉴

트리거 메뉴는 키보드로 구조화된 작업을 여는 가장 빠른 방법입니다.

### `/` 명령 메뉴

Markdown 문서에서 줄 첫머리나 공백 뒤에 `/`를 입력하면 명령 메뉴가 열립니다. 계속 입력하면 항목이 걸러지며, 필터는 모든 그룹 안을 검색합니다. 화살표 키와 `Enter`로 항목을 선택하세요.

메뉴 구성은 다음과 같습니다.

- **Heading 1**부터 **Heading 3**까지, 그리고 **Heading 4-6**
- **List**: 체크리스트, 글머리 기호 목록, 번호 매기기 목록
- **Media**: 이미지, 동영상, 오디오, 캔버스, 파일 첨부. 모두 파일 선택기로 고릅니다
- **MetaInfo**: 문서 맨 위의 Frontmatter 블록
- **Code Block**: 표, HTML, 인용문, 코드 블록, 블록 수식, 구분선, 페이지 나누기, Mermaid 다이어그램
- **Info**: 정보, 메모, 경고, 팁, 오류 콜아웃
- **Templates**: Frontmatter에 `template: true`가 있는 문서가 있을 때 표시됩니다. 하나를 선택하면 현재 문서의 내용이 해당 템플릿으로 바뀝니다.

이 메뉴를 쓰면 다음과 같은 점이 좋습니다.

- 반복 입력 줄이기
- 사용할 수 있는 명령 빠르게 찾기
- 더 구조화된 작업 흐름 사용하기

에이전트의 메시지 입력란에서는 `/`를 입력하면 대화 명령인 `/share`, `/export`, `/goal`, `/compact`, `/side`가 대신 나열됩니다. 이곳에서 `@`는 작업 공간 파일을 멘션하고 `$`는 스킬을 선택합니다. [에이전트 가이드](/ko/agent-guide)를 참고하세요.

### 편집기의 다른 트리거 메뉴

편집기에는 `/` 말고도 자주 쓰는 트리거 메뉴가 몇 가지 더 있습니다.

- `@`: 작업 공간의 Markdown 또는 PDF 파일에 링크합니다. 하이라이트가 있는 PDF라면 하이라이트를 골라 PDF 카드로 삽입할 수도 있습니다.
- `#`: SuperTag 항목을 삽입하거나 만듭니다
- `:`: 이모지 선택기를 엽니다. 계속 입력하면 이름으로 이모지를 걸러 냅니다

각 메뉴는 **Settings → Editor → Markdown Editor**의 **Command menu (/)**, **Link menu (@)**, **Object menu (#)**, **Emoji menu (:)**에서 끌 수 있습니다.

<Tip>
  편집기에서 같은 작업을 자주 반복한다면, 매번 같은 문법을 다시 입력하는 것보다 트리거 메뉴가 대개 더 빠르고 안정적입니다.
</Tip>

## 도구 모음

Zditor는 고정된 서식 도구 모음 하나에 의존하지 않습니다. 대신 선택한 대상에 따라 상황에 맞는 도구 모음을 보여 줍니다.

### 선택 도구 모음

텍스트나 노드를 선택하면 편집기가 그에 맞는 도구 모음을 표시합니다. 예를 들면 다음과 같습니다.

- 텍스트 서식 도구 모음
- 링크 도구 모음
- 이미지, 동영상, 오디오 도구 모음
- 첨부 파일 도구 모음
- 캔버스 도구 모음
- 임베드 도구 모음
- 코드 블록 및 HTML 블록 도구 모음
- 수식 도구 모음
- 표 도구 모음
- 콜아웃 도구 모음
- 각주 도구 모음
- 팁 및 수정 표시 도구 모음
- SuperTag 도구 모음
- PDF 카드 도구 모음

따라서 모든 문법을 미리 외워 둘 필요가 없는 경우가 많습니다. 흔히 쓰는 방식은 다음과 같습니다.

1. 먼저 내용을 선택합니다
2. 도구 모음으로 작업을 적용하거나 조정합니다

이 도구 모음을 숨기려면 **Settings → Editor → Markdown Editor**에서 **Selection toolbar**를 끄세요.

### 도구 모음의 동작

<AccordionGroup>
  <Accordion title="선택한 개체에 따라 변경" icon="arrows-rotate" defaultOpen>
    개체마다 다른 도구 모음이 표시됩니다. 텍스트에는 서식 도구가, 이미지에는 이미지 도구가, PDF 카드에는 PDF 카드 전용 도구 모음이 나타납니다.
  </Accordion>

  <Accordion title="보조 플로팅 패널 열기" icon="layer-group">

  </Accordion>

  <Accordion title="제자리 편집 지원" icon="pen-to-square">
    도구 모음이 선택한 내용 가까이에 나타나므로 편집 중인 위치에서 시선을 떼지 않아도 됩니다.
  </Accordion>

  <Accordion title="선택 내용을 에이전트에 전달" icon="sparkles">
    많은 도구 모음에 **ASK AI** 버튼이 있습니다. 이 버튼을 누르면 선택한 내용이 첨부된 상태로 문서 옆에 에이전트가 열립니다. **Settings → AI → AI Toolbar Prompts**에서 추가한 프롬프트는 도구 모음에 추가 버튼으로 표시됩니다.
  </Accordion>
</AccordionGroup>

### 도구 모음이 특히 유용한 경우

도구 모음은 대개 다음과 같은 경우에 더 편리합니다.

- 편집할 내용은 알지만 문법을 기억하고 싶지 않을 때
- 결정하기 전에 가능한 작업을 먼저 보고 싶을 때
- 이미지, 첨부 파일, PDF 카드, SuperTag 같은 시각적 노드를 다룰 때

## 추천 학습 순서

Zditor를 막 시작했다면 다음 순서로 익히는 것이 실용적입니다.

1. 구조 편집을 위한 드래그 앤 드롭 익히기
2. 꼭 알아 둘 키보드 단축키 몇 가지 외우기
3. `/`, `@`, `#`, `:` 트리거 메뉴 사용하기
4. 실제로 글을 쓰면서 개체별 도구 모음에 익숙해지기
