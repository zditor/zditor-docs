## 拖拽

### 五种拖拽方式

Zditor 支持多种拖拽方式。

#### 1. 文件树内部拖拽

左侧文件树中的文件和文件夹都可以在文件树内部拖拽，以调整它们在工作区中的位置。

这类拖拽适合：

- 调整文件夹层级
- 把文件移动到其他目录
- 整理工作区结构

#### 2. 从左侧文件树拖到 Markdown 文档

左侧文件树中的文件可以直接拖拽到 Markdown 文档中。

拖入的文件会以**附件节点**的形式插入，链接到它在工作区中的原有位置。Zditor 不会复制这个文件。

如果想把它显示为图片、视频、音频播放器或画布：

1. 点击附件，打开它的 **更多** 菜单，选择 **转为链接**。
2. 点击新生成的链接，在链接工具栏中使用对应的按钮：**转换为图片**、**转换为视频**、**转换为音频** 或 **转换为画布**。工具栏只显示适合该文件类型的按钮。

如果是画布文件（`.excalidraw`），附件的 **更多** 菜单还直接提供 **转为画布**。

这个流程适合“先插入，再决定展示方式”。

#### 3. 从系统外部拖拽文件到 Markdown 文档

你也可以把系统文件管理器里的文件直接拖进 Markdown 文档。

Zditor 会根据文件类型决定插入的节点：

- 图片文件 -> 图片节点
- 视频文件 -> 视频节点
- 音频文件 -> 音频节点
- 画布文件（`.excalidraw`）-> 画布节点
- 其他文件 -> 附件节点

Zditor 会把每个拖入的文件复制一份，保存到 **设置 → 集成 → 图床与上传** 中设定的位置。这是把本地素材放进笔记或文档最快的方式。

#### 4. 在不同 Markdown 文档之间拖拽节点

不同 Markdown 文档之间也支持节点拖拽，例如在左右分屏之间拖动。

跨文档拖拽的默认行为是**复制**：目标文档得到一份副本，原节点仍留在源文档中。

这类跨文档拖拽适合：

- 把草稿内容整理到正式文档
- 在左右分屏之间复用内容块
- 重组多篇笔记中的内容

#### 5. 文档内部位置拖拽

在同一篇文档内，块级内容可以直接拖到新位置，不需要先剪切再粘贴。

同一文档内部拖拽的默认行为是**移动**。

这类拖拽适合：

- 调整段落顺序
- 重新编排章节结构
- 把文字、图片或代码块移到更合适的位置

### 编辑器中的拖拽手柄

编辑时，把鼠标悬停在某个内容块上，Zditor 会在左侧页边显示拖拽手柄。手柄上的抓手旁会标出块的类型（标题显示为 `H1` 到 `H6`）。拖动手柄会移动整个内容块。

每个顶层内容块都有这个手柄，包括：

- 段落
- 标题
- 列表
- 引用块
- 图片
- 视频
- 代码块
- 附件
- 提示块
- 表格
- 块级公式

列表会整体移动。要单独移动某个列表项，请使用 `Alt-ArrowUp` 和 `Alt-ArrowDown`。

<Warning>
  **拖拽异常反馈**

  如果你发现某一种节点拖拽时存在问题，例如：

  - 不能拖拽
  - 拖拽位置不对
  - 拖拽后内容异常

  可以直接提交 bug 反馈，我们会继续补齐和修复。
</Warning>

### 从哪里开始拖拽

有两个地方可以开始拖拽：

- **左侧页边**：悬停时出现的手柄，适用于所有顶层内容块
- **工具栏**：选中图片、视频、音频、附件、画布、嵌入内容、代码块、表格、HTML 块或公式后，工具栏中的 **拖拽** 按钮

<Tip>
  拖拽的核心价值在于调整内容结构。整理长篇笔记、草稿或大纲时，它比剪切粘贴快得多。
</Tip>

## 快捷键

快捷键是 Zditor 里最直接的提效方式之一。

常见场景包括：

- 保存文档
- 搜索内容
- 设置标题级别
- 切换粗体、斜体、高亮、行内代码
- 创建列表、引用块、表格、代码块、数学公式

### 最常用的一批快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Mod-K` | 打开搜索 |
| `Mod-S` | 保存当前文档 |
| `Mod-F` | 在当前文档中查找 |
| `Mod-/` | 在富文本视图和源码视图之间切换 |
| `Mod-B` | 切换粗体 |
| `Mod-I` | 切换斜体 |
| `Mod-H` | 切换高亮 |
| `Mod-Shift-C` | 切换行内代码 |
| `Mod-1` ~ `Mod-6` | 设置标题级别 |
| `Mod-Shift-8` | 切换无序列表 |
| `Mod-Shift-7` | 切换有序列表 |
| `Mod-Shift-9` | 切换复选框列表 |
| `Mod-Shift-\` | 切换代码块 |
| `Mod-T` | 创建表格 |

<Warning>
  `Mod` 在不同系统上含义不同：
  <ul>
    <li><strong>macOS</strong>：`Command`</li>
    <li><strong>Windows / Linux</strong>：`Ctrl`</li>
  </ul>
</Warning>

### 什么时候优先用快捷键

快捷键尤其适合下面这些场景：

- 你已经知道自己要用什么格式或结构
- 你不想因为伸手去拿鼠标而打断思路
- 你要多次重复同一个操作

完整列表以及如何在 **设置 → 个人 → 键盘快捷键** 中修改按键，请查看 [快捷键指南](/zh/keyboard-shortcuts)。

## 触发菜单

触发菜单是用键盘调出结构化操作最快的方式。

### `/` 命令菜单

在 Markdown 文档中，在行首或空格后输入 `/` 即可打开命令菜单。继续输入可以过滤菜单，过滤会搜索所有分组中的项目。用方向键和 `Enter` 选择。

菜单包含：

- **一级标题** 到 **三级标题**，以及 **标题 4-6**
- **列表**：待办列表、无序列表和有序列表
- **媒体**：图片、视频、音频、画布和附件，选中后都通过文件选择器挑选文件
- **元信息**：文档顶部的 Frontmatter 块
- **代码块**：表格、HTML、引用、代码块、块级公式、分隔线、分页符和 Mermaid 图表
- **信息**：信息、笔记、警告、提示和错误五种提示块
- **Templates**：当你有 Frontmatter 中写了 `template: true` 的文档时才会出现。选择一个模板会用它替换当前文档的内容。

命令菜单可以帮助你：

- 减少重复输入
- 快速发现可用的命令
- 用更结构化的方式工作

在智能体的输入框中，`/` 列出的则是对话命令：`/share`、`/export`、`/goal`、`/compact` 和 `/side`。在那里，`@` 用来提及工作区中的文件，`$` 用来选择技能。详见 [Agent 智能体使用指南](/zh/agent-guide)。

### 编辑器里的其他触发菜单

除了 `/` 之外，编辑器中还有几个常用的触发菜单：

- `@`：链接到工作区中的 Markdown 或 PDF 文件。如果 PDF 中有高亮，还可以选择其中一条高亮，把它插入为 PDF 卡片。
- `#`：插入或创建 SuperTag 条目
- `:`：打开表情选择器，继续输入可以按名称过滤表情

每个菜单都可以在 **设置 → 编辑器 → Markdown 编辑器** 中关闭，对应 **命令菜单（/）**、**链接菜单（@）**、**对象菜单（#）** 和 **表情菜单（:）**。

<Tip>
  如果你经常重复同一类编辑操作，触发菜单通常比每次重新输入相同的语法更快、更稳定。
</Tip>

## 工具栏

Zditor 的工具栏不是单一固定的一条，而是根据你选中的内容显示对应的上下文工具栏。

### 选区工具栏

在编辑器里选中文字或节点后，会弹出与之匹配的工具栏，例如：

- 文本格式工具栏
- 链接工具栏
- 图片、视频和音频工具栏
- 附件工具栏
- 画布工具栏
- 嵌入内容工具栏
- 代码块和 HTML 块工具栏
- 公式工具栏
- 表格工具栏
- 提示块工具栏
- 脚注工具栏
- 注释与修订工具栏
- SuperTag 工具栏
- PDF 卡片工具栏

这意味着你通常不需要先记住所有语法。常见的做法是：

1. 先选中内容
2. 再用工具栏执行或调整操作

如果想隐藏这些工具栏，请在 **设置 → 编辑器 → Markdown 编辑器** 中关闭 **选区工具栏**。

### 工具栏的特点

<AccordionGroup>
  <Accordion title="按对象变化" icon="arrows-rotate" defaultOpen>
    不同对象会出现不同工具栏。选中文本看到的是格式工具栏，选中图片看到的是图片工具栏，选中 PDF 卡片则会弹出 PDF 卡片专用的工具栏。
  </Accordion>

  <Accordion title="支持二级浮层" icon="layer-group">
    某些工具栏按钮会打开第二层浮动面板，用来选择更具体的选项或目标。
  </Accordion>

  <Accordion title="就地编辑" icon="pen-to-square">
    工具栏出现在选中内容附近，视线不用离开正在编辑的地方。
  </Accordion>

  <Accordion title="把选中内容交给智能体" icon="sparkles">
    许多工具栏都有 **询问 AI** 按钮，它会在文档旁打开智能体，并附上你选中的内容。你在 **设置 → AI → AI 工具栏提示词** 中添加的提示词会作为额外按钮出现在工具栏中。
  </Accordion>
</AccordionGroup>

### 什么时候优先用工具栏

工具栏更适合下面这些情况：

- 你知道要改哪块内容，但不想记语法
- 你想先看到可选动作，再决定怎么处理
- 你处理的是图片、附件、PDF 卡片、SuperTag 这类可视化节点

## 推荐的上手顺序

如果你刚开始使用 Zditor，推荐按下面的顺序熟悉：

1. 先学会用拖拽调整内容结构
2. 再记住最常用的一批快捷键
3. 接着开始使用 `/`、`@`、`#`、`:` 这些触发菜单
4. 最后在实际写作中熟悉不同对象的工具栏
