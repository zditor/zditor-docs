## 주석 데이터 저장 방식

PDF 주석은 PDF 파일에 기록되지 않습니다. Zditor는 주석을 같은 폴더에 PDF 이름을 딴 별도의 JSON 파일로 저장합니다.

```text
example.pdf.zditor-pdf-annotation.json
```

Zditor는 PDF에 처음 주석을 달 때 이 파일을 만들고, 이후 모든 변경 사항을 자동으로 저장합니다. 저장되는 내용은 다음과 같습니다.

- 레이어: 이름과 표시 여부
- 획: 페이지, 레이어, 점, 색상, 굵기, 획 설정
- 영역 하이라이트: 페이지, 레이어, 영역, 색상, 제목, 메모, 썸네일 참조
- 에이전트가 인용문으로 만든 하이라이트: 인용한 텍스트

<Tip>
  PDF 자체는 수정되지 않으므로 주석을 쉽게 동기화하고, 백업하고, 버전 관리할 수 있습니다.
</Tip>

## 화면 구성

데스크톱 앱에서 PDF 뷰어는 네 영역으로 구성됩니다.

### 제목 표시줄

PDF 위의 제목 표시줄에는 다음이 있습니다.

- 왼쪽: **Undo**와 **Redo**
- 오른쪽: **Print**, **Search**, **Bookmarks**, **Layers**, **Clear Page**

탭이 좁으면 **Bookmarks**, **Layers**, **Clear Page**가 **More** 메뉴 안으로 들어갑니다. 검색하는 동안에는 검색 입력란이 이 버튼들을 대신합니다.

### 주석 도구 모음

페이지 위쪽에 둥근 도구 모음이 떠 있습니다. 왼쪽부터 순서대로 다음이 있습니다.

- **Keep tool active**(도구 유지)
- 주석 도구
- 여섯 가지 색상
- **Width**(굵기) 슬라이더
- **Stroke Parameters**(획 설정)

탭이 너무 좁아 모두 들어가지 않으면 굵기 슬라이더가, 그다음에는 색상이 획 설정 버튼 안으로 들어갑니다. 이때 이 버튼은 현재 색상을 보여 주며 이름이 **Brush settings**로 바뀝니다. 그래도 공간이 부족하면 **Laser**, **Line**처럼 덜 자주 쓰는 도구부터 **More** 메뉴로 들어갑니다. 메뉴에는 도구마다 단축키 문자가 표시됩니다.

### 확대/축소 및 페이지 컨트롤

왼쪽 아래 모서리에는 **Zoom Out**, 확대 비율, **Zoom In**, 현재 페이지 번호가 있습니다.

### 왼쪽 사이드바

**Bookmarks**, **Layers**, **Search**를 누르면 페이지 왼쪽에 사이드바가 열립니다. 사이드바에는 다음 중 하나가 표시됩니다.

- PDF의 책갈피
- 레이어와 영역 하이라이트 목록
- 검색 결과

**Bookmarks**나 **Layers**를 다시 클릭하면 사이드바가 닫힙니다.

## 주석 도구

주석 도구 모음에서 도구를 고르거나 해당 문자 키를 누르세요.

### 선택

단축키: `V`. 선택 도구는 그리는 대신 주석을 선택하고 옮깁니다. PDF를 열면 이 도구가 활성화되어 있습니다.

선택 도구로 할 수 있는 일은 다음과 같습니다.

- 획을 클릭해 선택하고, `Shift`-클릭으로 획을 선택에 추가하거나 선택에서 뺍니다
- 선택한 획이나 선택 영역 안의 아무 곳이나 드래그해 옮깁니다
- 영역 하이라이트를 클릭해 카드를 표시하고, 드래그해 옮기거나, 모서리 핸들을 드래그해 크기를 조절합니다

빈 공간을 클릭하면 선택이 해제됩니다.

### 펜

단축키: `P`. 펜은 손글씨 메모, 동그라미, 화살표, 임의의 경로 등을 자유롭게 그리는 도구입니다. 여섯 가지 색상 중 하나를 고르고 **Width**를 설정하세요.

**Stroke Parameters**로 각 획의 모양을 조정합니다.

- **Pressure sensitivity**: 펜 압력에 따라 굵기가 달라집니다. 마우스에서는 효과가 없습니다.
- **Smoothing**: 각 획의 윤곽을 부드럽게 다듬습니다
- **Stabilization**: 선이 펜을 살짝 늦게 따라오게 해, 빠르게 그은 획도 더 안정적으로 그려집니다
- **Taper Start**와 **Taper End**: 획의 시작이나 끝을 점점 가늘게 만듭니다
- **Cap Start**와 **Cap End**: 가늘어지지 않는 획의 시작이나 끝을 둥글게 만듭니다
- **Reset**: 획 설정을 기본값으로 되돌립니다

<Tip>
  굵기와 획 설정은 새 획에 적용되며, 기존 획은 그릴 때의 설정을 유지합니다. Zditor는 선택한 값을 그리기 기본값으로 기억하며, 이 기본값은 **Settings → Editor → PDF Editor**에서도 설정할 수 있습니다.
</Tip>

### 형광펜

단축키: `M`. 형광펜도 자유롭게 그리는 도구지만 펜과는 다르게 동작합니다.

- 반투명해서 아래의 텍스트가 그대로 읽힙니다
- 형광 마커처럼 페이지와 섞여 보입니다
- 펜 압력에 따라 굵기가 바뀌지 않습니다

### 지우개

단축키: `E`. 지우려는 획 위로 지우개를 드래그하세요.

- 지나간 경로에 닿은 획을 직선과 사각형까지 포함해 통째로 지웁니다
- 크기는 **Width** 설정을 따릅니다
- 드래그하는 동안 획이 사라지고, 손을 떼면 변경 사항이 저장됩니다
- 보이는 모든 레이어의 획에 작동합니다

<Warning>
  지우개로는 영역 하이라이트를 지울 수 없습니다. 영역 하이라이트는 카드, 편집기, 또는 Layers 사이드바의 Annotations 목록에서 삭제하세요.
</Warning>

### 직선과 사각형

더 정돈된 표시가 필요하면 다음 도구를 사용하세요.

- **Line**(`L`): 누른 지점에서 놓은 지점까지 직선을 그립니다
- **Rectangle**(`R`): 두 모서리 사이에 상자 윤곽선을 그립니다

하나를 그리면 Zditor가 새 도형이 선택된 상태로 **Select**로 돌아가므로 바로 옮길 수 있습니다. 여러 개를 연달아 그리려면 **Keep tool active**를 켜세요.

### 올가미

단축키: `S`. 획 주위에 고리를 그려 선택합니다. 고리 안에 점이 하나라도 있는 획은 모두 선택됩니다. 그런 다음 [선택과 일괄 작업](#선택과-일괄-작업)에서 설명하는 대로 선택 도구 모음을 쓰거나 선택 영역을 드래그할 수 있습니다.

<Tip>
  올가미는 획만 선택합니다. 영역 하이라이트나 PDF의 텍스트는 선택하지 않습니다.
</Tip>

### 레이저

단축키: `K`. 레이저는 발표, 강의, 화면 공유에 쓰는 임시 포인터입니다.

- 현재 색상의 점이 커서를 대신하며, 1초 안에 사라지는 자취를 남깁니다
- 주석 데이터에는 아무것도 저장되지 않습니다
- 다른 도구로 바꾸면 자취가 바로 지워집니다

### 이동

단축키: `H`. 주석을 다는 대신 드래그해 페이지를 어느 방향으로든 스크롤합니다. 확대한 뒤에 특히 유용합니다.

### 도구 유지

단축키: `Q`. 직선, 사각형, 영역 하이라이트를 그리고 나면 Zditor는 보통 **Select**로 돌아갑니다. **Keep tool active**를 켜면 도구가 선택된 상태로 유지됩니다. 펜, 형광펜, 지우개, 올가미, 레이저, 이동 도구는 항상 선택된 상태로 유지됩니다.

### 키보드 단축키

| 키 | 동작 |
| --- | --- |
| `V` | 선택 |
| `H` | 이동 |
| `P` | 펜 |
| `M` | 형광펜 |
| `A` | 영역 하이라이트 |
| `E` | 지우개 |
| `L` | 직선 |
| `R` | 사각형 |
| `S` | 올가미 |
| `K` | 레이저 |
| `Q` | **Keep tool active** 켜기/끄기 |
| `Cmd/Ctrl + Z` | 실행 취소 |
| `Shift + Cmd/Ctrl + Z` | 다시 실행(Windows와 Linux에서는 `Ctrl + Y`도 사용 가능) |
| `Delete` 또는 `Backspace` | 선택한 획 삭제 |
| `Cmd/Ctrl + F` | PDF 검색 |

도구 문자 키와 실행 취소, 다시 실행 키는 PDF 뷰어 안을 클릭한 뒤에 작동하며, 입력란에 입력하는 중에는 작동하지 않습니다.

## 영역 하이라이트

영역 하이라이트는 PDF 뷰어에서 가장 구조화된 주석 유형으로, 색상, 제목, 메모, 영역 썸네일을 갖춘 페이지 위의 사각형입니다.

### 영역 하이라이트 만들기

<Steps>
  <Step title="영역 하이라이트 도구로 전환">
    주석 도구 모음에서 **Area Highlight**를 고르거나 `A`를 누르세요.
  </Step>

  <Step title="PDF에 사각형 드래그">
    주석을 달 영역 위로 드래그하세요.
  </Step>

  <Step title="제목과 메모 추가">
    포인터를 놓으면 영역 옆에 작은 편집기가 열립니다. 다섯 가지 색상(기본값은 노란색) 중 하나를 고르고, 필요하면 제목과 메모를 입력하세요. 제목에서 `Enter`를 누르면 메모로 이동합니다.
  </Step>

  <Step title="확인">
    **Confirm**을 클릭하거나 `Cmd/Ctrl + Enter`를 누르면 하이라이트가 활성 레이어에 저장됩니다. **Cancel**이나 `Esc`를 누르면 하이라이트가 버려집니다.
  </Step>
</Steps>

확인하고 나면 **Keep tool active**가 켜져 있지 않은 한 Zditor가 새 하이라이트를 선택한 상태로 **Select**로 돌아갑니다. 메모가 있는 하이라이트는 오른쪽 위 모서리에 작은 점이 표시됩니다.

### 영역 하이라이트 편집

#### 선택 도구로

하이라이트를 클릭하면 제목과 메모가 담긴 카드가 표시됩니다. **Edit Annotation**(연필 아이콘)이나 카드의 텍스트를 클릭하면 편집기가 열리고, **Delete Annotation**(휴지통 아이콘)을 클릭하면 하이라이트가 삭제됩니다. 이때 Layers 사이드바도 열리며, Annotations 목록에 해당 하이라이트가 표시됩니다.

#### 영역 하이라이트 도구로

기존 하이라이트를 클릭하면 바로 편집기가 열립니다.

#### 편집기에서

- 새 색상은 바로 적용됩니다
- 제목이나 메모를 바꾼 뒤에는 **Save**를 클릭하거나 `Cmd/Ctrl + Enter`를 누르세요
- **Close**나 `Esc`를 누르면 제목과 메모를 저장하지 않고 나갑니다
- 휴지통 아이콘을 누르면 하이라이트가 삭제됩니다

### 영역 하이라이트 이동과 크기 조절

선택 도구로 하이라이트를 드래그하면 옮길 수 있습니다. 선택한 하이라이트에는 모서리마다 핸들이 표시되며, 핸들을 드래그하면 크기가 조절됩니다.

편집기가 열려 있는 동안에는 상자 주위에 핸들 8개가 나타납니다.

- 왼쪽 위, 위, 오른쪽 위
- 왼쪽, 오른쪽
- 왼쪽 아래, 아래, 오른쪽 아래

지우고 다시 그리지 않고도 크기를 정밀하게 조절할 수 있습니다.

### 영역 하이라이트 삭제

하이라이트는 다음 방법으로 제거할 수 있습니다.

- 카드에서 **Delete Annotation** 클릭
- 편집기에서 휴지통 아이콘 클릭
- Layers 사이드바의 Annotations 목록에서 해당 항목 옆의 **Delete Annotation** 클릭
- 영역 하이라이트 도구가 활성화된 상태에서 하이라이트를 오른쪽 클릭

실행 취소하면 삭제한 하이라이트가 돌아옵니다.

### 하이라이트 썸네일

영역 하이라이트를 저장하면 Zditor가 그 영역의 이미지를 캡처해 **Settings → Editor → PDF Editor → Highlight thumbnails**에서 고른 위치에 저장합니다. **Settings → Integrations → Image hosting & uploads**에서도 같은 설정을 할 수 있습니다. 저장 위치는 로컬 폴더이거나, 설정해 둔 S3 호환, WebDAV, GitHub 스토리지일 수 있습니다.

하이라이트에 썸네일이 없다면 Layers 사이드바의 Annotations 목록에서 해당 하이라이트 위에 마우스를 올리고 **Regenerate missing thumbnails**를 클릭하세요.

## Markdown에서 PDF 카드 참조

영역 하이라이트는 PDF 뷰어 안에서만 쓰는 것이 아닙니다. Markdown 문서에 PDF 카드로 삽입할 수 있어, 읽으면서 단 주석을 재사용할 수 있는 노트로 만들 때 유용합니다.

Markdown 문서에서 `@`를 입력하면 Zditor가 참조 목록을 엽니다. 목록에는 다음이 포함됩니다.

- 작업 공간의 Markdown 파일
- 주석을 단 PDF

영역 하이라이트가 있는 PDF를 고르면 Zditor가 두 종류의 항목이 담긴 하위 메뉴를 엽니다.

- **PDF 자체**: PDF 전체로 연결되는 링크를 삽입합니다
- **각 영역 하이라이트**: 해당 영역의 PDF 카드를 삽입합니다

영역 하이라이트가 없는 PDF는 바로 링크로 삽입됩니다. 하이라이트는 제목으로, 제목이 없으면 페이지와 메모로 나열됩니다. `@` 뒤에 계속 입력하면 파일 이름, 하이라이트 제목, 메모, 페이지 번호(예: `page 3`)를 검색합니다.

PDF 카드에는 하이라이트의 제목(있는 경우)과 PDF 파일 이름이 표시됩니다.

### 일반적인 작업 흐름

<Steps>
  <Step title="먼저 PDF에 영역 하이라이트 만들기">
    중요한 영역에 영역 하이라이트를 추가하세요. 나중에 목록에서 알아보기 쉽도록 제목이나 메모를 달아 두는 것이 좋습니다.
  </Step>

  <Step title="Markdown 문서로 돌아가 @ 입력">
    작업 공간 참조 목록이 열립니다.
  </Step>

  <Step title="대상 PDF 선택">
    첫 번째 목록에서 PDF를 선택하면 하위 메뉴가 열립니다.
  </Step>

  <Step title="PDF 전체 또는 하이라이트 선택">
    파일 전체로 연결되는 링크가 필요하면 PDF 자체를, 특정 영역을 가리키는 카드가 필요하면 해당 하이라이트를 선택하세요.
  </Step>

  <Step title="Markdown에 삽입">
    Zditor가 링크나 PDF 카드를 현재 Markdown 문서에 삽입합니다.
  </Step>
</Steps>

### Markdown에서 PDF 카드 클릭

PDF 카드를 클릭하면 카드가 선택되고 도구 모음이 열립니다. 도구 모음은 글과 원본 PDF를 이어 줍니다.

- **ASK AI**: 하이라이트의 페이지, 제목, 메모와 함께 카드를 에이전트에서 엽니다
- **PDF 파일 이름**: PDF를 열고 하이라이트로 스크롤한 뒤 선택합니다
- **Open with Default App**, **Open Containing Folder**, **Copy File Path**: PDF 파일에 대해 작업합니다(데스크톱 앱)
- 하이라이트의 페이지 번호
- **Edit Title**: 노트에서 이 카드에 표시되는 제목을 바꿉니다
- **Refresh**: 하이라이트의 세부 정보와 썸네일을 다시 불러옵니다
- **More Options**: 하이라이트의 페이지, 제목, 메모, 썸네일을 보여 줍니다. 썸네일을 클릭하면 원래 크기로 볼 수 있습니다.

즉 PDF 카드는 단순한 정적 참조가 아닙니다. Markdown에 정리한 노트를 바탕으로 글을 쓰다가, 원래 맥락을 확인해야 할 때마다 원본 PDF로 바로 돌아갈 수 있습니다.

<Tip>
  이 작업 흐름은 논문 읽기와 연구 노트에 특히 유용합니다. Markdown 쪽에는 재사용할 수 있는 카드가, PDF 쪽에는 주석을 단 원래 영역이 남습니다.
</Tip>

이 방식은 다음과 같은 경우에 유용합니다.

- 논문 하이라이트를 노트로 정리할 때
- PDF 썸네일과 메모 맥락을 Markdown 안에 함께 둘 때
- 읽으면서 구조화된 연구 노트를 만들 때

## 레이어 관리

레이어는 PDF 주석을 정리하는 핵심 기능 중 하나입니다. 제목 표시줄의 **Layers**를 클릭하면 사이드바에 레이어가 열립니다. 모든 PDF는 **Default Layer**로 시작합니다.

### 지원되는 레이어 작업

레이어 사이드바에서 할 수 있는 일은 다음과 같습니다.

- **Add Layer**(더하기 아이콘)를 클릭해 레이어 만들기. 새 레이어가 활성 레이어가 됩니다
- 레이어를 클릭해 활성 레이어로 만들기. 숨겨진 레이어를 클릭하면 다시 표시되기도 합니다.
- 레이어 이름을 더블클릭해 이름 바꾸기. `Enter`로 확정하고 `Esc`로 취소합니다.
- 레이어 위에 마우스를 올리고 눈 아이콘을 클릭해 숨기거나 표시하기
- 레이어 위에 마우스를 올리고 휴지통 아이콘을 클릭해 삭제하기. 마지막 남은 레이어는 삭제할 수 없습니다.

<Warning>
  레이어를 삭제하면 그 레이어에 저장된 획과 영역 하이라이트도 함께 삭제됩니다. PDF가 열려 있는 동안에는 실행 취소로 되살릴 수 있습니다.
</Warning>

레이어 아래의 **Annotations** 목록에는 모든 영역 하이라이트가 페이지, 레이어, 제목, 메모와 함께 표시됩니다. 항목을 클릭하면 해당 페이지로 이동합니다.

### 활성 레이어의 의미

활성 레이어는 다음을 결정합니다.

- 새 획이 만들어지는 곳
- 새 영역 하이라이트가 만들어지는 곳
- 붙여 넣은 획이 들어가는 곳
- **Clear Page**가 지우는 획

지우개, 올가미, 선택 도구는 보이는 모든 레이어에 작동합니다. 활성 레이어를 숨기면 보이는 첫 번째 레이어가 활성 레이어가 됩니다.

### 레이어 표시 여부

각 레이어는 따로 숨기거나 표시할 수 있습니다. 레이어를 숨기면 다음과 같이 됩니다.

- 그 레이어의 획과 영역 하이라이트가 페이지에서 사라집니다
- 인쇄할 때 제외됩니다
- 데이터는 그대로 남아 있으며, Annotations 목록에도 그 레이어의 하이라이트가 계속 표시됩니다

다음과 같은 경우에 유용합니다.

- 주석을 주제별로 분리
- 개인 표시와 팀 표시 구분
- 한 가지 주석 범주에 잠시 집중

## 선택과 일괄 작업

선택 도구나 올가미로 획을 선택하면 Zditor가 선택 영역 왼쪽에 세로 도구 모음을 표시합니다.

사용할 수 있는 작업은 다음과 같습니다.

- **Delete**
- **Copy**
- **Cut**
- **Paste**: 복사하거나 잘라낸 뒤에 나타납니다. 복사한 획을 이 페이지의 활성 레이어에 약간 어긋난 위치로 추가합니다.
- **Move to Layer**: PDF에 레이어가 둘 이상일 때 나타납니다

선택 영역 안을 드래그해 선택한 획을 한꺼번에 옮길 수도 있습니다.

복사와 잘라내기는 같은 PDF 안에서 붙여 넣기 위해 획을 보관할 뿐, 시스템 클립보드는 사용하지 않습니다.

### 삭제 단축키

선택 도구나 올가미로 획을 선택한 상태라면 다음 키를 눌러

- `Delete`
- `Backspace`

선택한 획을 삭제할 수 있습니다.

## 실행 취소, 다시 실행, 지우기

### 실행 취소와 다시 실행

**Undo**와 **Redo**는 제목 표시줄에 있습니다. 모든 페이지와 레이어에 걸쳐 PDF 주석의 모든 변경 사항을 한 단계씩 되돌리거나 다시 실행합니다.

- 획 그리기, 지우기, 옮기기, 붙여넣기, 삭제, 다른 레이어로 옮기기
- 영역 하이라이트 만들기, 편집, 옮기기, 크기 조절, 삭제
- 레이어 추가, 이름 바꾸기, 숨기기, 표시, 삭제
- **Clear Page**
- PDF가 열려 있는 동안 에이전트가 만든 변경 사항

기록은 PDF가 열려 있는 동안 유지됩니다. PDF를 다시 열면 기록이 새로 시작됩니다.

### 현재 페이지 지우기

**Clear Page**(제목 표시줄의 휴지통 아이콘, 탭이 좁으면 **More** 안에 있음)는 다음 범위의 모든 획을 지웁니다.

- 현재 페이지, 즉 왼쪽 아래 페이지 번호에 표시된 페이지
- 활성 레이어

<Warning>
  **Clear Page**는 획에만 적용됩니다. 영역 하이라이트와 다른 레이어의 획은 그대로 남습니다. 실행 취소하면 지운 획이 돌아옵니다.
</Warning>

## 책갈피, 검색, 이동

### PDF 책갈피

PDF에 자체 개요나 책갈피가 있으면 제목 표시줄의 **Bookmarks**를 클릭해 사이드바에 표시하세요.

다음과 같은 일을 할 수 있습니다.

- 중첩된 책갈피 펼치기 또는 접기
- 책갈피를 클릭해 해당 페이지로 이동하기. 페이지 번호는 제목 옆에 표시됩니다
- 사이드바에서 현재 위치 확인하기. 현재 페이지의 책갈피가 강조 표시됩니다

개요가 없는 PDF에는 **No bookmarks**가 표시됩니다.

### 텍스트와 주석 메모 검색

제목 표시줄의 **Search**를 클릭하거나 `Cmd/Ctrl + F`를 누르세요. 검색 입력란이 제목 표시줄의 버튼 자리에 나타나고, 결과는 사이드바에 열립니다.

PDF 검색은 PDF 본문 텍스트만 검색하지 않습니다. 영역 하이라이트의 메모도 검색합니다.

검색은 다음과 같이 동작합니다.

- 입력을 멈추면 곧 결과가 업데이트되고, 뷰어가 첫 번째 결과로 이동합니다
- 대소문자를 구분하지 않습니다
- `Enter` 또는 아래쪽 화살표 버튼: 다음 결과
- `Shift + Enter` 또는 위쪽 화살표 버튼: 이전 결과
- `Esc` 또는 닫기 버튼: 검색과 결과 닫기

### 검색 결과 표시 방식

일치하는 항목을 찾으면 다음과 같이 표시됩니다.

- 페이지에서 일치하는 영역이 표시됩니다
- 검색 입력란에 현재 결과의 위치가 `2/7`처럼 표시됩니다
- 사이드바에 모든 결과가 나열되며, 결과를 클릭하면 해당 위치로 이동합니다

결과에는 두 가지 유형이 있습니다.

- **텍스트 일치**: 페이지별로 묶입니다. 일치하는 항목이 있는 페이지 하나가 결과 하나입니다
- **하이라이트 메모 일치**: 하이라이트마다 하나씩, 하이라이트의 색상, 페이지, 메모와 함께 나열됩니다

## 확대/축소와 읽기

PDF 뷰어는 다음을 지원합니다.

- 왼쪽 아래의 **Zoom In**과 **Zoom Out**
- 확대 비율을 클릭해 페이지를 뷰어 너비에 맞추기
- Mac 트랙패드에서 핀치하기
- `Ctrl`을 누른 채 스크롤하기
- 40%에서 400%까지의 확대 비율
- 페이지 번호를 클릭하고 페이지를 입력한 뒤 `Enter`를 눌러 해당 페이지로 이동하기

### 인쇄

제목 표시줄의 **Print**는 PDF의 모든 페이지를 보이는 레이어의 주석과 함께 인쇄합니다. 숨긴 레이어는 인쇄되지 않습니다.

### 다크 모드

Zditor가 어두운 화면 모드를 사용할 때는 더 편하게 읽을 수 있도록 PDF 페이지의 색이 반전되어, 어두운 페이지에 밝은 텍스트가 표시됩니다.

<Tip>
  반전은 PDF 페이지에만 적용됩니다. 주석은 페이지 위의 별도 레이어에 그려지므로 원래 색상을 유지합니다.
</Tip>

## 에이전트와 함께 작업

내장 에이전트는 탭에 열려 있는지와 관계없이 작업 공간의 모든 PDF로 작업할 수 있습니다. 다음과 같은 일을 요청할 수 있습니다.

- PDF의 개요와 기존 하이라이트를 포함해 PDF를 페이지별로 읽기
- 특정 구절 찾기
- 그림, 표, 스캔한 페이지처럼 페이지 전체나 일부를 살펴보기
- 구절에 제목과 메모가 달린 하이라이트를 추가하거나, 밑줄이나 취소선을 긋거나, 상자로 두르기
- 자유롭게 그리기, 하이라이트 편집 또는 삭제, 획 삭제

알아 둘 점은 다음과 같습니다.

- 사용자의 레이어를 쓰라고 요청하지 않는 한 새 주석은 **Agent**라는 레이어에 추가되므로, 에이전트의 작업을 한 번에 숨기거나 삭제할 수 있습니다
- PDF가 열려 있으면 에이전트의 변경 사항이 바로 나타나며, **Undo**로 변경 묶음을 한 번에 하나씩 되돌릴 수 있습니다
- 에이전트는 만든 하이라이트마다 바로 쓸 수 있는 PDF 카드 링크를 받으므로, Markdown 노트에서 그 하이라이트를 인용할 수 있습니다
- 에이전트가 만든 하이라이트의 썸네일은 PDF가 열려 있는 동안 만들어집니다. PDF가 닫혀 있는 동안 만든 하이라이트라면 PDF를 열고 Annotations 목록에서 **Regenerate missing thumbnails**를 사용하세요.
- 읽기, 검색, 페이지 살펴보기에는 승인이 필요하지 않습니다. 주석 추가, 변경, 삭제는 에이전트의 **Permission mode**를 따릅니다.

에이전트를 AI 서비스에 연결하려면 **Settings → AI → Agents**를 여세요.

## 성능 참고 사항

페이지 목록은 화면 주변의 페이지만 렌더링합니다.

- 보이는 페이지와 그 앞뒤 한 페이지씩은 완전히 렌더링됩니다
- 나머지 페이지는 스크롤 높이를 유지하는 자리 표시자로 대체됩니다

이렇게 하면 특히 긴 PDF, 높은 확대 비율, 고해상도 디스플레이에서 렌더링 부담이 줄어듭니다.

PDF에서 처음 검색할 때는 모든 페이지의 텍스트를 읽으므로 긴 문서에서는 잠시 시간이 걸릴 수 있습니다. 같은 PDF에서 이후에 검색할 때는 그 텍스트를 재사용합니다.

    PDF를 열고 Layers 사이드바를 연 다음, Annotations 목록에서 해당 하이라이트 위에 마우스를 올리고 **Regenerate missing thumbnails**를 클릭하세요. 계속 실패하면 **Settings → Editor → PDF Editor → Highlight thumbnails**에서 저장 위치를 확인하세요.
  </Accordion>

  <Accordion title="레이어를 삭제하면 어떻게 되나요?" icon="question">
    레이어를 삭제하면 그 레이어에 저장된 획과 영역 하이라이트가 제거됩니다. PDF가 열려 있는 동안에는 실행 취소로 되살릴 수 있습니다. 일부 획을 남기려면 먼저 **Move to Layer**로 다른 레이어에 옮기세요. 영역 하이라이트는 레이어 간에 옮길 수 없습니다.
  </Accordion>

  <Accordion title="PDF를 닫은 뒤에도 변경 사항을 실행 취소할 수 있나요?" icon="question">
    아니요. 실행 취소 기록은 PDF가 열려 있는 동안에만 유지됩니다. 나중에 에이전트의 작업을 되돌리려면 **Agent** 레이어를 숨기거나 삭제하세요.
  </Accordion>

  <Accordion title="영역 하이라이트와 일반 형광펜은 어떻게 다른가요?" icon="question">
    형광펜은 자유롭게 그린 반투명 획을 그립니다. 영역 하이라이트는 제목, 메모, 색상, 썸네일을 갖춘 구조화된 사각형입니다. 옮기거나 크기를 조절할 수 있고, 검색에서 메모로 찾을 수 있으며, Markdown에서 PDF 카드로 인용할 수 있습니다.
  </Accordion>
