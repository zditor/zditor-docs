SuperTag позволяет Zditor работать с файлами Markdown как со структурированными записями и показывать ссылки на эти записи в документах в виде плашек, похожих на теги.

## Обзор

<CardGroup cols={2}>
  <Card title="Структурированные записи" icon="database">
    Метаданные для повторного использования хранятся во Frontmatter, а сам текст остаётся обычным Markdown.
  </Card>

  <Card title="Общий класс" icon="table">
    Объединяйте файлы в одну логическую таблицу, задавая им одинаковое значение `class`.
  </Card>

  <Card title="Ссылки в тексте" icon="link">
    Вставляйте запись в другой документ с помощью `mode=supertag`.
  </Card>

  <Card title="Поля макета карточки" icon="table">
    Поля `col`, `row`, `cover`, `warm` и другие определяют вид шапки документа и карточек записей.
  </Card>

## Основные понятия

<AccordionGroup>
  <Accordion title="Запись — это обычный файл Markdown" icon="file" defaultOpen>
    Запись SuperTag — обычный документ Markdown с типизированным Frontmatter.

    ```yaml
    ---
    title:
      type: text
      label: Title
      value: "The Godfather"
    director:
      type: text
      label: Director
      value: "Francis Ford Coppola"
    year:
      type: number
      label: Year
      value: 1972
    class:
      type: text
      label: class
      value: "ClassicMovieEnglish"
    ---
    ```
  </Accordion>

  <Accordion title="Поле class группирует записи" icon="table">
    Файлы с одинаковым значением `class` относятся к одной логической таблице. `class` должно быть текстовым полем.

    ```yaml
    class:
      type: text
      label: class
      value: "ClassicMovieEnglish"
    ```

    Именно так Zditor собирает множество файлов Markdown в одну структурированную коллекцию. Ваши классы перечислены на вкладке **Objects** боковой панели **Calendar**.
  </Accordion>

  <Accordion title="Файл схемы задаёт поля" icon="list-check">
    Файл с тем же `class` и списком `field` служит файлом схемы класса. `field` перечисляет поля, которые должны быть у каждой записи, а сам файл схемы содержит эти поля с их типами и подписями.

    ```yaml
    ---
    class:
      type: text
      label: class
      value: "ClassicMovieEnglish"
    field:
      type: array
      label: field
      value: [title, director, year]
    title:
      type: text
      label: Title
      value: ""
    director:
      type: text
      label: Director
      value: ""
    year:
      type: number
      label: Year
      value: 0
    ---
    ```

    Записи, созданные из меню `#`, получают эти поля, скопированные из файла схемы. Файл схемы также задаёт столбцы таблицы класса, а в графе знаний каждая запись связана с ним.
  </Accordion>

  <Accordion title="col и row определяют макет карточки" icon="table">
    Поля макета определяют, какие метаданные выделяются в шапке документа и на карточках записей в представлении **Gallery** класса.

    ```yaml
    col:
      type: array
      label: Col
      value: [year, title, director]
    row:
      type: array
      label: Row
      value: [genre, rank, score, watched]
    ```

    - `col` задаёт до трёх полей для области заголовка: короткую строку сверху, заголовок и описание снизу
    - `row` задаёт поля, которые показываются в информационной строке под ними
  </Accordion>
</AccordionGroup>

## Синтаксис ссылок

Используйте обычную ссылку Markdown с `mode=supertag`:

```markdown
[ClassicMovieEnglish](/movies/The%20Godfather.md|mode=supertag)
```

- Текст в квадратных скобках — класс записи.
- Путь указывает на файл записи. Путь, начинающийся с `/`, отсчитывается от корня рабочего пространства, любой другой — от папки текущего документа. Пробелы в пути записываются как `%20`.

В редакторе ссылка выглядит как цветная плашка, например `#ClassicMovieEnglish · The Godfather`. Цвет зависит от имени класса.

<Note>
  Набирать этот синтаксис вручную приходится редко. Введите `#` в документе, чтобы открыть меню объектов со списком ваших классов; выберите класс, затем запись — и ссылка будет вставлена. **Create Row** создаёт в папке текущего документа новую запись класса с именем из введённого текста и вставляет её. **Create Table** начинает новый класс — он появится, когда вы создадите его первую строку. Если меню не появляется, проверьте, что параметр **Object menu (#)** включён в **Settings → Editor → Markdown Editor**.
</Note>

Нажмите на ссылку, чтобы выделить её. На появившейся панели есть:

- Имя класса — открывает все записи класса во вкладке с представлениями **Table**, **Gallery** и **Gantt**
- Имя записи — открывает файл записи
- Кнопка обновления — обновляет индекс заметок Zditor
- **Info** — показывает поля записи

## Распространённые типы полей

| Тип | В редакторе | Где применять |
| --- | --- | --- |
| `text` | Text | название, автор, страна, примечания |
| `number` | Number | год, оценка, место в рейтинге |
| `date` | Date | сроки, даты просмотра, даты создания |
| `checkbox` | Toggle | готовность, тёплая тема, отметка «рекомендуемое» |
| `multiselect` | Multi-select | жанр, теги, категории |
| `array` | List | списки актёров, списки полей макета |
| `progress` | Progress | значения от 0 до 100, например оценки или степень готовности |
| `asset` | Image | обложки и другие изображения |

Все типы полей и способы их редактирования описаны на странице [Метаданные Frontmatter](/ru/frontmatter).

## Рекомендуемый порядок работы

<Steps>
  <Step title="Скопируйте существующую запись">
    Начните с файла, у которого уже есть нужная схема, или создайте запись из меню `#` с помощью **Create Row**.
  </Step>

  <Step title="Сохраните структуру полей и класс">
    Используйте те же ключи, типы и значение `class`, чтобы запись осталась в той же коллекции.
  </Step>

  <Step title="Замените конкретные значения">
    Обновите заголовок, даты, обложку и текст под новую запись.
  </Step>

  <Step title="Добавляйте общие поля позже">
    Если всему классу нужно новое поле, добавьте его единообразно во все записи коллекции и в список `field` файла схемы.
  </Step>
</Steps>

<Tip>
  SuperTag работает лучше всего, когда имена полей со временем не меняются. Не переименовывайте поля без необходимости, если класс уже используется.
</Tip>
