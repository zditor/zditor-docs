Zditor にはエージェントが組み込まれています。エージェントはワークスペース内のファイルを扱い、ノートの読み取りと編集、PDF への注釈、キャンバスの作成、コマンドの実行を行い、Zditor 自体を操作することもできます。エージェントが使う AI サービスは、Zditor アカウントで使う Zditor AI と、自分で用意したプロバイダーから選べます。また、確認なしで何をしてよいかも自分で決められます。

<Warning>
  エージェントは、ファイルを変更したり、コマンドを実行したり、Mac ではほかのアプリを操作したりできます。承認する前に各リクエストをよく読み、信頼できるタスクでない限り、権限モードは **Always ask** のままにしてください。
</Warning>

また、大きなタスクの一部を並行して動くサブエージェントに任せたり、判断が必要なときに質問したり、作成したもの（HTML ページ、画像、動画など）を Zditor のタブで開いたりすることもできます。

<Note>
  iPhone と iPad、およびリモートワークスペース（SSH、S3、WebDAV、Git）では、エージェントは Zditor を通じてファイルを読み書きできますが、ターミナルのコマンドの実行やほかのアプリの操作はできません。リモートワークスペースでは Git も使えません。
</Note>

## AI サービスの設定

エージェントを使うには、まず AI サービスが必要です。**Settings → AI → Agents** を開き、**Provider** の **AI service** を **Zditor** または **Custom provider** に設定します。

<Tabs>
<Tab title="Zditor AI">
  Zditor AI には API キーは不要です。Zditor アカウントにログインしていて、毎月の AI 利用枠を含む Pro か、アカウントに無料の AI トークンがあれば使えます。無料のトークンは Claude Haiku 5.5 で使われます。

  1. **Settings → AI → Agents** を開きます。
  2. ログインしていない場合は、**Sign in** をクリックし、ブラウザーでログインを完了します。
  3. **AI service** を **Zditor** に設定します。

  Zditor は起動するたびに、利用できるモデルとその設定を読み込みます。**Service configuration** の **Update** をクリックすると、すぐに読み込めます。利用状況は、**Settings → Personal → Account** の **AI usage** に表示されます。
</Tab>

<Tab title="カスタムプロバイダー">
  OpenAI Responses API または Claude Messages（Anthropic）API に対応したサービスを接続します。自分のパソコンで動いているサービスも使えます。

  <Steps>
    <Step title="プロトコルを選ぶ">
      **AI service** を **Custom provider** に設定し、サービスが対応している **API protocol**（**OpenAI Responses** または **Claude Messages (Anthropic)**）を選びます。
    </Step>

    <Step title="アドレスとキーを入力する">
      **Base URL** に、サービスの API のルートアドレスを入力します。通常は `/v1` で終わります（例：`https://api.openai.com/v1`、`https://api.anthropic.com/v1`）。続けて **API key** を入力します。ローカルのプロバイダーでは不要な場合があります。キーはこのデバイスに保存され、このアドレスにだけ送信されます。
    </Step>

    <Step title="モデルを追加する">
      **Model and generation** で **Fetch models** をクリックします。プロバイダーのモデルが **Not enabled** として表示されるので、使いたいモデルをそれぞれ開いて **Enable** スイッチをオンにします。プロバイダーの一覧にないモデルを追加するには、**Add model** にモデル ID を入力して Enter キーを押します。この方法で追加したモデルは有効になります。
    </Step>

    <Step title="トークンの上限を確認する">
      有効にした各モデルには、**Context window tokens** と **Maximum output tokens** が必要です。プロバイダーがこれらの値を返す場合は、Zditor が自動で入力します（**Server-reported**）。返さない場合は、**Enter manually** を選び、プロバイダーのドキュメントに記載された数値を入力します。
    </Step>

    <Step title="保存する">
      **Save** をクリックします。**Test connection** を使うと、モデルの一覧を取得して、アドレスとキーを確認できます。
    </Step>
  </Steps>
</Tab>
</Tabs>

### モデルの設定

モデルを調整するには、**Model and generation** でモデルを開きます。Zditor AI では、これらの設定を確認できますが、変更はできません。

| 設定 | 内容 |
| :--- | :--- |
| **Reasoning effort** | 回答する前にモデルがどの程度推論するか。**Automatic** ではモデルの既定値を使います。レベルが高いほど、時間とトークンを多く使います。 |
| **Temperature** | 値が低いほど回答が予測しやすく、高いほど多様になります。空欄にすると、サービスに任せます。 |
| **Context window tokens**、**Maximum output tokens** | モデルの上限。サービスから報告された値か、自分で入力した値です。 |
| **Automatic compaction threshold** | 会話のトークン数がこの値に達すると、Zditor は以前のコンテキストを要約して空きを作ります。既定値はコンテキストウィンドウの 90% です。 |

会話では、上部のモデルメニュー（**Model and reasoning effort**）に、有効にしたモデルと推論の強さが表示されます。会話の途中でもモデルを切り替えられ、新しい会話は最後に選んだモデルで始まります。

## 会話の開始

### Agent タブで

タブバーの **+** をクリックすると、新しいタブが開きます。新しいタブは Agent タブです。エージェントは Zditor で開いているワークスペースで作業するので、先にワークスペースを開いてください。空の Agent タブには **Open Workspace** と **New Workspace** が表示されます。ワークスペースがない場合、エージェントは Zditor のアプリデータ内にある作業用フォルダーで作業します。

### ドキュメントの横で

Markdown のノートで、タイトルバーの **Document sidebar** をクリックし、**Chat** タブを選びます。チャットはそのノートが添付された状態で始まるので、すぐにノートについて質問できます。キャンバスのサイドバーにも同じ **Chat** タブがあります。

ノートの一部について質問するには、その部分を選択し、選択ツールバーのきらめきのボタン（**ASK AI**）をクリックします。選択範囲が添付された状態で **Chat** タブが開きます。**Settings → AI → AI Toolbar Prompts** で設定したプロンプトは、ツールバーに追加のボタンとして表示され、選択範囲とともにその指示がすぐに送信されます。

<Note>
  ドキュメントのサイドバーでのチャットは一時的なもので、会話履歴には保存されません。残しておきたい作業には Agent タブを使ってください。
</Note>

### 依頼の書き方

メッセージ入力欄に入力して、**Send message** をクリックします。エージェントの作業中は **Stop current turn** で止められます。その間に送信したメッセージは、現在のターンが終わるまでキューで待機します。

- `/` を入力すると、コマンドを実行できます（下の表を参照）。
- `@` を入力すると、ワークスペースのファイルを添付できます。
- `$` を入力すると、スキルを使えます。
- ファイルを添付するには、**Upload file**（クリップのアイコン）をクリックするか、ファイルをメッセージ入力欄にドラッグします。画像、音声、テキストファイルはメッセージに含まれます。PDF や Office 文書などその他のファイルはパスで渡され、エージェントが自分で開きます。

iPhone と iPad では、メッセージ入力欄の下にある **Commands**、**Files**、**Skills** の各ボタンで、`/`、`@`、`$` と同じ一覧を開けます。

AI サービスに初めてメッセージを送るときは、そのサービスとデータを共有してよいかを確認されます。下の「プライバシー」を参照してください。

### コマンド

| コマンド | 内容 |
| :--- | :--- |
| `/goal` | 会話に目標を設定します。エージェントは、目標を達成するか行き詰まるまで、ターンをまたいで作業を続けます。設定するには `/goal` に続けて目的を入力します。`/goal` だけを入力すると現在の目標を確認でき、`/goal edit`、`/goal pause`、`/goal resume`、`/goal clear` も使えます。一時的なチャットでは使えません。 |
| `/side` | 現在のコンテキストから始まる、一時的なサイド会話を開きます。コマンドの後に質問を続けて入力することもできます。 |
| `/compact` | これまでの会話を要約してコンテキストの空きを作ります。重要な情報は保持されます。 |
| `/export` | 会話を Markdown として保存します。`/export json` では JSON として保存します。 |
| `/share` | 会話を PNG 画像として保存します。 |

<Tip>
  目標が有効な間、エージェントは新しいメッセージがなくても作業を続け、ターンごとにトークンを消費します。止めたいときは、目標を一時停止するか消去してください。
</Tip>

### 作業中の表示

エージェントは、読み取ったり編集したりしたファイル、実行したコマンド、回答など、作業の様子を順に表示します。ターンが終わると、その手順は **Work details** に折りたたまれ、展開して確認できます。

- ファイルを変更したターンの後には、**Changed 2 files** のようなカードに変更したファイルが一覧表示されます。ファイルを展開すると、変更内容を確認できます。ローカルのワークスペースでは、**Undo** でそのターンのテキストの変更を元に戻せます。その後にファイルが変更されている場合は、何も元に戻されません。
- メッセージ入力欄の下の **Usage** には、会話がモデルのコンテキストウィンドウをどれだけ使っているかが表示されます。モデルの圧縮しきい値に達すると、Zditor が以前のコンテキストを自動的に圧縮します。`/compact` を使えば、好きなときに圧縮できます。
- Agent タブでは、メッセージの **More** メニューから **Branch in new chat** を選ぶと、その時点から新しい会話で続けられます。元の会話はそのまま残ります。
- ワークスペースに `AGENTS.md` ファイルがある場合、エージェントはそれをプロジェクトの指示として従います。

## 権限と承認

メッセージ入力欄の下で **Permission mode**（権限モード）を選びます。選んだモードは記憶されます。

| モード | 動作 |
| :--- | :--- |
| **Always ask** | 制限された操作の前に、エージェントが毎回確認を求めます。これが既定のモードです。 |
| **AI review** | モデルへの別のリクエストで、制限された各操作をタスクに照らして確認し、許可または拒否します。判断に迷う場合は拒否します。あなたに確認は求められず、確認のたびにモデルへのリクエストが 1 回増えます。 |
| **Full Access** | すべてのツール操作が確認なしで実行されます。 |

**Always ask** では、エージェントは次の操作の前に確認を求めます。コマンドの実行（デスクトップでは、ファイルを読み取るだけのコマンドも含みます）、ファイルの編集、Git の使用、Web リクエストの送信、Zditor のタブや設定の変更、PDF への注釈、キャンバスの編集、MCP ツールの呼び出し、アプリを開く操作、アプリ内でのクリック・入力・スクロールです。PDF やキャンバスの読み取り、開いているタブの確認、スクリーンショットの撮影には承認は不要です。

確認を求めるときは、操作の内容と 3 つの選択肢が表示されます。

- **Allow once**：この操作を実行します。
- **Always allow**：この操作を実行し、その会話の間は、同じコマンドや同じファイルへの追加の編集など、同じ操作を確認なしで許可します。ほかの操作では引き続き確認を求めます。
- **Reject**：操作を実行せず、拒否したことをエージェントに伝えます。

<Tip>
  デスクトップでのタスクでは、多くのコマンドを実行することがよくあります。1 つずつ承認するのが面倒な場合は、**AI review** が中間的な選択肢になります。**Full Access** は、バージョン管理しているワークスペースなど、元に戻せるワークスペースでだけ使ってください。
</Tip>

## Mac の操作

Mac のローカルのワークスペースでは、タスクに必要な場合、エージェントがほかのアプリを操作できます。スクリーンショットとアクセシビリティ情報からアプリのウィンドウを把握し、アプリを開く、クリックする、入力する、スクロールする、キーを押すといった操作ができます。

- 初回は、Zditor に**画面収録**と**アクセシビリティ**の許可を与えるよう macOS から求められます。どちらかが許可されていない場合、会話のその操作のステップに「macOS is blocking computer use:」と表示され、足りない許可ごとに **Open Accessibility** または **Open Screen Recording** のボタンが表示されます。ボタンをクリックすると、システム設定の該当するページが開きます。どちらの許可も、そこでいつでもオフにできます。
- **Always ask** では、アプリを開く、クリック、入力、スクロール、キー操作に承認が必要ですが、スクリーンショットには不要です。これらのいずれかで **Always allow** を選ぶと、その会話では同じ種類の操作も確認なしで行われます。
- エージェントの作業中は、操作しているアプリがパネルに表示されます。パネルを閉じた場合は、**Show computer use window**（メッセージ入力欄の下にあるモニターのボタン）で再び表示できます。

## MCP サーバーとスキル

### MCP サーバー

MCP サーバーは、課題管理ツールやデータベースなど、ほかのアプリやサービスにエージェントを接続します。**Settings → AI → MCP Servers** で追加すると、有効なサーバーはすべて、エージェントとのどの会話でも使えます。[MCP ガイド](/ja/mcp-guide)を参照してください。

### スキル

スキルとは、特定の種類のタスク向けに書かれた一連の指示で、`SKILL.md` ファイルに保存されます。エージェントはすべてのスキルの名前と説明を把握していて、タスクに合うときに指示の全文を読みます。スキルを意図的に使うには、メッセージ入力欄で `$` を入力して選びます。

- **組み込みスキル**：**Canvas**、**Markdown**、**Settings and tabs** は Zditor に付属しています。**Settings → AI → Skills** の **Installed skills** に表示されます。
- **自分のスキル**：**Settings → AI → Skills** で **Add skill** をクリックし、**Name**（英字、数字、ハイフン、アンダースコア）、**Description**（スキルの用途）、**Skill instructions (Markdown)** を入力して、**Save** をクリックします。スキルは Zditor のアプリデータに保存され、すべてのローカルのワークスペースで使えます。
- **プロジェクトのスキル**：`SKILL.md` を含むスキルのフォルダーをワークスペース内の `.zditor/skills` に置くと、そのワークスペースでだけ使えます。
- **ほかのエージェントのスキル**：Zditor は、ワークスペースやホームフォルダーにある `.agents/skills`、`.claude/skills`、`.codex/skills` など、ほかのエージェントのスキルフォルダーからもスキルを読み込みます。これらは設定には表示されないので、変更はそれぞれの場所で行ってください。
- **GitHub からのインストール**：デスクトップでは、`SKILL.md` を含む GitHub のフォルダーからスキルをインストールするよう、エージェントに頼めます。ほかの変更と同様に、**Always ask** ではあなたの承認が必要です。

## 会話履歴

Agent タブでの会話は自動的に保存され、タイトルが付けられます。会話を探すには、左のサイドバーの **AI conversations**（きらめきのアイコン）をクリックし、タイトルやワークスペースで検索します。会話をクリックすると、タブで開きます。

会話にポインターを合わせると、**Export session**（JSON）、**Export as text**、**Copy session ID**、**Delete session** が表示されます。**Clear History** を使うと、すべての会話が削除されます。

## プライバシー

- **送信前の確認**：AI サービスに初めて何かを送るとき、Zditor は **Allow data sharing with AI?** を表示し、送信先、サービスのアドレス、送信される内容を示します。**Allow and continue** をクリックするまで何も送信されず、**Not now** を選ぶとキャンセルされます。新しいサービスのアドレスごとに、改めて確認されます。
- **送信される内容**：メッセージ、会話履歴、選択したテキスト、追加した画像・音声・添付ファイル、そしてエージェントがタスクのために読み取るワークスペースのファイル、ファイル名、ツールの実行結果です。
- **送信先**：カスタムプロバイダーの場合、リクエストはデバイスから入力した **Base URL** に直接送られます。API キーはこのデバイスに保存され、そのアドレスにだけ送信されます。Zditor AI の場合、リクエストは Zditor のサービスを経由します。その利用記録に残るのは各リクエストのモデル、トークン数、費用で、メッセージは記録されません。MCP サーバーは、エージェントがそのツールに送る内容を受け取ります。
- **会話の保存場所**：このデバイスの、Zditor のアプリデータ内です。**Settings → Personal → Sync** で作成したバックアップには含まれません。
- **許可の取り消し**：**Settings → AI → Agents** の **AI data privacy** で **Withdraw permission** をクリックします。以後は、何かを送信する前に改めて確認されます。すでに送信したデータは取り戻せません。

  </Accordion>

    有効にしたモデルには、両方の上限が必要です。モデルを開いて **Enter manually** を選び、プロバイダーのドキュメントを見て **Context window tokens** と **Maximum output tokens** を入力してください。
  </Accordion>

  <Accordion title="「This response is incomplete」と表示される" icon="scissors">
    モデルが 1 回の応答の出力上限に達しました。そのモデルの **Maximum output tokens** を増やすか、タスクを小さく分けてください。
  </Accordion>

  <Accordion title="「Your input exceeds this model's context window」と表示される" icon="triangle-exclamation">
    メッセージや添付ファイルを短くするか、`/compact` を実行するか、コンテキストウィンドウの大きいモデルに切り替えてください。
  </Accordion>

  <Accordion title="「Model response timed out」と表示される" icon="hourglass-half">
    サービスが応答を始めるまでに時間がかかりすぎました。もう一度試してください。繰り返し起きる場合は、サービスの状態を確認するか、時間をおいて試してください。
  </Accordion>

  <Accordion title="エージェントがコマンドを実行できない、またはほかのアプリを使えない" icon="terminal">
    コマンドの実行にはデスクトップアプリとローカルのワークスペースが必要で、ほかのアプリの操作にはさらに Mac が必要です。iPhone と iPad、およびリモートワークスペースでは、エージェントは代わりに Zditor を通じてファイルを扱います。Mac では、システム設定で Zditor に**画面収録**と**アクセシビリティ**の許可があるか確認してください。
  </Accordion>

  <Accordion title="承認のリクエストが何度も表示される" icon="shield-halved">
    **Always ask** では、すべてのコマンドに承認が必要です。繰り返し使うコマンドには **Always allow** を選ぶか、**AI review** に切り替えてください。**Full Access** は、誤りを元に戻せる場合にだけ使ってください。
  </Accordion>
</AccordionGroup>
