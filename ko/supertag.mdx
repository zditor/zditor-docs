SuperTag를 사용하면 Zditor가 Markdown 파일을 구조화된 레코드로 다루고, 그 레코드에 대한 참조를 문서 안에 태그 모양의 칩으로 표시합니다.

## 핵심 개념

<AccordionGroup>
  <Accordion title="레코드도 Markdown 파일" icon="file" defaultOpen>
    SuperTag 레코드는 유형이 지정된 Frontmatter를 가진 일반 Markdown 문서입니다.

    ```yaml
    ---
    title:
      type: text
      label: Title
      value: "The Godfather"
    director:
      type: text
      label: Director
      value: "Francis Ford Coppola"
    year:
      type: number
      label: Year
      value: 1972
    class:
      type: text
      label: class
      value: "ClassicMovieEnglish"
    ---
    ```
  </Accordion>

  <Accordion title="class 필드로 레코드 묶기" icon="table">
    같은 `class` 값을 공유하는 파일은 같은 논리적 표에 속합니다. `class`는 텍스트 필드여야 합니다.

    ```yaml
    class:
      type: text
      label: class
      value: "ClassicMovieEnglish"
    ```

    이 덕분에 Zditor는 여러 Markdown 파일을 하나의 구조화된 컬렉션으로 모을 수 있습니다. **Calendar** 사이드바의 **Objects** 탭에 클래스 목록이 표시됩니다.
  </Accordion>

  <Accordion title="스키마 파일로 필드 정의" icon="list-check">
    같은 `class`와 `field` 목록을 가진 파일은 그 클래스의 스키마 파일 역할을 합니다. `field`는 모든 레코드가 가져야 할 필드를 나열하고, 스키마 파일에는 그 필드가 유형 및 레이블과 함께 들어 있습니다.

    ```yaml
    ---
    class:
      type: text
      label: class
      value: "ClassicMovieEnglish"
    field:
      type: array
      label: field
      value: [title, director, year]
    title:
      type: text
      label: Title
      value: ""
    director:
      type: text
      label: Director
      value: ""
    year:
      type: number
      label: Year
      value: 0
    ---
    ```

    `#` 메뉴에서 만든 레코드는 스키마 파일에서 복사한 이 필드를 갖고 시작합니다. 스키마 파일은 클래스 표의 열도 정의하며, 지식 그래프에서는 모든 레코드가 스키마 파일에 연결됩니다.
  </Accordion>

  <Accordion title="col과 row로 카드 레이아웃 구성" icon="table">
    레이아웃 필드는 문서 헤더와 클래스의 **Gallery** 보기에 있는 레코드 카드에서 어떤 메타데이터를 강조할지 정합니다.

    ```yaml
    col:
      type: array
      label: Col
      value: [year, title, director]
    row:
      type: array
      label: Row
      value: [genre, rank, score, watched]
    ```

    - `col`은 제목 영역에 쓸 필드를 최대 3개까지 지정합니다. 순서대로 위쪽의 작은 줄, 제목, 아래쪽 설명이 됩니다
    - `row`는 그 아래 정보 행에 표시할 필드를 지정합니다
  </Accordion>
</AccordionGroup>

## 참조 문법

`mode=supertag`를 붙인 일반 Markdown 링크를 사용하세요.

```markdown
[ClassicMovieEnglish](/movies/The%20Godfather.md|mode=supertag)
```

- 대괄호 안의 텍스트는 레코드의 클래스입니다.
- 경로는 레코드 파일을 가리킵니다. `/`로 시작하는 경로는 작업 공간 루트를 기준으로 하고, 그 밖의 경로는 현재 문서가 있는 폴더를 기준으로 합니다. 경로의 공백은 `%20`으로 씁니다.

편집기에서 참조는 `#ClassicMovieEnglish · The Godfather` 같은 색깔 칩으로 표시됩니다. 색상은 클래스 이름에 따라 달라집니다.

<Note>
  이 문법을 직접 입력할 일은 거의 없습니다. 문서에서 `#`를 입력하면 클래스 목록이 담긴 개체 메뉴가 열립니다. 클래스를 고른 다음 레코드를 고르면 참조가 삽입됩니다. **Create Row**는 입력한 텍스트를 이름으로 하는 새 레코드를 현재 문서의 폴더에 만들어 삽입합니다. **Create Table**은 새 클래스를 시작하며, 이 클래스는 첫 행을 만들어야 실제로 생깁니다. 메뉴가 나타나지 않으면 **Settings → Editor → Markdown Editor**에서 **Object menu (#)**가 켜져 있는지 확인하세요.
</Note>

참조를 클릭하면 선택됩니다. 이때 나타나는 도구 모음에는 다음이 표시됩니다.

- 클래스 이름: 클릭하면 해당 클래스의 모든 레코드가 **Table**, **Gallery**, **Gantt** 보기를 갖춘 탭에서 열립니다
- 레코드 이름: 클릭하면 레코드 파일이 열립니다
- 새로 고침 버튼: Zditor의 노트 인덱스를 업데이트합니다
- **Info**: 레코드의 필드를 보여 줍니다

## 자주 쓰는 필드 유형

| 유형 | 편집기 표시 | 주요 용도 |
| --- | --- | --- |
| `text` | Text | 제목, 저자, 국가, 메모 |
| `number` | Number | 연도, 점수, 순위 |
| `date` | Date | 마감일, 관람일, 생성일 |
| `checkbox` | Toggle | 완료 여부, 따뜻한 테마, 추천 여부 |
| `multiselect` | Multi-select | 장르, 태그, 카테고리 |
| `array` | List | 출연진 목록, 레이아웃 필드 목록 |
| `progress` | Progress | 점수나 완료율처럼 0부터 100까지의 값 |
| `asset` | Image | 커버와 기타 이미지 |

모든 필드 유형과 필드 편집 방법은 [Frontmatter 가이드](/ko/frontmatter)를 참고하세요.

## 권장 작업 흐름

<Steps>
  <Step title="기존 레코드 복사">
    원하는 스키마를 이미 갖춘 파일에서 시작하거나, `#` 메뉴의 **Create Row**로 레코드를 만드세요.
  </Step>

  <Step title="필드 구조와 클래스 유지">
    레코드가 같은 컬렉션에 남도록 같은 키, 유형, `class` 값을 그대로 쓰세요.
  </Step>

  <Step title="구체적인 값 바꾸기">
    제목, 날짜, 커버, 본문 내용을 새 레코드에 맞게 바꾸세요.
  </Step>

  <Step title="새 공통 필드는 나중에 채우기">
    클래스 전체에 필드가 하나 더 필요하다면 컬렉션 전체에 일관되게 추가하고, 스키마 파일의 `field` 목록에도 추가하세요.
  </Step>
</Steps>

<Tip>
  SuperTag는 필드 이름이 오래도록 바뀌지 않을 때 가장 잘 작동합니다. 클래스를 이미 쓰고 있다면 이름을 함부로 바꾸지 마세요.
</Tip>
