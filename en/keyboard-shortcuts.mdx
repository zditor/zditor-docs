Zditor includes extensive keyboard shortcut support for editing, formatting, structure changes, and navigation. The tables below list the default bindings of the Markdown editor and the app.

<Warning>
  `Mod` means `Ctrl` on Windows and Linux, and `Command` on macOS. `Alt` is the `Option` key on macOS.
</Warning>

## Global shortcuts

### Search and save

| Shortcut | Action |
| --- | --- |
| `Mod-K` | Open search |
| `Mod-S` | Save the current document |
| `Mod-F` | Search in the current document |

### View modes

These work in the active Markdown document. Press the same shortcut again to return to rich text.

| Shortcut | Action |
| --- | --- |
| `Mod-E` | Switch between edit mode and read-only mode |
| `Mod-/` | Switch between rich text and source view |
| `Mod-\` | Switch between rich text and split view |

### View zoom

| Shortcut | Action |
| --- | --- |
| `Mod-=` | Zoom in |
| `Mod--` | Zoom out |
| `Mod-0` | Reset zoom |

| Shortcut | Action |
| --- | --- |

### Suggestion menu

These keys work in the `/`, `@`, and `#` menus.

| Shortcut | Action |
| --- | --- |
| `ArrowUp` | Move up in the list |
| `ArrowDown` | Move down in the list |
| `Tab` / `Shift-Tab` | Move to the next or previous item |
| `ArrowRight` | Open the highlighted group |
| `ArrowLeft` | Go back from a group |
| `Enter` | Choose the highlighted item, or open the highlighted group |
| `Escape` | Go back from a group, or close the menu |
| `Backspace` | Delete a character and update the filter |

In the emoji picker that `:` opens, the arrow keys move around the grid, `Enter` inserts the highlighted emoji, and `Mod-ArrowLeft` / `Mod-ArrowRight` switch category before you type a filter.

## Shortcut customization

On desktop, open **Settings → Personal → Keyboard shortcuts**.

<Steps>
  <Step title="Find the binding">
    Search by name, pick a category, or switch between **All Bindings**, **Commands**, and **Semantic Intents**.
  </Step>
  <Step title="Record new keys">
    Click the binding's key field and press the new combination. Press `Escape` to cancel.
  </Step>
  <Step title="Check for conflicts">
    A binding that clashes with another in the same category shows a **Conflict** badge. **Conflicts only** lists just those.
  </Step>
</Steps>

Changed bindings show a **Customized** badge and a **Reset to default** button. **Reset All** restores every default.

<Tip>
  Bindings marked **Readonly** cannot be changed. These include search, save, and zoom, the keys inside code blocks and formulas, and the semantic keys such as `Enter`, `Tab`, and `Backspace`. Changes take effect right away.
</Tip>

## FAQ

<AccordionGroup>
  <Accordion title="Why does a shortcut not work?" icon="question">
    Check whether the editor has focus, whether the current node type supports that action, whether you changed the binding in **Settings → Personal → Keyboard shortcuts**, and whether the operating system intercepted the shortcut first.
  </Accordion>

  <Accordion title="Are shortcuts different on macOS?" icon="question">
    The bindings are the same. Replace `Mod` with `Command` on macOS and `Ctrl` elsewhere, and press `Option` where a shortcut says `Alt`.
  </Accordion>

  <Accordion title="Can I customize everything?" icon="question">
    No. Bindings marked **Readonly** in the settings keep their defaults, and some shortcuts are reserved by the operating system.
  </Accordion>
</AccordionGroup>
