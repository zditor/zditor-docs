В Zditor есть множество сочетаний клавиш для редактирования, форматирования, изменения структуры и навигации. В таблицах ниже перечислены привязки по умолчанию для редактора Markdown и приложения.

<Warning>
  `Mod` — это `Ctrl` в Windows и Linux и `Command` в macOS. `Alt` в macOS — это клавиша `Option`.
</Warning>

## Глобальные сочетания клавиш

### Поиск и сохранение

| Сочетание | Действие |
| --- | --- |
| `Mod-K` | Открыть поиск |
| `Mod-S` | Сохранить текущий документ |
| `Mod-F` | Найти в текущем документе |

### Режимы отображения

Работают в активном документе Markdown. Повторное нажатие того же сочетания возвращает к форматированному тексту.

| Сочетание | Действие |
| --- | --- |
| `Mod-E` | Переключение между режимом редактирования и режимом только для чтения |
| `Mod-/` | Переключение между форматированным и исходным текстом |
| `Mod-\` | Переключение между форматированным текстом и разделённым видом |

### Масштаб

| Сочетание | Действие |
| --- | --- |
| `Mod-=` | Увеличить |
| `Mod--` | Уменьшить |
| `Mod-0` | Сбросить масштаб |

## Действия в редакторе

### Основное

| Сочетание | Действие |
| --- | --- |
| `Mod-A` | Выделить весь документ |
| `Escape` | Убрать фокус из редактора |
| `Shift-Enter` | Перенос строки без начала нового абзаца |

### Отмена и повтор

| Сочетание | Действие |
| --- | --- |
| `Mod-Z` | Отменить |
| `Mod-Y` | Повторить |
| `Mod-Shift-Z` | Повторить (альтернативное сочетание) |
| `Backspace` | Сразу после того, как Zditor преобразовал введённое (например, `## ` в заголовок), — отменить это преобразование |

## Форматирование текста

### Стили

| Сочетание | Действие |
| --- | --- |
| `Mod-B` | Полужирный |
| `Mod-I` | Курсив |
| `Mod-D` | Зачёркнутый |
| `Mod-H` | Выделение цветом |
| `Mod-Shift-C` | Код в строке |
| `Mod-R` | Пометка правки (см. [Пометки в тексте](/ru/text-marks)) |

### Вставка элементов

| Сочетание | Действие |
| --- | --- |
| `Mod-Shift-E` | Вставить строчную формулу |
| `Mod-Shift-D` | Вставить блочную формулу |
| `Mod-Shift-H` | Вставить разделитель (горизонтальную линию) |
| `Mod-P` | Вставить разрыв страницы |
| `Mod-T` | Вставить таблицу 3 × 3 |

<Note>
  Для сочетаний пометки правки и формул нужны плагины **Track changes** и **Math formulas**; по умолчанию они включены в **Settings → Integrations → Plugins**.
</Note>

## Заголовки

| Сочетание | Действие |
| --- | --- |
| `Mod-1` | Заголовок 1 |
| `Mod-2` | Заголовок 2 |
| `Mod-3` | Заголовок 3 |
| `Mod-4` | Заголовок 4 |
| `Mod-5` | Заголовок 5 |
| `Mod-6` | Заголовок 6 |
| `Mod-Shift-P` | Преобразовать в абзац |
| `Backspace` | В начале заголовка — преобразовать его обратно в абзац |

Если нажать сочетание заголовка на заголовке того же уровня, он снова станет абзацем.

## Списки

### Создание списков

| Сочетание | Действие |
| --- | --- |
| `Mod-Shift-8` | Маркированный список |
| `Mod-Shift-7` | Нумерованный список |
| `Mod-Shift-9` | Список с флажками |
| `Mod-Shift-B` | Цитата |

### Пункты списка

| Сочетание | Действие |
| --- | --- |
| `Enter` | Разделить пункт списка |
| `Tab` | Увеличить отступ пункта |
| `Shift-Tab` | Уменьшить отступ пункта |
| `Mod-Shift-Enter` | Начать новый абзац внутри текущего пункта списка или цитаты |
| `Alt-ArrowUp` | Переместить пункт вверх |
| `Alt-ArrowDown` | Переместить пункт вниз |

### Флажки

| Сочетание | Действие |
| --- | --- |
| `Mod-Enter` | Отметить флажок или снять отметку |
| `Enter` | Разделить пункт с флажком |
| `Tab` | Увеличить отступ пункта с флажком |
| `Shift-Tab` | Уменьшить отступ пункта с флажком |

## Блоки кода

### Создание блока кода

| Сочетание | Действие |
| --- | --- |
| `Mod-Shift-\` | Блок кода |

### Редактирование и перемещение

| Сочетание | Действие |
| --- | --- |
| `ArrowUp` | Вверх; на первой строке — выйти из блока кода |
| `ArrowDown` | Вниз; на последней строке — выйти из блока кода |
| `ArrowLeft` | Влево; в начале блока — выйти из него |
| `ArrowRight` | Вправо; в конце блока — выйти из него |
| `Tab` | Увеличить отступ |
| `Shift-Tab` | Уменьшить отступ |
| `Mod-Enter` | Выйти из блока кода и продолжить в новом абзаце ниже |
| `Backspace` | В самом начале блока кода — преобразовать его обратно в абзац |

### Форматирование кода

| Сочетание | Действие |
| --- | --- |
| `Mod-Shift-F` | Отформатировать блок кода |
| `Alt-Shift-F` | Альтернативное сочетание для форматирования кода |

## Формулы

### Внутри формулы

| Сочетание | Действие |
| --- | --- |
| `Tab` | Вставить табуляцию |
| `Enter` | В блочной формуле — новая строка, в строчной — выход из формулы |
| `Mod-Enter` | Выйти из формулы |
| `Backspace` | Удалить пустую формулу |
| `Mod-Backspace` | Удалить формулу и вернуться к тексту |
| `Mod-A` | Выделить всё содержимое формулы |
| `Mod-M` | Переключить строчную и блочную формулу |
| `Mod-P` | Преобразовать формулу в обычный текст |

### Перемещение в формуле

| Сочетание | Действие |
| --- | --- |
| `ArrowLeft` | Влево; в начале формулы — выйти из неё |
| `ArrowRight` | Вправо; в конце формулы — выйти из неё |
| `ArrowUp` | Вверх; на первой строке — выйти из формулы |
| `ArrowDown` | Вниз; на последней строке — выйти из формулы |

Чтобы изменить выбранную блочную формулу, нажмите `Enter`. Подробнее — на странице [Математические формулы](/ru/math-formulas).

## Таблицы

### Перемещение по таблице

| Сочетание | Действие |
| --- | --- |
| `Tab` | Перейти к следующей ячейке; в последней ячейке — добавить строку |
| `Shift-Tab` | Перейти к предыдущей ячейке |

### Редактирование таблицы

| Сочетание | Действие |
| --- | --- |
| `Mod-Enter` | Добавить строку ниже и перейти в неё |
| `Mod-Shift-Enter` | Добавить столбец справа и перейти в него |
| `Mod-Backspace` | Удалить текущую строку |
| `Mod-Shift-Backspace` | Удалить текущий столбец |

## Прочие действия

### Другие элементы

| Сочетание | Действие |
| --- | --- |
| `Mod-Shift-M` | Добавить блок Frontmatter из первого абзаца документа, в котором его ещё нет (см. [Метаданные Frontmatter](/ru/frontmatter)) |
| `Mod-Shift-V` | Блок HTML |

### Меню подсказок

Эти клавиши работают в меню `/`, `@` и `#`.

| Сочетание | Действие |
| --- | --- |
| `ArrowUp` | Вверх по списку |
| `ArrowDown` | Вниз по списку |
| `Tab` / `Shift-Tab` | К следующему или предыдущему пункту |
| `ArrowRight` | Открыть выделенную группу |
| `ArrowLeft` | Вернуться из группы |
| `Enter` | Выбрать выделенный пункт или открыть выделенную группу |
| `Escape` | Вернуться из группы или закрыть меню |
| `Backspace` | Удалить символ и обновить фильтр |

В окне выбора эмодзи, которое открывает `:`, клавиши со стрелками перемещают по сетке, `Enter` вставляет выделенный эмодзи, а `Mod-ArrowLeft` / `Mod-ArrowRight` переключают категорию, пока вы не начали вводить фильтр.

## Настройка сочетаний клавиш

В настольном приложении откройте **Settings → Personal → Keyboard shortcuts**.

<Steps>
  <Step title="Найдите привязку">
    Ищите по названию, выберите категорию или переключайтесь между **All Bindings**, **Commands** и **Semantic Intents**.
  </Step>
  <Step title="Запишите новое сочетание">
    Щёлкните поле с клавишами привязки и нажмите новое сочетание. Чтобы отменить, нажмите `Escape`.
  </Step>
  <Step title="Проверьте конфликты">
    Привязка, которая совпадает с другой в той же категории, помечается значком **Conflict**. Фильтр **Conflicts only** показывает только такие привязки.
  </Step>
</Steps>

У изменённых привязок появляются значок **Customized** и кнопка **Reset to default**. **Reset All** восстанавливает все значения по умолчанию.

<Tip>
  Привязки, отмеченные как **Readonly**, изменить нельзя. К ним относятся поиск, сохранение и масштаб, клавиши внутри блоков кода и формул, а также семантические клавиши, такие как `Enter`, `Tab` и `Backspace`. Изменения вступают в силу сразу.
</Tip>

## Частые вопросы

<AccordionGroup>
  <Accordion title="Почему не срабатывает сочетание клавиш?" icon="question">
    Проверьте, что фокус находится в редакторе, что текущий тип узла поддерживает это действие, не меняли ли вы привязку в **Settings → Personal → Keyboard shortcuts** и не перехватывает ли сочетание операционная система.
  </Accordion>

  <Accordion title="Отличаются ли сочетания в macOS?" icon="question">
    Привязки одинаковые. `Mod` — это `Command` в macOS и `Ctrl` в остальных системах, а там, где в сочетании указан `Alt`, на Mac нажимайте `Option`.
  </Accordion>

  <Accordion title="Можно ли изменить любое сочетание?" icon="question">
    Нет. Привязки, отмеченные в настройках как **Readonly**, сохраняют значения по умолчанию, а некоторые сочетания зарезервированы операционной системой.
  </Accordion>
</AccordionGroup>
