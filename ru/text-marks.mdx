Zditor поддерживает стандартное форматирование в строке — полужирный, курсив, выделение цветом и код в строке, — а также добавляет более богатые пометки для рецензирования: пояснения и правки.

## Основное форматирование

| Пометка | Синтаксис | Где применять |
| --- | --- | --- |
| Полужирный | `**text**` | ключевые выводы и важные термины |
| Курсив | `*text*` | лёгкий акцент, иностранные слова, особые термины |
| Зачёркнутый | `~~text~~` | удалённые или устаревшие формулировки |
| Выделение цветом | `==text==` | важные определения и выводы |
| Код в строке | `` `code` `` | команды, переменные, идентификаторы |
| Ссылка | `[text](url)` | навигация и ссылки на источники |

Эти пометки можно применить и с панели форматирования, которая появляется при выделении текста, или сочетаниями клавиш со страницы [Сочетания клавиш](/ru/keyboard-shortcuts).

<Tip>
  Не перегружайте текст оформлением. Пометки работают лучше всего, когда проясняют структуру, а не спорят за внимание.
</Tip>

## Пометки для рецензирования

<AccordionGroup>
  <Accordion title="Пояснения с mode=tip" icon="lightbulb" defaultOpen>
    Пояснения нужны, когда исходный текст верен, но ему не хватает контекста.

    ```md
    [text](explanation|mode=tip)
    ```

    Расширенная форма:

    ```md
    [term](explanation%20goes%20here|mode=tip|style=teal)
    ```

    Типичные случаи:

    - пояснить технические термины
    - добавить подсказки для читателя
    - дать краткий контекст, не переписывая предложение
  </Accordion>

  <Accordion title="Правки с mode=revision" icon="pen-to-square">
    Правки нужны, когда текущую формулировку следует заменить.

    ```md
    [original text](reason|mode=revision|advice=replacement)
    ```

    Расширенная форма:

    ```md
    [original text](why%20it%20should%20change|mode=revision|style=indigo|advice=replacement%20text)
    ```

    Типичные случаи:

    - исправить опечатки
    - сделать формулировку точнее
    - заменить расплывчатые даты конкретными
  </Accordion>

  <Accordion title="Создание и просмотр пометок в редакторе" icon="mouse-pointer">
    - **Создание пометки**: выделите текст, нажмите **Revision** на панели форматирования и выберите цвет. `Mod-R` добавляет бирюзовую пометку. Новая пометка — это правка без описания и без предлагаемого текста.
    - **Открытие пометки**: нажмите на помеченный текст. На панели пометки показаны **Description** (у пояснения — **Tip Content**) и, для правки, **Suggested Text**.
    - **Изменение**: поменяйте цвет в **Revision Type**, описание и предлагаемый текст, затем нажмите **Save Changes**.
    - Переключатель **Tip / Revision**: меняет режим. При переключении правки в пояснение её предлагаемый текст удаляется.
    - **Accept Revision**: заменяет помеченный текст предлагаемым. У пояснений нет действия «принять».
    - **Delete**: удаляет пометку, но сохраняет текст.

    Если в документе есть пометки, кнопка **Remove All Revisions** в строке заголовка сразу удаляет все пояснения и правки, сохраняя текст. Пояснения подчёркиваются волнистой линией, правки — подчёркиванием из темы документа.
  </Accordion>

  <Accordion title="Когда кодировать пробелы как %20" icon="code">
    Если вы пишете исходный текст Markdown вручную, пробелы внутри скобок `tip` и `revision` нужно кодировать как `%20`. Обычный пробел завершает ссылку, и тогда разметка отображается как обычный текст.

    Это относится к:

    - тексту пояснения
    - значениям `advice`

    При сохранении документа Zditor кодирует их сам. Символы `|`, `(` и `)` внутри этих значений он кодирует как `%7C`, `%28` и `%29`.
  </Accordion>
</AccordionGroup>

<Note>
  Для пояснений и правок нужен плагин **Track changes** в **Settings → Integrations → Plugins**. По умолчанию он включён. Изменение этого параметра вступает в силу после повторного открытия редактора Markdown.
</Note>

## Значения цветов

`style` принимает пять цветов: `red`, `indigo`, `teal`, `yellow` и `green`. Пометка без `style` — бирюзовая. Значения ниже — лишь соглашение: Zditor обрабатывает все цвета одинаково.

| Цвет | Где применять |
| --- | --- |
| `red` | ошибки, удаления, расплывчатые даты, орфография |
| `indigo` | улучшение формулировок, тон, единый стиль |
| `teal` | нейтральные пояснения и общие предложения |
| `yellow` | предупреждения и места, требующие особого внимания |
| `green` | подтверждение или рекомендация оставить как есть |

## Готовые шаблоны

### Шаблон пояснения

```md
This sentence includes a [term](explain%20the%20meaning%20here|mode=tip|style=teal).
```

### Шаблон правки

```md
Please change [the original phrase](explain%20why%20it%20should%20change|mode=revision|style=indigo|advice=the%20revised%20phrase).
```

<Warning>
  Чтобы `revision` предлагала замену, нужно значение `advice`. Без него **Accept Revision** удаляет помеченный текст, поэтому оставляйте `advice` пустым, только если предлагаете удаление.
</Warning>
