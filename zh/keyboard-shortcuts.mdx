Zditor 提供了丰富的快捷键，覆盖编辑、格式化、结构调整和导航。下面的表格列出了 Markdown 编辑器和应用的默认快捷键。

<Warning>
  `Mod` 在 Windows 和 Linux 上对应 `Ctrl`，在 macOS 上对应 `Command`。`Alt` 在 macOS 上对应 `Option` 键。
</Warning>

## 全局快捷键

### 搜索与保存

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-K` | 打开搜索 |
| `Mod-S` | 保存当前文档 |
| `Mod-F` | 在当前文档中查找 |

### 视图模式

以下快捷键作用于当前的 Markdown 文档。再按一次同一快捷键即可回到富文本视图。

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-E` | 在编辑模式和只读模式之间切换 |
| `Mod-/` | 在富文本视图和源码视图之间切换 |
| `Mod-\` | 在富文本视图和分栏视图之间切换 |

### 视图缩放

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-=` | 放大 |
| `Mod--` | 缩小 |
| `Mod-0` | 重置缩放 |

## 编辑器操作

### 基础编辑

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-A` | 全选文档内容 |
| `Escape` | 让编辑器失去焦点 |
| `Shift-Enter` | 插入换行，但不开始新段落 |

### 撤销与重做

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-Z` | 撤销 |
| `Mod-Y` | 重做 |
| `Mod-Shift-Z` | 重做（备用组合键） |
| `Backspace` | 在 Zditor 刚转换完你的输入时（例如把 `## ` 转成标题），撤销这次转换 |

## 文本格式化

### 字体样式

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-B` | 切换粗体 |
| `Mod-I` | 切换斜体 |
| `Mod-D` | 切换删除线 |
| `Mod-H` | 切换高亮 |
| `Mod-Shift-C` | 切换行内代码 |
| `Mod-R` | 切换修订标记（见 [文本标记使用指南](/zh/text-marks)） |

### 插入元素

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-Shift-E` | 插入行内公式 |
| `Mod-Shift-D` | 插入块级公式 |
| `Mod-Shift-H` | 插入分隔线（水平线） |
| `Mod-P` | 插入分页符 |
| `Mod-T` | 插入 3 × 3 表格 |

<Note>
  修订标记和公式的快捷键需要 **修订** 和 **数学公式** 插件，它们在 **设置 → 集成 → 插件** 中默认开启。
</Note>

## 标题设置

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-1` | 设置为 1 级标题 |
| `Mod-2` | 设置为 2 级标题 |
| `Mod-3` | 设置为 3 级标题 |
| `Mod-4` | 设置为 4 级标题 |
| `Mod-5` | 设置为 5 级标题 |
| `Mod-6` | 设置为 6 级标题 |
| `Mod-Shift-P` | 设置为段落 |
| `Backspace` | 在标题开头按退格键转换为段落 |

在同级标题上按对应的标题快捷键，会把它变回段落。

## 列表操作

### 创建列表

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-Shift-8` | 切换无序列表 |
| `Mod-Shift-7` | 切换有序列表 |
| `Mod-Shift-9` | 切换复选框列表 |
| `Mod-Shift-B` | 切换引用块 |

### 列表项操作

| 快捷键 | 功能说明 |
| --- | --- |
| `Enter` | 分割列表项 |
| `Tab` | 缩进列表项 |
| `Shift-Tab` | 取消缩进列表项 |
| `Mod-Shift-Enter` | 在当前列表项或引用块内开始新段落 |
| `Alt-ArrowUp` | 上移列表项 |
| `Alt-ArrowDown` | 下移列表项 |

### 复选框操作

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-Enter` | 切换复选框状态 |
| `Enter` | 分割复选框项 |
| `Tab` | 缩进复选框项 |
| `Shift-Tab` | 取消缩进复选框项 |

## 代码块编辑

### 创建代码块

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-Shift-\` | 切换代码块 |

### 代码块编辑与导航

| 快捷键 | 功能说明 |
| --- | --- |
| `ArrowUp` | 上移；在第一行时退出代码块 |
| `ArrowDown` | 下移；在最后一行时退出代码块 |
| `ArrowLeft` | 左移；在开头时退出代码块 |
| `ArrowRight` | 右移；在末尾时退出代码块 |
| `Tab` | 缩进 |
| `Shift-Tab` | 取消缩进 |
| `Mod-Enter` | 退出代码块，在下方的新段落中继续输入 |
| `Backspace` | 在代码块最开头按下时，把它转换回段落 |

### 代码块格式化

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-Shift-F` | 格式化代码块 |
| `Alt-Shift-F` | 格式化代码块（备用组合键） |

## 数学公式编辑

### 公式内部

| 快捷键 | 功能说明 |
| --- | --- |
| `Tab` | 插入制表符 |
| `Enter` | 在块级公式中换行；在行内公式中退出公式 |
| `Mod-Enter` | 退出公式 |
| `Backspace` | 公式为空时删除它 |
| `Mod-Backspace` | 删除公式并回到正文 |
| `Mod-A` | 全选公式中的内容 |
| `Mod-M` | 在行内公式和块级公式之间切换 |
| `Mod-P` | 把公式转换为纯文本 |

### 公式导航

| 快捷键 | 功能说明 |
| --- | --- |
| `ArrowLeft` | 左移；在开头时退出公式 |
| `ArrowRight` | 右移；在末尾时退出公式 |
| `ArrowUp` | 上移；在第一行时退出公式 |
| `ArrowDown` | 下移；在最后一行时退出公式 |

选中块级公式后，按 `Enter` 即可编辑它。详见 [数学公式使用指南](/zh/math-formulas)。

## 表格操作

### 表格导航

| 快捷键 | 功能说明 |
| --- | --- |
| `Tab` | 移到下一个单元格；在最后一个单元格中按下时添加一行 |
| `Shift-Tab` | 移到上一个单元格 |

### 表格编辑

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-Enter` | 在下方添加一行并移入其中 |
| `Mod-Shift-Enter` | 在右侧添加一列并移入其中 |
| `Mod-Backspace` | 删除当前行 |
| `Mod-Shift-Backspace` | 删除当前列 |

## 其他操作

### 其他元素

| 快捷键 | 功能说明 |
| --- | --- |
| `Mod-Shift-M` | 在还没有 Frontmatter 的文档中，光标位于第一段时添加 Frontmatter 块（见 [Frontmatter 使用指南](/zh/frontmatter)） |
| `Mod-Shift-V` | 切换 HTML 块 |

### 建议菜单

以下按键在 `/`、`@` 和 `#` 菜单中可用。

| 快捷键 | 功能说明 |
| --- | --- |
| `ArrowUp` | 在列表中上移 |
| `ArrowDown` | 在列表中下移 |
| `Tab` / `Shift-Tab` | 移到下一项或上一项 |
| `ArrowRight` | 打开高亮的分组 |
| `ArrowLeft` | 从分组返回 |
| `Enter` | 选择高亮的项目，或打开高亮的分组 |
| `Escape` | 从分组返回，或关闭菜单 |
| `Backspace` | 删除一个字符并更新过滤结果 |

在 `:` 打开的表情选择器中，方向键在网格中移动，`Enter` 插入高亮的表情；在输入过滤词之前，`Mod-ArrowLeft` / `Mod-ArrowRight` 可以切换分类。

## 快捷键自定义

在桌面版中，打开 **设置 → 个人 → 键盘快捷键**。

<Steps>
  <Step title="找到绑定">
    按名称搜索、选择分类，或在 **全部绑定**、**命令** 和 **语义键** 之间切换。
  </Step>
  <Step title="录制新按键">
    点击绑定的按键框，按下新的组合键。按 `Escape` 取消。
  </Step>
  <Step title="检查冲突">
    与同一分类中其他绑定冲突的绑定会显示 **冲突** 标记。**只看冲突项** 只列出这些绑定。
  </Step>
</Steps>

修改过的绑定会显示 **已自定义** 标记和 **重置为默认值** 按钮。**全部重置** 会恢复所有默认设置。

<Tip>
  标有 **只读** 的绑定无法修改，包括搜索、保存和缩放，代码块和公式内部的按键，以及 `Enter`、`Tab`、`Backspace` 等语义键。修改会立即生效。
</Tip>

## 常见问题

<AccordionGroup>
  <Accordion title="快捷键不工作怎么办？" icon="question">
    请检查编辑器是否获得了焦点、当前节点类型是否支持该操作、你是否在 **设置 → 个人 → 键盘快捷键** 中修改过这个绑定，以及操作系统是否先拦截了这个快捷键。
  </Accordion>

  <Accordion title="macOS 上的快捷键有区别吗？" icon="question">
    绑定是一样的。在 macOS 上把 `Mod` 换成 `Command`，在其他系统上换成 `Ctrl`；快捷键中写作 `Alt` 的地方，在 macOS 上按 `Option`。
  </Accordion>

  <Accordion title="所有快捷键都能自定义吗？" icon="question">
    不能。设置中标有 **只读** 的绑定会保持默认值，另外有些快捷键被操作系统保留。
  </Accordion>
</AccordionGroup>
