사이드바의 파일 트리는 Zditor의 핵심 요소 중 하나입니다. 현재 작업 공간 안의 파일을 바로 탐색하고, 만들고, 이름을 바꾸고, 옮기고, 정리할 수 있습니다.

## 화면 구성

파일 트리는 사이드바의 **Files** 패널입니다. 왼쪽 탐색 막대 맨 위의 폴더 아이콘을 클릭하면 표시됩니다. 필터가 켜져 있지 않으면 이름이 점으로 시작하는 항목을 포함해 작업 공간의 모든 파일과 폴더가 표시됩니다.

### 상단 도구 모음

파일 트리 맨 위에는 현재 작업 공간의 이름이 표시됩니다. 이름을 클릭하면 작업 공간을 전환할 수 있습니다([작업 공간 관리](#작업-공간-관리) 참고). 그 옆에는 버튼이 세 개 있습니다.

- **New File**: 작업 공간 루트에 파일을 만듭니다
- **New Folder**: 작업 공간 루트에 폴더를 만듭니다
- **More**: 다음 항목이 있는 메뉴를 엽니다
  - **Filter**: 특정 파일 형식만 표시
  - **Refresh**: 작업 공간 다시 스캔
  - **Collapse**: 펼쳐진 폴더를 모두 접기
  - **Clear clipboard**: 대기 중인 복사나 잘라내기 취소(무언가를 복사하거나 잘라 둔 동안에만 표시)
  - **Open Folder**: 시스템 파일 관리자에서 작업 공간 열기

트리를 불러오거나 새로 고치거나 파일을 가져오는 동안에는 도구 모음 아래에 얇은 진행 표시줄이 나타납니다.

### 파일 목록

기본 목록에는 현재 계층 구조를 반영해 들여쓴 파일과 폴더가 표시됩니다. 항목 위에 마우스를 올리면 전체 경로를 볼 수 있습니다.

### 하단 막대

패널 맨 아래의 막대는 세 부분으로 나뉩니다.

- 왼쪽의 **+** 버튼은 작업 공간 루트에 `untitled1.md`(또는 다음으로 비어 있는 번호)라는 빈 Markdown 파일을 만들고 엽니다.
- 가운데의 작업 공간 이름을 클릭하면 시스템 폴더 선택기가 열려 다른 로컬 폴더로 전환할 수 있습니다.
- 오른쪽의 **⋮** 버튼은 정렬 옵션, 최근 폴더, 설정해 둔 원격 작업 공간이 있는 패널을 엽니다.

    - 목록 아래의 빈 영역을 오른쪽 클릭하면 작업 공간 루트 메뉴가 열립니다
  </Accordion>

### 항목 선택

파일이나 폴더를 클릭하면 선택됩니다. 선택한 항목은 강조 표시됩니다.

### 이름 바꾸기

<AccordionGroup>
  <Accordion title="이름 바꾸는 방법" icon="pen">
    1. 파일이나 폴더를 오른쪽 클릭하고 **Rename**을 선택합니다
    2. 또는 항목 위에 마우스를 올리고 **…** 버튼을 클릭한 다음 **Rename**을 선택합니다
    3. `Enter`를 눌러 확정하거나 `Esc`를 눌러 취소합니다. 다른 곳을 클릭해도 새 이름이 확정됩니다.
  </Accordion>
</AccordionGroup>

<Tip>
  파일 이름을 바꿀 때는 확장자 앞부분만 선택되므로, 새 이름을 입력해도 확장자는 그대로 유지됩니다.
</Tip>

## 파일과 폴더 관리

### 파일과 폴더 만들기

<AccordionGroup>
  <Accordion icon="plus" title="방법 1: 상단 도구 모음">
    도구 모음에서 **New File** 또는 **New Folder**를 클릭하면 작업 공간 루트에 항목이 만들어집니다.
  </Accordion>

  <Accordion icon="folder-plus" title="방법 2: 마우스를 올리면 나타나는 버튼">
    폴더 위에 마우스를 올리면 빠른 작업 버튼이 나타납니다.

    - `+`: 해당 폴더 안에 새 파일을 만듭니다
    - 폴더 아이콘: 하위 폴더를 만듭니다
  </Accordion>

  <Accordion icon="computer-mouse" title="방법 3: 오른쪽 클릭 메뉴">
    대상 폴더를 오른쪽 클릭하거나, 작업 공간 루트라면 목록 아래의 빈 영역을 오른쪽 클릭한 다음 **New File** 또는 **New Folder**를 선택하세요.
  </Accordion>
</AccordionGroup>

파일을 만들면 Zditor가 이름 입력란과 그 뒤에 확장자 입력란을 표시합니다. 확장자는 기본 확장자(바꾸지 않았다면 `.md`)로 시작합니다.

- `↑` 또는 `↓`를 누르면 목록의 다른 확장자로 전환됩니다
- `notes.txt`처럼 이름 끝에 목록에 있는 확장자를 입력하면 그 확장자로 전환됩니다
- 이름 끝에서 `→`를 누르면 확장자 입력란으로 이동합니다

기본 확장자와 확장자 목록은 **Settings → Personal → General → File types**에서 바꿀 수 있습니다.

### 파일과 폴더 삭제

1. 대상 파일이나 폴더를 오른쪽 클릭합니다
2. **Delete**를 선택합니다

파일이 탭에 열려 있거나 폴더 안의 항목이 탭에 열려 있으면, Zditor가 먼저 그 탭을 닫고 삭제할지 묻습니다. 그렇지 않으면 항목이 바로 삭제됩니다.

<Warning>
  삭제한 항목은 시스템 휴지통으로 이동하지 않으며 되돌릴 수 없습니다. 파일이나 폴더를 지우기 전에 꼼꼼히 확인하세요.
</Warning>

### 복사, 잘라내기, 붙여넣기

<AccordionGroup>
  <Accordion icon="copy" title="복사">
    1. 파일이나 폴더를 오른쪽 클릭하고 **Copy**를 선택합니다
    2. 항목에 노란색 윤곽선과 **Copy** 레이블이 표시됩니다
  </Accordion>

  <Accordion icon="scissors" title="잘라내기">
    1. 파일이나 폴더를 오른쪽 클릭하고 **Cut**을 선택합니다
    2. 항목에 청록색 윤곽선과 **Cut** 레이블이 표시됩니다
  </Accordion>

  <Accordion icon="paste" title="붙여넣기">
    1. 대상 폴더를 오른쪽 클릭합니다. 작업 공간 루트라면 목록 아래의 빈 영역을 오른쪽 클릭합니다
    2. **Paste**를 선택합니다
    3. 항목이 그 위치로 복사되거나 이동합니다
  </Accordion>
</AccordionGroup>

<Tip>
  클립보드에는 한 번에 하나의 항목만 담기며, 붙여 넣은 뒤에는 비워집니다. 항목을 자기 자신 안에 붙여 넣거나, 자신의 하위 폴더로 옮기거나, 같은 이름의 항목이 이미 있는 폴더에 붙여 넣을 수는 없습니다.
</Tip>

## 정렬과 필터

### 파일 형식 필터

특정 파일 형식만 표시하려면 상단 도구 모음에서 **More → Filter**를 여세요.

| 필터 | 표시 대상 |
| --- | --- |
| **All** | 모든 파일과 폴더 |
| **Markdown** | `.md`, `.mdx`, `.markdown` |
| **Documents** | `.pdf`, `.doc`, `.docx`, `.txt`, `.csv`, `.xls`, `.xlsx`, `.ppt`, `.pptx` |
| **Assets** | 이미지, 동영상, 오디오 파일 |
| **Code** | `.ts`, `.js`, `.py`, `.json`, `.yaml`, `.html`, `.css` 같은 소스, 웹, 구성 파일 |
| **Excalidraw** | 캔버스 파일(`.excalidraw`) |
| **Hidden** | 이름이 점으로 시작하는 파일과 폴더 |
| **Other** | 위 범주 어디에도 해당하지 않는 파일 |

여러 필터를 동시에 켤 수 있습니다. **All**을 선택하면 다른 필터는 꺼집니다. 필터가 켜져 있는 동안에는 **Filter** 항목에 선택한 형식의 수가 표시되고, **More** 버튼에 점이 표시됩니다.

폴더는 그 안의 일치하는 파일에 접근할 수 있도록 항상 목록에 남아 있습니다. 필터가 켜져 있으면, 선택한 필터에 **Hidden**이 없는 한 이름이 점으로 시작하는 항목은 숨겨집니다.

### 정렬 옵션

하단 막대의 **⋮** 버튼을 클릭하세요. 정렬 버튼은 패널 맨 위에 있습니다.

#### 정렬 기준

- **Sort alphabetically**: 이름순으로 정렬합니다
- **Sort by creation time**: 파일을 만든 시간순으로 정렬합니다
- **Sort by modification time**: 파일을 마지막으로 수정한 시간순으로 정렬합니다

#### 정렬 방향

- 화살표 버튼으로 **Sort ascending**과 **Sort descending**을 전환합니다

#### 폴더 묶기

- **Group by folder**: 폴더를 파일보다 위에 둡니다

기본적으로 트리는 이름의 알파벳 오름차순으로 정렬되며, 폴더가 먼저 묶여 표시됩니다. 이름이 점으로 시작하는 항목은 다른 항목보다 앞에 나열됩니다.

## 드래그 앤 드롭

파일 트리에서는 드래그 앤 드롭으로 파일을 관리할 수 있습니다.

<AccordionGroup>
  <Accordion icon="file-import" title="파일이나 폴더 이동">
    1. 대상 파일이나 폴더를 드래그합니다
    2. 옮길 폴더 위로 가져갑니다
    3. 마우스 버튼을 놓으면 이동이 완료됩니다
  </Accordion>

  <Accordion icon="upload" title="외부 파일 가져오기">
    시스템 파일 관리자에서 파일이나 폴더를 트리의 폴더 위에, 또는 작업 공간 루트라면 빈 영역에 드래그하면 작업 공간으로 복사됩니다. 놓은 파일은 그 폴더에 있는 같은 이름의 파일을 대체합니다. 트리 맨 아래에 추가된 파일 수를 알려 주는 짧은 상태 줄이 표시됩니다.
  </Accordion>

  <Accordion icon="home" title="루트에 놓기">
    항목을 트리의 빈 영역에 놓으면 작업 공간 루트로 이동합니다.
  </Accordion>
</AccordionGroup>

<Tip>
  드래그하는 동안 대상 폴더가 강조 표시됩니다. 닫힌 폴더 위에 약 600ms 동안 머무르면 폴더가 자동으로 펼쳐집니다. 목록의 위쪽이나 아래쪽 가장자리 근처로 드래그하면 목록이 스크롤됩니다.
</Tip>

## 컨텍스트 메뉴

파일과 폴더에는 다양한 컨텍스트 메뉴가 있습니다. 항목 위에 마우스를 올리면 나타나는 **…** 버튼으로도 같은 메뉴를 열 수 있습니다.

### 파일 컨텍스트 메뉴

| 항목 | 기능 |
| --- | --- |
| **Open** | 왼쪽 창에서 파일 열기 |
| **Open in Right Split** | 오른쪽 창에서 파일 열기 |
| **Rename** | 파일 이름 바꾸기 |
| **Copy** | 파일을 클립보드에 복사 |
| **Cut** | 파일을 클립보드로 잘라내기 |
| **Paste** | 파일에서는 쓸 수 없습니다. 폴더나 작업 공간 루트에 붙여 넣으세요 |
| **Open in Folder** | 시스템 파일 관리자에서 파일 위치 표시 |
| **Copy File Path** | 파일의 전체 경로를 클립보드에 복사 |
| **Save As** | 이 컴퓨터에서 선택한 위치에 파일 사본 저장 |
| **Delete** | 파일 삭제 |

### 폴더 컨텍스트 메뉴

폴더 메뉴에는 **Rename**, **Copy**, **Cut**, **Paste**, **Open in Folder**, **Copy File Path**, **Delete** 외에 다음 항목이 있습니다.

| 항목 | 기능 |
| --- | --- |
| **New File** | 해당 폴더에 파일 만들기 |
| **New Folder** | 하위 폴더 만들기 |

### 루트 컨텍스트 메뉴

파일 트리의 빈 영역을 오른쪽 클릭하면 작업 공간 루트 메뉴가 열립니다.

- **New File**과 **New Folder**: 루트에 항목 만들기
- **Paste**: 복사하거나 잘라 둔 항목을 루트에 붙여넣기
- **Refresh**: 작업 공간 다시 스캔
- **Collapse All**: 펼쳐진 폴더 접기
- **Open in Folder**: 시스템 파일 관리자에서 작업 공간 열기
- **Copy File Path**: 작업 공간 경로 복사

## 작업 공간 관리

작업 공간은 트리에 파일이 표시되는 폴더입니다. 빈 탭에서 **Open Workspace**를 선택해 기존 폴더를 열거나, **New Workspace**를 선택해 빈 폴더를 만들고 열 수도 있습니다.

### 작업 공간 전환

1. 파일 트리 맨 위의 작업 공간 이름을 클릭합니다
2. 메뉴에서 작업 공간을 고르거나, **Open Directory**를 선택해 시스템 폴더 선택기에서 폴더를 고릅니다
3. Zditor가 새 작업 공간을 불러옵니다

Agent 탭이 열려 있으면 현재 작업 공간과의 연결이 끊기므로 Zditor가 전환할지 확인합니다. 탭과 세션 기록은 유지되며, 그 작업 공간으로 돌아오면 다시 연결됩니다.

<Tip>
  작업 공간마다 별도의 창을 쓸 수 있습니다. **Open Folder in New Window…**를 선택하거나 메뉴에서 작업 공간을 `Cmd`-클릭(Windows와 Linux에서는 `Ctrl`-클릭)하면 새 창에서 열립니다. 이미 다른 창에 열려 있는 작업 공간을 선택하면 그 창이 앞으로 나옵니다.
</Tip>

### 원격 작업 공간

작업 공간이 꼭 이 컴퓨터에 있어야 하는 것은 아닙니다. **Settings → Integrations → Connections**에서 연결을 추가하세요.

- **S3** 스토리지, **WebDAV** 서버, **SSH** 호스트의 폴더는 작업 공간 메뉴와 **⋮** 패널에 각각 별도의 그룹으로 표시됩니다.
- **Git** 연결은 저장소의 로컬 클론을 유지하며, 다른 폴더처럼 엽니다.

S3, WebDAV, SSH 작업 공간에서는 **Open in Folder**를 쓸 수 없으며, 서버에서 파일이 바뀌어도 트리가 저절로 새로 고쳐지지 않습니다. 최신 파일을 보려면 **Refresh**를 사용하세요.

### 최근 폴더

작업 공간 메뉴에 최근 로컬 폴더가 나열됩니다. 하단 막대의 **⋮** 패널에도 나열되며, 여기서 목록을 관리할 수 있습니다.

<AccordionGroup>
  <Accordion icon="thumbtack" title="폴더 고정">
    고정 아이콘을 클릭하면 중요한 폴더를 최근 목록 맨 위에 둘 수 있습니다.
  </Accordion>

  <Accordion icon="trash" title="최근 항목 제거">
    고정하지 않은 폴더는 휴지통 아이콘을 클릭해 최근 목록에서 제거할 수 있습니다.
  </Accordion>
</AccordionGroup>

목록에는 폴더가 최대 5개까지 남으며, 고정한 폴더는 항상 목록에 있습니다. Zditor는 시작할 때 마지막으로 사용한 작업 공간을 다시 엽니다. 작업 공간 없이 시작하려면 **Settings → Personal → General**에서 **Reopen previous workspace**를 끄세요.

### 자동 새로 고침

로컬 작업 공간에서는 파일 트리가 작업 공간 루트와 펼쳐진 모든 폴더를 감시합니다.

- Zditor에서든 다른 앱에서든 파일을 만들거나 삭제하거나 이름을 바꾸면 트리가 업데이트됩니다
- 다시 펼친 폴더는 새로 스캔되므로, 접혀 있는 동안 생긴 변경 사항도 나타납니다

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="트리에 일부 파일이 보이지 않는 이유는 무엇인가요?" icon="question">
    파일 형식 필터가 켜져 있는지 확인하세요. 필터가 켜져 있으면 **More** 버튼에 점이 표시됩니다. **More → Filter**를 다시 **All**로 설정하세요. 다른 필터가 켜져 있는 동안에는 **Hidden**도 함께 선택하지 않는 한 이름이 점으로 시작하는 파일과 폴더가 숨겨집니다.
  </Accordion>

  <Accordion title="드래그가 되지 않는 이유는 무엇인가요?" icon="question">
    닫힌 폴더는 펼쳐질 때까지 충분히 오래 마우스를 올려 두세요. 항목을 자기 자신, 자신의 하위 폴더, 이미 들어 있는 폴더로는 옮길 수 없으며, 대상 폴더에 같은 이름의 항목이 이미 있으면 이동이 거부됩니다.
  </Accordion>

  <Accordion title="최근에 바뀐 파일을 빠르게 찾으려면 어떻게 하나요?" icon="question">
    **⋮** 패널에서 **Sort by modification time**을 선택하고 방향을 내림차순으로 설정하세요.
  </Accordion>

  <Accordion title="여러 파일을 한꺼번에 열 수 있나요?" icon="question">
    네. 파일을 클릭하면 각각 별도의 탭에서 열립니다. 두 파일을 나란히 보려면 **Open in Right Split**을 사용하세요.
  </Accordion>

  <Accordion title="Open in Folder를 쓸 수 없는 이유는 무엇인가요?" icon="question">
    S3, WebDAV, SSH 작업 공간은 이 컴퓨터에 있지 않으므로 시스템 파일 관리자에서 보여 줄 로컬 폴더가 없습니다.
  </Accordion>
</AccordionGroup>
