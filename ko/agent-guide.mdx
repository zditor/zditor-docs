Zditor에는 에이전트가 내장되어 있습니다. 에이전트는 작업 공간의 파일로 일합니다. 노트를 읽고 편집하고, PDF에 주석을 달고, 캔버스를 만들고, 명령을 실행하며, Zditor 자체를 조작할 수도 있습니다. 에이전트가 쓸 AI 서비스는 Zditor 계정을 통한 Zditor AI와 직접 지정한 제공자 중에서 고를 수 있으며, 묻지 않고 해도 되는 작업도 직접 정합니다.

<Warning>
  에이전트는 파일을 변경하고, 명령을 실행하고, Mac에서는 다른 앱을 조작할 수 있습니다. 승인하기 전에 각 요청을 읽어 보고, 믿을 수 있는 작업이 아니라면 **Always ask**(항상 확인) 권한 모드를 유지하세요.
</Warning>

큰 작업의 일부를 병렬로 일하는 하위 에이전트에게 맡기고, 결정이 필요하면 사용자에게 질문하며, HTML 페이지, 이미지, 동영상처럼 직접 만든 결과물을 Zditor 탭에서 열 수도 있습니다.

<Note>
  iPhone과 iPad, 그리고 원격 작업 공간(SSH, S3, WebDAV, Git)에서는 에이전트가 Zditor를 통해 파일을 읽고 쓸 수 있지만, 터미널 명령을 실행하거나 다른 앱을 조작할 수는 없습니다. 원격 작업 공간에서는 Git도 사용할 수 없습니다.
</Note>

## AI 서비스 설정

에이전트가 일하려면 먼저 AI 서비스가 필요합니다. **Settings → AI → Agents**를 열고 **Provider**에서 **AI service**를 **Zditor** 또는 **Custom provider**로 설정하세요.

<Tabs>
<Tab title="Zditor AI">
  Zditor AI는 API 키가 필요 없습니다. Zditor 계정에 로그인되어 있고, 매월 AI 사용 한도가 포함된 Pro나 무료 AI 토큰이 계정에 있으면 사용할 수 있습니다. 무료 토큰은 Claude Haiku 5.5에서 사용됩니다.

  1. **Settings → AI → Agents**를 엽니다.
  2. 로그인하지 않았다면 **Sign in**을 클릭하고 브라우저에서 로그인을 마칩니다.
  3. **AI service**를 **Zditor**로 설정합니다.

  Zditor는 시작할 때마다 사용 가능한 모델과 그 설정을 불러옵니다. **Service configuration** 아래의 **Update**를 누르면 바로 불러옵니다. 사용량은 **Settings → Personal → Account**의 **AI usage**에 표시됩니다.
</Tab>

<Tab title="Custom provider">
  OpenAI Responses API 또는 Claude Messages(Anthropic) API를 지원하는 서비스를 연결하세요. 내 컴퓨터에서 실행되는 서비스도 연결할 수 있습니다.

  <Steps>
    <Step title="프로토콜 선택">
      **AI service**를 **Custom provider**로 설정한 다음, 서비스가 지원하는 **API protocol**을 고르세요. **OpenAI Responses** 또는 **Claude Messages (Anthropic)** 중 하나입니다.
    </Step>

    <Step title="주소와 키 입력">
      서비스 API의 루트 주소인 **Base URL**을 입력하세요. 보통 `/v1`로 끝납니다(예: `https://api.openai.com/v1` 또는 `https://api.anthropic.com/v1`). 그런 다음 **API key**를 입력하세요. 로컬 제공자는 키가 필요 없을 수도 있습니다. 키는 이 기기에 저장되며 이 주소로만 전송됩니다.
    </Step>

    <Step title="모델 추가">
      **Model and generation**에서 **Fetch models**를 클릭하세요. 제공자의 모델이 **Not enabled** 상태로 표시됩니다. 사용할 모델을 하나씩 열고 **Enable** 스위치를 켜세요. 제공자 목록에 없는 모델을 추가하려면 **Add model**에 모델 ID를 입력하고 Enter 키를 누르세요. 이렇게 추가한 모델은 활성화된 상태가 됩니다.
    </Step>

    <Step title="토큰 한도 확인">
      활성화한 모델마다 **Context window tokens**와 **Maximum output tokens**가 필요합니다. 제공자가 이 값을 알려 주면 Zditor가 채워 넣습니다(**Server-reported**). 그렇지 않으면 **Enter manually**를 선택하고 제공자 문서에 나온 수치를 입력하세요.
    </Step>

    <Step title="저장">
      **Save**를 클릭하세요. **Test connection**은 모델 목록을 가져와 주소와 키를 확인합니다.
    </Step>
  </Steps>
</Tab>
</Tabs>

### 모델 설정

**Model and generation**에서 모델을 열어 설정을 조정하세요. Zditor AI에서는 이 설정을 볼 수만 있고 바꿀 수는 없습니다.

| 설정 | 기능 |
| :--- | :--- |
| **Reasoning effort** | 모델이 답하기 전에 얼마나 추론할지 정합니다. **Automatic**은 모델의 기본값을 쓰며, 수준이 높을수록 시간과 토큰이 더 듭니다. |
| **Temperature** | 값이 낮을수록 예측 가능한 답이, 높을수록 다양한 답이 나옵니다. 서비스가 정하게 하려면 비워 두세요. |
| **Context window tokens**, **Maximum output tokens** | 서비스가 알려 주거나 직접 입력한 모델의 한도. |
| **Automatic compaction threshold** | 대화가 이 토큰 수에 도달하면 Zditor가 앞선 컨텍스트를 요약해 공간을 확보합니다. 기본값은 컨텍스트 창의 90%입니다. |

대화 화면 위쪽의 모델 메뉴(**Model and reasoning effort**)에는 활성화한 모델과 추론 강도가 나열됩니다. 대화 중에도 모델을 바꿀 수 있으며, 새 대화는 마지막으로 고른 모델로 시작합니다.

## 대화 시작

### Agent 탭에서

탭 표시줄의 **+**를 클릭해 새 탭을 여세요. 새 탭은 Agent 탭입니다. 에이전트는 Zditor에 열린 작업 공간에서 일하므로 먼저 작업 공간을 여세요. 빈 Agent 탭에서 **Open Workspace**와 **New Workspace**를 쓸 수 있습니다. 작업 공간이 없으면 에이전트는 Zditor 앱 데이터 안의 임시 폴더에서 일합니다.

### 문서 옆에서

Markdown 노트의 제목 표시줄에서 **Document sidebar**를 클릭하고 **Chat** 탭을 선택하세요. 노트가 첨부된 상태로 채팅이 시작되므로 바로 노트에 대해 물어볼 수 있습니다. 캔버스의 사이드바에도 같은 **Chat** 탭이 있습니다.

노트의 일부에 대해 물어보려면 그 부분을 선택하고 선택 도구 모음의 반짝이 버튼(**ASK AI**)을 클릭하세요. 선택한 내용이 첨부된 상태로 **Chat** 탭이 열립니다. **Settings → AI → AI Toolbar Prompts**에서 설정한 프롬프트는 도구 모음에 추가 버튼으로 나타나며, 누르면 선택한 내용과 함께 해당 지침을 바로 보냅니다.

<Note>
  문서 사이드바의 채팅은 임시이며 대화 기록에 저장되지 않습니다. 남겨 두고 싶은 작업에는 Agent 탭을 사용하세요.
</Note>

### 요청 작성

메시지 입력란에 입력하고 **Send message**를 클릭하세요. 에이전트가 일하는 동안 **Stop current turn**으로 멈출 수 있으며, 그 사이에 보낸 메시지는 현재 턴이 끝날 때까지 대기열에서 기다립니다.

- 명령을 실행하려면 `/`를 입력하세요(아래 표 참고).
- 작업 공간의 파일을 첨부하려면 `@`를 입력하세요.
- 스킬을 사용하려면 `$`를 입력하세요.
- 파일을 첨부하려면 **Upload file**(클립 아이콘)을 클릭하거나 파일을 메시지 입력란으로 드래그하세요. 이미지, 오디오, 텍스트 파일은 메시지에 포함되고, PDF나 Office 문서 같은 다른 파일은 경로로 전달되어 에이전트가 직접 엽니다.

iPhone과 iPad에서는 메시지 입력란 아래의 **Commands**, **Files**, **Skills** 버튼으로 `/`, `@`, `$`와 같은 목록을 열 수 있습니다.

AI 서비스에 처음 메시지를 보내면 Zditor가 데이터 공유 허가를 요청합니다. 아래의 개인정보 보호 섹션을 참고하세요.

### 명령

| 명령 | 기능 |
| :--- | :--- |
| `/goal` | 대화에 목표를 지정합니다. 에이전트는 목표를 달성하거나 막힐 때까지 턴을 이어 가며 계속 작업합니다. `/goal` 뒤에 목표를 입력하면 설정되고, `/goal`만 입력하면 현재 목표를 볼 수 있으며, `/goal edit`, `/goal pause`, `/goal resume`, `/goal clear`도 쓸 수 있습니다. 임시 채팅에서는 쓸 수 없습니다. |
| `/side` | 현재 컨텍스트에서 시작하는 임시 사이드 대화를 엽니다. 명령 뒤에 질문을 덧붙일 수 있습니다. |
| `/compact` | 지금까지의 대화를 요약해 컨텍스트 공간을 확보하되, 핵심 정보는 유지합니다. |
| `/export` | 대화를 Markdown으로 저장합니다. `/export json`을 쓰면 JSON으로 저장합니다. |
| `/share` | 대화를 PNG 이미지로 저장합니다. |

<Tip>
  목표가 활성화되어 있으면 새 메시지를 보내지 않아도 에이전트가 계속 작업하며, 턴마다 토큰이 사용됩니다. 멈추고 싶을 때는 목표를 일시 정지하거나 지우세요.
</Tip>

### 작업 중 화면

에이전트는 작업 과정을 그대로 보여 줍니다. 읽고 편집하는 파일, 실행하는 명령, 그리고 답변이 표시됩니다. 턴이 끝나면 각 단계가 **Work details** 안으로 접히며, 펼쳐서 볼 수 있습니다.

- 파일을 변경한 턴이 끝나면 **Changed 2 files** 같은 카드에 변경된 파일이 나열됩니다. 파일을 펼치면 무엇이 바뀌었는지 볼 수 있습니다. 로컬 작업 공간에서는 **Undo**로 그 턴의 텍스트 변경을 되돌릴 수 있습니다. 그 뒤로 파일이 바뀌었다면 아무것도 되돌리지 않습니다.
- 메시지 입력란 아래의 **Usage**는 대화가 모델의 컨텍스트 창을 얼마나 쓰고 있는지 보여 줍니다. Zditor는 모델의 압축 임계값에 도달하면 앞선 컨텍스트를 자동으로 압축하며, `/compact`로 원할 때 압축할 수도 있습니다.
- Agent 탭에서 메시지의 **More** 메뉴를 열고 **Branch in new chat**을 선택하면 그 지점부터 새 대화로 이어 갈 수 있습니다. 원래 대화는 그대로 남습니다.
- 작업 공간에 `AGENTS.md` 파일이 있으면 에이전트가 이를 프로젝트 지침으로 따릅니다.

## 권한과 승인

메시지 입력란 아래에서 **Permission mode**를 고르세요. Zditor는 선택한 모드를 기억합니다.

| 모드 | 동작 |
| :--- | :--- |
| **Always ask** | 에이전트가 제한된 작업을 할 때마다 먼저 묻습니다. 기본값입니다. |
| **AI review**(AI 검토) | 사용 중인 모델에 별도 요청을 보내 제한된 작업이 사용자의 작업에 맞는지 검사하고 허용하거나 거부합니다. 확실하지 않으면 거부합니다. 사용자에게는 묻지 않으며, 검사할 때마다 모델 요청이 하나씩 추가됩니다. |
| **Full Access**(전체 접근) | 모든 도구 작업을 묻지 않고 실행합니다. |

**Always ask** 모드에서 에이전트는 명령을 실행하거나(데스크톱에서는 파일을 읽기만 하는 명령도 포함), 파일을 편집하거나, Git을 사용하거나, 웹 요청을 보내거나, Zditor의 탭이나 설정을 바꾸거나, PDF에 주석을 달거나, 캔버스를 편집하거나, MCP 도구를 호출하거나, 앱을 열거나 앱 안에서 클릭, 입력, 스크롤하기 전에 먼저 묻습니다. PDF와 캔버스 읽기, 열린 탭 확인, 스크린샷 찍기는 승인이 필요하지 않습니다.

에이전트가 물을 때는 요청에 해당 작업과 세 가지 선택지가 표시됩니다.

- **Allow once**: 이번 작업만 실행합니다.
- **Always allow**: 작업을 실행하고, 같은 명령이나 같은 파일에 대한 추가 편집처럼 같은 작업은 대화가 끝날 때까지 묻지 않고 허용합니다. 다른 작업은 계속 묻습니다.
- **Reject**: 작업을 실행하지 않으며, 사용자가 거절했다는 사실이 에이전트에게 전달됩니다.

<Tip>
  데스크톱 작업에는 명령이 많이 따르는 경우가 많습니다. 하나하나 승인하기가 번거롭다면 **AI review**가 절충안이 될 수 있습니다. **Full Access**는 버전 관리 중인 작업 공간처럼 복원할 수 있는 곳에서만 사용하세요.
</Tip>

## Mac에서 컴퓨터 사용

Mac의 로컬 작업 공간에서는 작업에 필요할 때 에이전트가 다른 앱을 조작할 수 있습니다. 스크린샷과 손쉬운 사용 정보로 앱 창을 살펴보고, 앱을 열고, 클릭하고, 입력하고, 스크롤하고, 키를 누를 수 있습니다.

- 처음에는 macOS가 Zditor에 **Screen Recording**(화면 기록)과 **Accessibility**(손쉬운 사용) 권한을 달라고 요청합니다. 둘 중 하나라도 없으면 대화의 컴퓨터 사용 단계에 "macOS is blocking computer use:"라는 문구와 함께 빠진 권한별로 **Open Accessibility** 또는 **Open Screen Recording** 버튼이 표시되며, 버튼을 누르면 시스템 설정의 해당 페이지가 열립니다. 두 권한은 그곳에서 언제든 끌 수 있습니다.
- **Always ask** 모드에서는 앱 열기, 클릭, 입력, 스크롤, 키 누르기에 승인이 필요하지만 스크린샷은 필요하지 않습니다. 이 중 하나에 **Always allow**를 선택하면 그 대화에서 같은 종류의 다른 작업에도 적용됩니다.
- 에이전트가 작업하는 동안 패널에 에이전트가 조작 중인 앱이 표시됩니다. 패널을 닫았다면 **Show computer use window**(메시지 입력란 아래의 모니터 버튼)로 다시 열 수 있습니다.

## MCP 서버와 스킬

### MCP 서버

MCP 서버는 에이전트를 이슈 트래커나 데이터베이스 같은 다른 앱 및 서비스와 연결합니다. **Settings → AI → MCP Servers**에서 추가하세요. 켜져 있는 서버는 모든 에이전트 대화에서 쓸 수 있습니다. [MCP 가이드](/ko/mcp-guide)를 참고하세요.

### 스킬

스킬은 특정 종류의 작업을 위한 지침을 글로 적은 것으로, `SKILL.md` 파일에 보관됩니다. 에이전트는 모든 스킬의 이름과 설명을 알고 있으며, 작업이 스킬과 맞으면 전체 지침을 읽습니다. 스킬을 직접 골라 쓰려면 메시지 입력란에 `$`를 입력하고 스킬을 선택하세요.

- **내장 스킬.** **Canvas**, **Markdown**, **Settings and tabs**는 Zditor에 기본으로 들어 있습니다. **Settings → AI → Skills**의 **Installed skills**에 나열됩니다.
- **직접 만든 스킬.** **Settings → AI → Skills**에서 **Add skill**을 클릭하고 **Name**(문자, 숫자, 하이픈, 밑줄), **Description**(스킬의 용도), **Skill instructions (Markdown)**을 채운 다음 **Save**를 클릭하세요. Zditor는 스킬을 앱 데이터에 보관하며, 모든 로컬 작업 공간에서 쓸 수 있습니다.
- **프로젝트 스킬.** 작업 공간 안의 `.zditor/skills`에 둔, `SKILL.md`가 들어 있는 스킬 폴더는 그 작업 공간에서만 쓸 수 있습니다.
- **다른 에이전트의 스킬.** Zditor는 작업 공간이나 홈 폴더에 있는 `.agents/skills`, `.claude/skills`, `.codex/skills` 같은 다른 에이전트의 스킬 폴더에서도 스킬을 가져옵니다. 이런 스킬은 설정 화면에 나타나지 않으므로 원래 위치에서 수정하세요.
- **GitHub에서 설치.** 데스크톱에서는 `SKILL.md`가 들어 있는 GitHub 폴더에서 스킬을 설치해 달라고 에이전트에게 요청할 수 있습니다. 다른 변경과 마찬가지로 **Always ask** 모드에서는 승인이 필요합니다.

## 대화 기록

Agent 탭의 대화는 자동으로 저장되고 제목이 붙습니다. 대화를 찾으려면 왼쪽 사이드바의 **AI conversations**(반짝이 아이콘)를 클릭하고, 제목이나 작업 공간으로 검색한 다음, 대화를 클릭해 탭에서 여세요.

대화 위에 마우스를 올리면 **Export session**(JSON), **Export as text**, **Copy session ID**, **Delete session**이 나타납니다. **Clear History**는 모든 대화를 삭제합니다.

## 개인정보 보호

- **Zditor가 먼저 묻습니다.** AI 서비스에 처음 무언가를 보낼 때 Zditor는 수신자, 서비스 주소, 전송될 내용과 함께 **Allow data sharing with AI?**를 표시합니다. **Allow and continue**를 클릭하기 전에는 아무것도 전송되지 않으며, **Not now**를 누르면 취소됩니다. 새 서비스 주소마다 다시 묻습니다.
- **전송되는 내용.** 메시지, 대화 기록, 선택한 텍스트, 추가한 이미지, 오디오, 첨부 파일, 그리고 에이전트가 작업을 위해 읽는 작업 공간 파일, 파일 이름, 도구 결과입니다.
- **전송되는 곳.** 사용자 지정 제공자를 쓰면 요청은 기기에서 입력한 **Base URL**로 바로 전송되며, API 키는 이 기기에 저장되고 그 주소로만 전송됩니다. Zditor AI를 쓰면 요청이 Zditor 서비스를 거치며, 서비스의 사용 기록에는 메시지가 아니라 요청별 모델, 토큰 수, 비용이 남습니다. MCP 서버는 에이전트가 그 도구에 보내는 내용을 받습니다.
- **대화가 보관되는 곳.** 이 기기의 Zditor 앱 데이터 안입니다. **Settings → Personal → Sync**에서 만든 백업에는 포함되지 않습니다.
- **허가 철회.** **Settings → AI → Agents**의 **AI data privacy**에서 **Withdraw permission**을 클릭하세요. 그러면 Zditor는 다른 내용을 보내기 전에 다시 묻습니다. 이미 전송된 데이터는 되돌릴 수 없습니다.

## 문제 해결

<AccordionGroup>
  <Accordion title="“No AI service is configured” 오류로 전송이 실패할 때" icon="circle-xmark">
    에이전트에 아직 AI 서비스가 없습니다. **Settings → AI → Agents**에서 로그인한 뒤 **Zditor**를 선택하거나 **Custom provider**를 설정하세요.
  </Accordion>

  <Accordion title="Fetch models 또는 Test connection이 실패할 때" icon="plug">
    **API protocol**이 서비스와 맞는지, **Base URL**이 API의 루트 주소인지(보통 `/v1`로 끝남), API 키가 올바른지 확인하세요. Zditor에는 OpenAI Responses API 또는 Claude Messages API가 필요하며, 예전 Chat Completions API만 제공하는 서비스는 작동하지 않습니다. 제공자 목록에 모델이 없으면 **Add model**에 모델 ID를 입력하세요.
  </Accordion>

  <Accordion title="Save를 누르면 컨텍스트 창과 출력 토큰을 요구할 때" icon="ruler">
    활성화한 모든 모델에는 두 한도가 모두 필요합니다. 모델을 열고 **Enter manually**를 선택한 다음, 제공자 문서에 나온 **Context window tokens**와 **Maximum output tokens**를 입력하세요.
  </Accordion>

  <Accordion title="“This response is incomplete” 메시지가 표시될 때" icon="scissors">
    모델이 한 번의 응답에서 출력 한도에 도달했습니다. 모델의 **Maximum output tokens**를 높이거나 작업을 더 작게 나누세요.
  </Accordion>

  <Accordion title="“Your input exceeds this model's context window” 메시지가 표시될 때" icon="triangle-exclamation">
    메시지나 첨부 파일을 줄이거나, `/compact`를 실행하거나, 컨텍스트 창이 더 큰 모델로 바꾸세요.
  </Accordion>

  <Accordion title="“Model response timed out” 메시지가 표시될 때" icon="hourglass-half">
    서비스가 응답을 시작하기까지 너무 오래 걸렸습니다. 다시 시도해 보고, 계속 발생하면 서비스 상태를 확인하거나 나중에 다시 시도하세요.
  </Accordion>

  <Accordion title="에이전트가 명령을 실행하거나 다른 앱을 쓰지 못할 때" icon="terminal">
    명령을 실행하려면 데스크톱 앱과 로컬 작업 공간이 필요하며, 컴퓨터 사용에는 Mac도 필요합니다. iPhone과 iPad, 원격 작업 공간에서는 에이전트가 대신 Zditor를 통해 파일로 작업합니다. Mac에서는 시스템 설정에서 Zditor에 **Screen Recording**과 **Accessibility** 권한이 있는지 확인하세요.
  </Accordion>

  <Accordion title="승인 요청이 계속 작업을 끊을 때" icon="shield-halved">
    **Always ask** 모드에서는 모든 명령에 승인이 필요합니다. 반복될 명령에는 **Always allow**를 선택하거나 **AI review**로 전환하세요. **Full Access**는 실수를 되돌릴 수 있는 곳에서만 사용하세요.
  </Accordion>
</AccordionGroup>
