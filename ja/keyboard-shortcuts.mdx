Zditor では、編集、書式設定、構造の変更、移動に幅広いキーボードショートカットを使えます。以下の表は、Markdown エディターとアプリの既定のキー割り当てです。

<Warning>
  `Mod` は、Windows と Linux では `Ctrl`、macOS では `Command` を表します。macOS では、`Alt` は `Option` キーです。
</Warning>

## グローバルショートカット

### 検索と保存

| ショートカット | 操作 |
| --- | --- |
| `Mod-K` | 検索を開く |
| `Mod-S` | 現在のドキュメントを保存 |
| `Mod-F` | 現在のドキュメント内を検索 |

### 表示モード

アクティブな Markdown ドキュメントで使えます。同じショートカットをもう一度押すと、リッチテキストに戻ります。

| ショートカット | 操作 |
| --- | --- |
| `Mod-E` | 編集モードと読み取り専用モードの切り替え |
| `Mod-/` | リッチテキストとソース表示の切り替え |
| `Mod-\` | リッチテキストと分割表示の切り替え |

### 表示の拡大と縮小

| ショートカット | 操作 |
| --- | --- |
| `Mod-=` | 拡大 |
| `Mod--` | 縮小 |
| `Mod-0` | ズームをリセット |

## エディターの操作

### 基本の編集

| ショートカット | 操作 |
| --- | --- |
| `Mod-A` | ドキュメント全体を選択 |
| `Escape` | エディターからフォーカスを外す |
| `Shift-Enter` | 新しい段落にせずに改行を挿入 |

### 取り消しとやり直し

| ショートカット | 操作 |
| --- | --- |
| `Mod-Z` | 取り消す |
| `Mod-Y` | やり直す |
| `Mod-Shift-Z` | やり直す（別のショートカット） |
| `Backspace` | Zditor が入力内容を変換した直後（たとえば `## ` を見出しにした直後）に、その変換を取り消す |

## テキストの書式

### スタイルの切り替え

| ショートカット | 操作 |
| --- | --- |
| `Mod-B` | 太字の切り替え |
| `Mod-I` | 斜体の切り替え |
| `Mod-D` | 取り消し線の切り替え |
| `Mod-H` | ハイライトの切り替え |
| `Mod-Shift-C` | インラインコードの切り替え |
| `Mod-R` | 修正マークの切り替え（[テキストマークガイド](/ja/text-marks)を参照） |

### 要素の挿入

| ショートカット | 操作 |
| --- | --- |
| `Mod-Shift-E` | インライン数式を挿入 |
| `Mod-Shift-D` | ディスプレイ数式を挿入 |
| `Mod-Shift-H` | 区切り線（水平線）を挿入 |
| `Mod-P` | 改ページを挿入 |
| `Mod-T` | 3 × 3 の表を挿入 |

<Note>
  修正マークと数式のショートカットを使うには、**Track changes** プラグインと **Math formulas** プラグインが必要です。どちらも **Settings → Integrations → Plugins** で既定でオンになっています。
</Note>

## 見出しの操作

| ショートカット | 操作 |
| --- | --- |
| `Mod-1` | 見出し 1 |
| `Mod-2` | 見出し 2 |
| `Mod-3` | 見出し 3 |
| `Mod-4` | 見出し 4 |
| `Mod-5` | 見出し 5 |
| `Mod-6` | 見出し 6 |
| `Mod-Shift-P` | 段落に変換 |
| `Backspace` | 見出しの先頭で押すと、見出しを段落に戻す |

見出しで、そのレベルと同じ見出しショートカットを押すと、段落に戻ります。

## リストの操作

### リストの作成

| ショートカット | 操作 |
| --- | --- |
| `Mod-Shift-8` | 箇条書きリストの切り替え |
| `Mod-Shift-7` | 番号付きリストの切り替え |
| `Mod-Shift-9` | チェックボックスリストの切り替え |
| `Mod-Shift-B` | 引用の切り替え |

### リスト項目の操作

| ショートカット | 操作 |
| --- | --- |
| `Enter` | リスト項目を分割 |
| `Tab` | リスト項目をインデント |
| `Shift-Tab` | リスト項目のインデントを戻す |
| `Mod-Shift-Enter` | 現在のリスト項目または引用の中で新しい段落を開始 |
| `Alt-ArrowUp` | 項目を上へ移動 |
| `Alt-ArrowDown` | 項目を下へ移動 |

### チェックボックスの操作

| ショートカット | 操作 |
| --- | --- |
| `Mod-Enter` | チェックの状態を切り替え |
| `Enter` | チェックボックス項目を分割 |
| `Tab` | チェックボックス項目をインデント |
| `Shift-Tab` | チェックボックス項目のインデントを戻す |

## コードブロックの編集

### コードブロックの作成

| ショートカット | 操作 |
| --- | --- |
| `Mod-Shift-\` | コードブロックの切り替え |

### コードブロック内の編集と移動

| ショートカット | 操作 |
| --- | --- |
| `ArrowUp` | 上へ移動（1 行目ではコードブロックから出る） |
| `ArrowDown` | 下へ移動（最終行ではコードブロックから出る） |
| `ArrowLeft` | 左へ移動（先頭ではコードブロックから出る） |
| `ArrowRight` | 右へ移動（末尾ではコードブロックから出る） |
| `Tab` | インデント |
| `Shift-Tab` | インデントを戻す |
| `Mod-Enter` | コードブロックを出て、下の新しい段落で続ける |
| `Backspace` | コードブロックの先頭で押すと、段落に戻す |

### コードブロックの整形

| ショートカット | 操作 |
| --- | --- |
| `Mod-Shift-F` | コードブロックを整形 |
| `Alt-Shift-F` | コード整形の別のショートカット |

## 数式の編集

### 数式内での操作

| ショートカット | 操作 |
| --- | --- |
| `Tab` | タブを挿入 |
| `Enter` | ディスプレイ数式では改行、インライン数式では数式から出る |
| `Mod-Enter` | 数式から出る |
| `Backspace` | 空の数式を削除 |
| `Mod-Backspace` | 数式を削除してテキストに戻る |
| `Mod-A` | 数式内をすべて選択 |
| `Mod-M` | インライン数式とディスプレイ数式の切り替え |
| `Mod-P` | 数式をプレーンテキストに変換 |

### 数式内の移動

| ショートカット | 操作 |
| --- | --- |
| `ArrowLeft` | 左へ移動（先頭では数式から出る） |
| `ArrowRight` | 右へ移動（末尾では数式から出る） |
| `ArrowUp` | 上へ移動（1 行目では数式から出る） |
| `ArrowDown` | 下へ移動（最終行では数式から出る） |

ディスプレイ数式を選択しているときに `Enter` を押すと、その数式を編集できます。[数式ガイド](/ja/math-formulas)を参照してください。

## 表の操作

### 表内の移動

| ショートカット | 操作 |
| --- | --- |
| `Tab` | 次のセルへ移動（最後のセルでは行を追加） |
| `Shift-Tab` | 前のセルへ移動 |

### 表の編集

| ショートカット | 操作 |
| --- | --- |
| `Mod-Enter` | 下に行を追加して、その行へ移動 |
| `Mod-Shift-Enter` | 右に列を追加して、その列へ移動 |
| `Mod-Backspace` | 現在の行を削除 |
| `Mod-Shift-Backspace` | 現在の列を削除 |

## その他の操作

### その他の要素

| ショートカット | 操作 |
| --- | --- |
| `Mod-Shift-M` | Frontmatter のないドキュメントの最初の段落で、Frontmatter ブロックを追加（[Frontmatter ガイド](/ja/frontmatter)を参照） |
| `Mod-Shift-V` | HTML ブロックの切り替え |

### 候補メニュー

これらのキーは、`/`、`@`、`#` のメニューで使えます。

| ショートカット | 操作 |
| --- | --- |
| `ArrowUp` | リスト内で上へ移動 |
| `ArrowDown` | リスト内で下へ移動 |
| `Tab` / `Shift-Tab` | 次または前の項目へ移動 |
| `ArrowRight` | ハイライトされたグループを開く |
| `ArrowLeft` | グループから戻る |
| `Enter` | ハイライトされた項目を選ぶ、またはハイライトされたグループを開く |
| `Escape` | グループから戻る、またはメニューを閉じる |
| `Backspace` | 1 文字削除して絞り込みを更新 |

`:` で開く絵文字ピッカーでは、矢印キーでグリッド内を移動し、`Enter` でハイライトされた絵文字を挿入します。絞り込みの文字を入力する前なら、`Mod-ArrowLeft` / `Mod-ArrowRight` でカテゴリを切り替えられます。

## ショートカットのカスタマイズ

デスクトップ版では、**Settings → Personal → Keyboard shortcuts** を開きます。

<Steps>
  <Step title="キー割り当てを探す">
    名前で検索するか、カテゴリを選ぶか、**All Bindings**、**Commands**、**Semantic Intents** を切り替えます。
  </Step>
  <Step title="新しいキーを記録する">
    キー割り当てのキー欄をクリックし、新しいキーの組み合わせを押します。キャンセルするには `Escape` を押します。
  </Step>
  <Step title="競合を確認する">
    同じカテゴリ内のほかのキー割り当てと重なるものには、**Conflict** バッジが表示されます。**Conflicts only** を選ぶと、それらだけが一覧表示されます。
  </Step>
</Steps>

変更したキー割り当てには、**Customized** バッジと **Reset to default** ボタンが表示されます。**Reset All** を使うと、すべて既定に戻ります。

<Tip>
  **Readonly** と表示されたキー割り当ては変更できません。検索、保存、ズーム、コードブロックや数式の中で使うキー、`Enter`、`Tab`、`Backspace` などのセマンティックキーがこれに当たります。変更はすぐに反映されます。
</Tip>

## よくある質問

<AccordionGroup>
  <Accordion title="ショートカットが効かないのはなぜですか？" icon="question">
    エディターにフォーカスがあるか、現在のノードの種類がその操作に対応しているか、**Settings → Personal → Keyboard shortcuts** でキー割り当てを変更していないか、OS が先にショートカットを受け取っていないかを確認してください。
  </Accordion>

  <Accordion title="macOS ではショートカットが違いますか？" icon="question">
    キー割り当ては同じです。`Mod` は macOS では `Command`、それ以外では `Ctrl` に読み替え、`Alt` と書かれているところでは `Option` を押してください。
  </Accordion>

  <Accordion title="すべてカスタマイズできますか？" icon="question">
    いいえ。設定で **Readonly** と表示されたキー割り当ては既定のままです。また、一部のショートカットは OS が予約しています。
  </Accordion>
</AccordionGroup>
