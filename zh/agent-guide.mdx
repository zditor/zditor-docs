Zditor 内置了一个智能体。它直接处理工作区中的文件：阅读和编辑笔记、批注 PDF、构建画布、运行命令，还能操作 Zditor 本身。你可以选择它背后的 AI 服务（通过 Zditor 账户使用 Zditor AI，或者使用你自己的服务商），并决定它可以不经询问做哪些事。

<Frame>
  <img src="/images/agent.webp" alt="Zditor 中的一段智能体对话，正在等待批准编辑文件，显示允许一次、始终允许和拒绝三个选项，输入框下方的权限模式为总是询问" style={{ borderRadius: '0.5rem' }} />
</Frame>

<Warning>
  智能体可以修改文件、运行命令，在 Mac 上还能操作其他应用。批准每个请求前请先看清内容；除非你信任这项任务，否则请保持 **总是询问** 权限模式。
</Warning>

它还可以把大任务的一部分交给并行工作的子智能体，在需要你做决定时向你提问，并在 Zditor 标签页中打开它生成的内容，例如 HTML 页面、图片或视频。

<Note>
  在 iPhone 和 iPad 上，以及在远程工作区（SSH、S3、WebDAV 或 Git）中，智能体通过 Zditor 读写文件，但不能运行终端命令，也不能操作其他应用。在远程工作区中，它也不能使用 Git。
</Note>

## 设置 AI 服务

智能体需要先连接 AI 服务才能工作。打开 **设置 → AI → 智能体**，在 **服务提供方** 下把 **AI 服务** 设为 **Zditor 内置** 或 **自定义服务**。

<Tabs>
<Tab title="Zditor AI">
  Zditor AI 不需要 API 密钥。登录 Zditor 账户后，只要你订阅了 Pro（包含每月 AI 用量额度），或者账户中有免费 AI Token，就可以使用它。免费 Token 用于 Claude Haiku 5.5。

  1. 打开 **设置 → AI → 智能体**。
  2. 如果尚未登录，点击 **登录账号**，然后在浏览器中完成登录。
  3. 把 **AI 服务** 设为 **Zditor 内置**。

  Zditor 每次启动时都会加载可用的模型及其设置；点击 **服务配置** 下的 **更新** 可以立即加载。你的用量显示在 **设置 → 个人 → 账户** 的 **AI 用量** 中。
</Tab>

<Tab title="自定义服务">
  可以连接任何支持 OpenAI Responses API 或 Claude Messages（Anthropic）API 的服务，包括运行在你自己电脑上的服务。

  <Steps>
    <Step title="选择协议">
      把 **AI 服务** 设为 **自定义服务**，然后选择你的服务支持的 **API 协议**：**OpenAI Responses** 或 **Claude Messages（Anthropic）**。
    </Step>

    <Step title="填写地址和密钥">
      填写 **基础 URL**，即该服务 API 的根地址，通常以 `/v1` 结尾（例如 `https://api.openai.com/v1` 或 `https://api.anthropic.com/v1`）。然后填写你的 **API 密钥**；本地服务可能不需要密钥。密钥保存在这台设备上，只会发送到这个地址。
    </Step>

    <Step title="添加模型">
      在 **模型与生成** 下点击 **获取模型**。服务商的模型会显示为 **未启用**：打开每个你想使用的模型，打开它的 **启用** 开关。如果要添加服务商没有列出的模型，在 **添加模型** 中输入它的 ID 并按 Enter。用这种方式添加的模型会直接启用。
    </Step>

    <Step title="检查 Token 上限">
      每个已启用的模型都需要设置 **上下文窗口词元数** 和 **最大输出词元数**。如果服务商提供了这些数值，Zditor 会自动填入（**服务端提供**）；否则请选择 **手动填写**，并使用服务商文档中的数值。
    </Step>

    <Step title="保存">
      点击 **保存**。**测试连接** 会通过获取模型列表来检查地址和密钥。
    </Step>
  </Steps>
</Tab>
</Tabs>

### 模型设置

在 **模型与生成** 下打开某个模型即可调整它。使用 Zditor AI 时，你可以查看这些设置，但不能修改。

| 设置 | 作用 |
| :--- | :--- |
| **推理强度** | 模型在回答前推理的程度。**自动** 使用模型的默认值；级别越高，耗费的时间和 Token 越多。 |
| **温度** | 数值越低，回答越可预测；数值越高，回答越多样。留空则由服务决定。 |
| **上下文窗口词元数**、**最大输出词元数** | 模型的上限，由服务提供或由你填写。 |
| **自动压缩阈值** | 对话达到这个 Token 数时，Zditor 会总结较早的上下文以腾出空间。默认值为上下文窗口的 90%。 |

在对话中，顶部的模型菜单（**模型与推理强度**）会列出已启用的模型和推理强度。你可以在对话过程中切换模型，新对话会使用你上次选择的模型。

## 开始对话

### 在智能体标签页中

点击标签栏中的 **+** 打开新标签页，新标签页就是智能体标签页。智能体在 Zditor 当前打开的工作区中工作，所以请先打开一个工作区：空白的智能体标签页提供 **打开工作区** 和 **新建工作区**。没有工作区时，智能体会在 Zditor 应用数据中的一个临时文件夹里工作。

### 在文档旁边

在 Markdown 笔记中，点击标题栏中的 **文档侧边栏**，选择 **对话** 标签页。对话开始时会自动附上这篇笔记，你可以直接就它提问。画布的侧边栏中也有同样的 **对话** 标签页。

如果想就笔记的某一部分提问，选中它，然后点击选区工具栏中的星光按钮（**询问 AI**）。**对话** 标签页会打开，并附上选中的内容。你在 **设置 → AI → AI 工具栏提示词** 中设置的提示词会作为额外按钮出现在工具栏中，点击后会立即把指令连同选中内容一起发送。

<Note>
  文档侧边栏中的对话是临时的，不会保存到对话历史中。需要保留的工作，请在智能体标签页中进行。
</Note>

### 编写请求

在输入框中输入内容，点击 **发送消息**。智能体工作时，**停止当前任务** 可以让它停下；在此期间发送的内容会排队，等当前这一轮结束后再处理。

- 输入 `/` 运行命令（见下表）。
- 输入 `@` 附加工作区中的文件。
- 输入 `$` 使用技能。
- 点击 **上传文件**（回形针图标），或者把文件拖到输入框上，即可附加文件。图片、音频和文本文件会直接放入消息；其他文件（例如 PDF 和 Office 文档）则以路径的形式传递，由智能体自行打开。

在 iPhone 和 iPad 上，输入框下方的 **命令**、**文件** 和 **技能** 按钮会打开与 `/`、`@` 和 `$` 相同的列表。

第一次向某个 AI 服务发送消息时，Zditor 会请你允许向它共享数据。详见下文的“隐私”。

### 命令

| 命令 | 作用 |
| :--- | :--- |
| `/goal` | 为对话设定一个目标，智能体会一轮接一轮地朝它推进，直到完成或受阻。输入 `/goal` 加上目标内容即可设定；单独输入 `/goal` 可以查看目标；也可以使用 `/goal edit`、`/goal pause`、`/goal resume` 或 `/goal clear`。临时会话中不可用。 |
| `/side` | 从当前上下文开启一个临时的旁支对话。可以在命令后面直接写上问题。 |
| `/compact` | 总结目前为止的对话以释放上下文，同时保留关键信息。 |
| `/export` | 把对话保存为 Markdown；使用 `/export json` 则保存为 JSON。 |
| `/share` | 把对话保存为一张 PNG 图片。 |

<Tip>
  目标处于活动状态时，即使你不发新消息，智能体也会继续工作，而每一轮都会消耗 Token。想让它停下时，请暂停或清除目标。
</Tip>

### 工作过程

智能体会边做边展示它的工作：读取和编辑的文件、运行的命令，以及它的回答。一轮结束后，其中的步骤会折叠进 **处理过程**，你可以展开查看。

- 如果某一轮修改了文件，会出现一张卡片（例如 **已变更 2 个文件**）列出这些文件；展开某个文件即可查看改动。在本地工作区中，**撤销** 会还原这一轮的文本修改；如果这些文件之后又被改动过，则不会撤销任何内容。
- 输入框下方的 **用量** 显示当前对话占用了模型上下文窗口的多少。达到模型的压缩阈值时，Zditor 会自动压缩较早的上下文；`/compact` 则可以随时手动压缩。
- 在智能体标签页中，打开某条消息的 **更多** 菜单，选择 **在新会话中创建分支**，即可从这一点开始在新对话中继续。原对话保持不变。
- 如果工作区中有 `AGENTS.md` 文件，智能体会把它当作项目说明来遵循。

## 权限与审批

在输入框下方选择 **权限模式**，Zditor 会记住你的选择。

| 模式 | 效果 |
| :--- | :--- |
| **总是询问** | 每次执行受限操作前，智能体都会先询问你。这是默认模式。 |
| **AI 评审** | 由一次单独的模型请求，根据你的任务检查每个受限操作，决定允许还是拒绝；拿不准时就拒绝。不会询问你，而且每次检查都会额外发起一次模型请求。 |
| **完全访问** | 所有工具操作都直接执行，不再询问。 |

在 **总是询问** 模式下，智能体在以下操作前都会询问：运行命令（在桌面版中，也包括只读取文件的命令）、编辑文件、使用 Git、发送网络请求、更改 Zditor 的标签页或设置、批注 PDF、编辑画布、调用 MCP 工具，以及打开应用或在应用中点击、输入、滚动。阅读 PDF 和画布、查看已打开的标签页以及截屏则无需批准。

询问时，请求中会显示要执行的操作和三个选项：

- **允许一次**：执行这一次操作。
- **始终允许**：执行这次操作，并在本次对话的剩余部分中不再询问同样的操作，例如同一条命令，或对同一批文件的后续编辑。其他操作仍会询问。
- **拒绝**：不执行这次操作，并告知智能体你拒绝了。

<Tip>
  桌面任务往往涉及很多命令。如果逐条批准太繁琐，**AI 评审** 是一个折中的选择。只在可以恢复的工作区（例如纳入版本管理的工作区）中使用 **完全访问**。
</Tip>

## 在 Mac 上操作电脑

在 Mac 的本地工作区中，智能体可以在任务需要时操作其他应用。它通过截屏和辅助功能信息查看应用窗口，并且可以打开应用、点击、输入、滚动和按键。

- 第一次使用时，macOS 会请你为 Zditor 授予 **屏幕录制** 和 **辅助功能** 权限。缺少其中任何一项时，对话中的电脑操作步骤会显示“macOS 拒绝了计算机操作：”，并为每项缺少的权限提供一个按钮（**打开辅助功能** 或 **打开屏幕录制**），点击即可打开系统设置中对应的页面。你可以随时在那里关闭这两项权限。
- 在 **总是询问** 模式下，打开应用、点击、输入、滚动和按键都需要批准，截屏则不需要。对其中某类操作选择 **始终允许**，会在本次对话中放行同类的后续操作。
- 智能体工作时，会有一个面板显示它正在操作的应用。如果关闭了这个面板，可以点击 **显示电脑操作窗口**（输入框下方的显示器按钮）把它找回来。

## MCP 服务器与技能

### MCP 服务器

MCP 服务器把智能体连接到其他应用和服务，例如问题跟踪系统或数据库。在 **设置 → AI → MCP 服务器** 中添加它们；每个已启用的服务器在所有智能体对话中都可用。详见 [MCP 服务使用指南](/zh/mcp-guide)。

### 技能

技能是针对某一类任务写成的一套指令，保存在 `SKILL.md` 文件中。智能体知道每个技能的名称和描述，遇到匹配的任务时才会读取完整指令。如果想主动使用某个技能，在输入框中输入 `$` 并选择它。

- **内置技能。** Zditor 自带 **画布**、**Markdown** 和 **设置与标签页** 三个技能，它们列在 **设置 → AI → 技能** 的 **已安装的技能** 下。
- **你自己的技能。** 在 **设置 → AI → 技能** 中点击 **添加技能**，填写 **名称**（字母、数字、连字符或下划线）、**描述**（这个技能的用途）和 **技能指令（Markdown）**，然后点击 **保存**。Zditor 会把这个技能保存在应用数据中，你的所有本地工作区都可以使用它。
- **项目技能。** 放在工作区 `.zditor/skills` 中、包含 `SKILL.md` 的技能文件夹，只在该工作区中可用。
- **来自其他智能体的技能。** Zditor 也会读取其他智能体的技能文件夹中的技能，例如工作区或主文件夹中的 `.agents/skills`、`.claude/skills` 和 `.codex/skills`。它们不会出现在设置中，请在原位置修改。
- **从 GitHub 安装。** 在桌面版中，你可以让智能体从包含 `SKILL.md` 的 GitHub 文件夹安装技能。和其他修改一样，在 **总是询问** 模式下这需要你的批准。

## 对话历史

智能体标签页中的对话会自动保存，并自动生成标题。要查找某个对话，点击左侧边栏中的 **AI 对话**（星光图标），按标题或工作区搜索，然后点击对话，在标签页中打开它。

把鼠标悬停在对话上，可以使用 **导出会话**（JSON）、**导出纯文本**、**复制会话 ID** 和 **删除会话**。**清空历史** 会删除你的所有对话。

## 隐私

- **Zditor 会先征求你的同意。** 第一次向某个 AI 服务发送内容时，Zditor 会显示 **允许向 AI 服务发送数据？**，并列出接收方、服务地址和将要发送的内容。在你点击 **允许并继续** 之前，不会发送任何内容；**暂不允许** 会取消发送。每遇到一个新的服务地址，Zditor 都会再次询问。
- **发送什么。** 你的消息、对话历史、选中的文字、你添加的图片、音频和附件，以及智能体为完成任务而读取的工作区文件、文件名和工具结果。
- **发送到哪里。** 使用自定义服务时，请求从你的设备直接发送到你填写的 **基础 URL**，API 密钥保存在这台设备上，也只会发送到那里。使用 Zditor AI 时，请求会经过 Zditor 的服务，其用量记录只保存每次请求的模型、Token 数和费用，不保存你的消息。MCP 服务器会收到智能体发送给其工具的内容。
- **对话保存在哪里。** 保存在这台设备上的 Zditor 应用数据中。在 **设置 → 个人 → 同步** 中创建的备份不包含对话。
- **撤回授权。** 在 **设置 → AI → 智能体** 的 **AI 数据隐私** 下，点击 **撤回授权**。之后再发送任何内容前，Zditor 都会重新询问。已经发送的数据无法收回。

## 常见问题排查

<AccordionGroup>
  <Accordion title="发送失败，提示“尚未配置 AI 服务”" icon="circle-xmark">
    智能体还没有可用的 AI 服务。在 **设置 → AI → 智能体** 中登录并选择 **Zditor 内置**，或者设置 **自定义服务**。
  </Accordion>

  <Accordion title="获取模型或测试连接失败" icon="plug">
    检查 **API 协议** 是否与服务匹配、**基础 URL** 是否是其 API 的根地址（通常以 `/v1` 结尾），以及 API 密钥是否正确。Zditor 需要 OpenAI Responses API 或 Claude Messages API；只提供旧版 Chat Completions API 的服务无法使用。如果服务商没有列出任何模型，请在 **添加模型** 中输入模型 ID。
  </Accordion>

  <Accordion title="保存时要求填写上下文窗口和输出 Token" icon="ruler">
    每个已启用的模型都需要这两个上限。打开该模型，选择 **手动填写**，再根据服务商的文档填写 **上下文窗口词元数** 和 **最大输出词元数**。
  </Accordion>

  <Accordion title="“本次输出未完成”" icon="scissors">
    模型的单次回复达到了输出上限。请调高该模型的 **最大输出词元数**，或者把任务拆成更小的部分。
  </Accordion>

  <Accordion title="“输入内容超出模型的上下文窗口”" icon="triangle-exclamation">
    缩短消息或附件、运行 `/compact`，或者换用上下文窗口更大的模型。
  </Accordion>

  <Accordion title="“模型响应超时”" icon="hourglass-half">
    服务过了太久仍未开始回答。请重试；如果一直出现，请检查服务状态或稍后再试。
  </Accordion>

  <Accordion title="智能体无法运行命令或操作其他应用" icon="terminal">
    运行命令需要桌面版和本地工作区，电脑操作还需要 Mac。在 iPhone、iPad 和远程工作区中，智能体改为通过 Zditor 处理文件。在 Mac 上，请在系统设置中确认 Zditor 已获得 **屏幕录制** 和 **辅助功能** 权限。
  </Accordion>

  <Accordion title="审批请求频繁打断工作" icon="shield-halved">
