Zditor には、PDF を読んだり注釈を付けたりするための PDF ビューアーが組み込まれています。ページに描き込んだり、タイトルとコメントを付けたエリアハイライトで範囲に印を付けたり、注釈のまとまりをレイヤーで分けたり、ハイライトを Markdown のノートで引用したりできます。注釈は別のファイルに保存されるので、PDF 自体が変更されることはありません。

## 注釈データの保存方法

PDF の注釈が PDF ファイルに書き込まれることはありません。Zditor は注釈を、同じフォルダー内にある、PDF の名前にちなんだ別の JSON ファイルに保存します。

```text
example.pdf.zditor-pdf-annotation.json
```

このファイルは PDF に初めて注釈を付けたときに作成され、変更はすべて自動的に保存されます。保存される内容は次のとおりです。

- レイヤー（名前と表示状態）
- ストローク（ページ、レイヤー、点、色、太さ、ストロークの設定）
- エリアハイライト（ページ、レイヤー、範囲、色、タイトル、コメント、サムネイルへの参照）
- エージェントが引用をもとに作成したハイライトの場合は、引用したテキスト

<Tip>
  PDF 自体は変更されないので、注釈の同期、バックアップ、バージョン管理が簡単です。
</Tip>

## 画面のレイアウト

デスクトップアプリでは、PDF ビューアーは 4 つの領域で構成されています。

### タイトルバー

PDF の上にあるタイトルバーには、次のものがあります。

- 左側に **Undo** と **Redo**
- 右側に **Print**、**Search**、**Bookmarks**、**Layers**、**Clear Page**

タブの幅が狭いときは、**Bookmarks**、**Layers**、**Clear Page** が **More** メニューに移動します。検索中は、これらのボタンの代わりに検索フィールドが表示されます。

### 注釈ツールバー

ページの上部には、角の丸いツールバーが浮かんで表示されます。左から順に、次のものがあります。

- **Keep tool active**
- 注釈ツール
- 6 つの色
- **Width** スライダー
- **Stroke Parameters**

タブの幅が足りないときは、まず太さのスライダー、次に色が、ストロークパラメーターのボタンの中に移動します。このボタンには現在の色が表示され、名前は **Brush settings** になります。それでも足りない場合は、**Laser** や **Line** など使用頻度の低いものから順に、ツールが **More** メニューに移動します。メニューには、各ツールのショートカットの文字が表示されます。

### ズームとページのコントロール

左下には、**Zoom Out**、拡大率、**Zoom In**、現在のページ番号があります。

### 左側のサイドバー

**Bookmarks**、**Layers**、**Search** を使うと、ページの左側にサイドバーが開きます。サイドバーには次のいずれかが表示されます。

- PDF のしおり
- レイヤーと、エリアハイライトの一覧
- 検索結果

閉じるには、**Bookmarks** または **Layers** をもう一度クリックします。

## 注釈ツール

注釈ツールバーでツールを選ぶか、そのツールの文字キーを押します。

### 選択ツール

ショートカット：`V`。選択ツール（**Select**）は、描画する代わりに注釈を選択して移動します。PDF を開くと、このツールが選ばれた状態になります。

選択ツールでは、次の操作ができます。

- ストロークをクリックして選択します。`Shift` キーを押しながらクリックすると、ストロークを選択に追加したり、選択から外したりできます。
- 選択したストローク、または選択範囲内の任意の場所をドラッグして移動します。
- エリアハイライトをクリックするとカードが表示されます。ドラッグで移動し、角のハンドルをドラッグするとサイズを変更できます。

何もない場所をクリックすると、選択が解除されます。

### ペン

ショートカット：`P`。ペンはフリーハンドで描くためのツールで、手書きのメモ、丸、矢印、自由な線を描けます。6 つの色から 1 つを選び、**Width** を設定します。

**Stroke Parameters** では、各ストロークの形を調整できます。

- **Pressure sensitivity**：筆圧に応じて太さを変えます。マウスでは効果はありません。
- **Smoothing**：各ストロークの輪郭をなめらかにします。
- **Stabilization**：線がペンより少し遅れて追従するようにして、すばやく描いた線も安定させます。
- **Taper Start** と **Taper End**：ストロークの始まりや終わりを細く尖らせます。
- **Cap Start** と **Cap End**：先細りにしていないストロークの始まりや終わりを丸くします。
- **Reset**：ストロークパラメーターを既定値に戻します。

<Tip>
  太さとストロークパラメーターは新しいストロークに適用され、既存のストロークは描いたときの設定のままです。選んだ設定は描画の既定値として記憶されます。既定値は **Settings → Editor → PDF Editor** でも設定できます。
</Tip>

### 蛍光ペン

ショートカット：`M`。蛍光ペンもフリーハンドのツールですが、ペンとは次の点が異なります。

- 半透明なので、下のテキストが読めるままです
- 蛍光マーカーのようにページになじみます
- 筆圧によって太さが変わりません

### 消しゴム

ショートカット：`E`。消したいストロークの上を消しゴムでドラッグします。

- 通った跡に触れたストロークは、直線や長方形も含めて、まるごと削除されます
- 消しゴムの大きさは **Width** の設定に従います
- ドラッグするそばからストロークが消え、離したときに変更が保存されます
- 表示されているすべてのレイヤーのストロークが対象になります

<Warning>
  消しゴムではエリアハイライトは削除できません。エリアハイライトは、カード、エディター、またはレイヤーサイドバーの注釈の一覧から削除します。
</Warning>

### 直線と長方形

より整った書き込みには、次のツールを使います。

- **Line**（`L`）：押した位置から離した位置まで直線を引きます
- **Rectangle**（`R`）：2 つの角を結ぶ四角い枠を描きます

描き終わると、新しい図形が選択された状態で **Select** に戻るので、すぐに移動できます。続けていくつも描くには、**Keep tool active** をオンにします。

### なげなわ

ショートカット：`S`。ストロークを囲むように輪を描くと、それらが選択されます。輪の内側に点が 1 つでもあるストロークは、すべて選択されます。その後は、[選択と一括操作](#選択と一括操作)で説明するように、選択ツールバーを使ったり、選択範囲をドラッグしたりできます。

<Tip>
  なげなわで選択できるのはストロークだけです。エリアハイライトや PDF のテキストは選択できません。
</Tip>

### レーザー

ショートカット：`K`。レーザーは、プレゼンテーション、授業、画面共有で使う一時的なポインターです。

- カーソルの代わりに現在の色の点が表示され、1 秒以内に消える軌跡を残します
- 注釈データには何も保存されません
- 別のツールに切り替えると、軌跡はすぐに消えます

### パン

ショートカット：`H`。注釈を付ける代わりに、ドラッグでページを任意の方向にスクロールします。ズームインした後に特に便利です。

### ツールの固定

ショートカット：`Q`。直線、長方形、エリアハイライトを描いた後は、通常 **Select** に戻ります。**Keep tool active** をオンにすると、ツールが選択されたままになります。ペン、蛍光ペン、消しゴム、なげなわ、レーザー、パンの各ツールは、常に選択されたままです。

### キーボードショートカット

| キー | 操作 |
| --- | --- |
| `V` | 選択 |
| `H` | パン |
| `P` | ペン |
| `M` | 蛍光ペン |
| `A` | エリアハイライト |
| `E` | 消しゴム |
| `L` | 直線 |
| `R` | 長方形 |
| `S` | なげなわ |
| `K` | レーザー |
| `Q` | **Keep tool active** のオンとオフを切り替え |
| `Cmd/Ctrl + Z` | 取り消す |
| `Shift + Cmd/Ctrl + Z` | やり直す（Windows と Linux では `Ctrl + Y` も使えます） |
| `Delete` または `Backspace` | 選択したストロークを削除 |
| `Cmd/Ctrl + F` | PDF を検索 |

ツールの文字キーと、取り消し・やり直しのキーは、PDF ビューアー内をクリックした後に使えます。入力欄で入力している間は使えません。

## エリアハイライト

エリアハイライトは、PDF ビューアーで最も構造化された注釈です。ページ上の長方形の範囲で、色、タイトル、コメント、その範囲のサムネイルを持ちます。

### エリアハイライトの作成

<Steps>
  <Step title="エリアハイライトツールに切り替える">
    注釈ツールバーで **Area Highlight** を選ぶか、`A` を押します。
  </Step>

  <Step title="PDF 上で長方形をドラッグする">
    注釈を付けたい範囲をドラッグします。
  </Step>

  <Step title="タイトルとコメントを追加する">
    ポインターを離すと、範囲の横に小さなエディターが開きます。5 つの色から 1 つを選び（既定は黄色）、必要に応じてタイトルとコメントを入力します。タイトルで `Enter` を押すと、コメントに移動します。
  </Step>

  <Step title="確定する">
    **Confirm** をクリックするか `Cmd/Ctrl + Enter` を押すと、ハイライトがアクティブなレイヤーに保存されます。**Cancel** または `Esc` で破棄されます。
  </Step>
</Steps>

確定すると、**Keep tool active** がオンでない限り、新しいハイライトが選択された状態で **Select** に戻ります。コメントのあるハイライトには、右上に小さな点が表示されます。

### エリアハイライトの編集

#### 選択ツールで

ハイライトをクリックすると、タイトルとコメントが書かれたカードが表示されます。**Edit Annotation**（鉛筆）またはカードのテキストをクリックするとエディターが開き、**Delete Annotation**（ゴミ箱）をクリックするとハイライトが削除されます。レイヤーサイドバーも開き、注釈の一覧でそのハイライトに印が付きます。

#### エリアハイライトツールで

既存のハイライトをクリックすると、直接エディターが開きます。

#### エディターで

- 色の変更はすぐに反映されます
- タイトルやコメントを変更したら、**Save** をクリックするか `Cmd/Ctrl + Enter` を押します
- **Close** または `Esc` で、タイトルとコメントを保存せずに閉じます
- ゴミ箱のボタンでハイライトを削除します

### エリアハイライトの移動とサイズ変更

選択ツールでハイライトをドラッグすると、移動できます。選択したハイライトには四隅にハンドルが表示され、ドラッグするとサイズを変更できます。

エディターが開いている間は、枠の周りに 8 つのハンドルが表示されます。

- 左上、上、右上
- 左、右
- 左下、下、右下

削除して描き直さなくても、正確にサイズを調整できます。

### エリアハイライトの削除

ハイライトは次の方法で削除できます。

- カードの **Delete Annotation** をクリックする
- エディターのゴミ箱をクリックする
- レイヤーサイドバーの注釈の一覧で、ハイライトの横にある **Delete Annotation** をクリックする
- エリアハイライトツールを選択している状態で、ハイライトを右クリックする

削除したハイライトは、取り消し操作で元に戻せます。

### ハイライトのサムネイル

エリアハイライトを保存すると、Zditor はその範囲の画像を取り込み、**Settings → Editor → PDF Editor → Highlight thumbnails** で選んだ場所に保存します。同じ設定は **Settings → Integrations → Image hosting & uploads** にもあります。保存先には、ローカルフォルダーか、設定済みの S3 互換ストレージ、WebDAV、GitHub のストレージを指定できます。

サムネイルのないハイライトがある場合は、レイヤーサイドバーの注釈の一覧でそのハイライトにポインターを合わせ、**Regenerate missing thumbnails** をクリックします。

## Markdown での PDF カードの参照

エリアハイライトは、PDF ビューアーの中だけのものではありません。PDF カードとして Markdown ドキュメントに挿入できるので、読書中の注釈を再利用できるノートにまとめるときに便利です。

Markdown ドキュメントで `@` を入力すると、参照先の一覧が開きます。一覧には次のものが含まれます。

- ワークスペース内の Markdown ファイル
- 注釈を付けた PDF

エリアハイライトのある PDF を選ぶと、2 種類の項目を含む第 2 階層のメニューが開きます。

- **PDF そのもの**：PDF 全体へのリンクを挿入します
- **各エリアハイライト**：その範囲の PDF カードを挿入します

エリアハイライトのない PDF は、すぐにリンクとして挿入されます。ハイライトはタイトルで表示され、タイトルがない場合はページとコメントで表示されます。`@` に続けて入力すると、ファイル名、ハイライトのタイトル、コメント、ページ番号（たとえば `page 3`）を検索できます。

PDF カードには、ハイライトのタイトル（ある場合）と PDF のファイル名が表示されます。

### 一般的な手順

<Steps>
  <Step title="先に PDF でエリアハイライトを作成する">
    重要な範囲にエリアハイライトを追加します。後で一覧から見分けやすいよう、タイトルかコメントを付けておくのがおすすめです。
  </Step>

  <Step title="Markdown ドキュメントに戻って @ を入力する">
    ワークスペースの参照先の一覧が開きます。
  </Step>

  <Step title="目的の PDF を選ぶ">
    第 1 階層の一覧で PDF を選ぶと、第 2 階層のメニューが開きます。
  </Step>

  <Step title="PDF 全体かハイライトを選ぶ">
    ファイル全体へのリンクにするなら PDF そのものを、特定の範囲を指すカードにするならそのハイライトを選びます。
  </Step>

  <Step title="Markdown に挿入する">
    リンクまたは PDF カードが、現在の Markdown ドキュメントに挿入されます。
  </Step>
</Steps>

### Markdown 内の PDF カードの操作

PDF カードをクリックすると、カードが選択されてツールバーが開きます。このツールバーで、書いている文章と元の PDF を行き来できます。

- **ASK AI**：ハイライトのページ、タイトル、コメントとともに、カードをエージェントで開きます
- **PDF のファイル名**：PDF を開き、ハイライトまでスクロールして選択します
- **Open with Default App**、**Open Containing Folder**、**Copy File Path**：PDF ファイルに対して操作します（デスクトップアプリ）
- ハイライトのページ番号
- **Edit Title**：ノートでこのカードに表示されるタイトルを変更します
- **Refresh**：ハイライトの詳細とサムネイルを再読み込みします
- **More Options**：ハイライトのページ、タイトル、コメント、サムネイルを表示します。サムネイルをクリックすると、元のサイズで表示されます。

つまり、PDF カードは単なる静的な参照ではありません。Markdown でまとめたノートをもとに書き進めながら、元の文脈を確かめたいときはいつでも元の PDF に戻れます。

<Tip>
  この使い方は、論文を読むときや研究ノートに特に役立ちます。Markdown 側には再利用できるカードが、PDF 側には注釈を付けた元の範囲が残ります。
</Tip>

次のような場合に便利です。

- 論文のハイライトをノートにまとめる
- PDF のサムネイルとコメントの文脈を Markdown 内に残す
- 読みながら構造化された研究ノートを作る

## レイヤーの管理

レイヤーは、PDF の注釈を整理するための中心的な機能の 1 つです。タイトルバーの **Layers** をクリックすると、サイドバーにレイヤーが表示されます。どの PDF にも、最初は **Default Layer** があります。

### レイヤーでできる操作

レイヤーサイドバーでは、次の操作ができます。

- **Add Layer**（プラス）をクリックしてレイヤーを作成します。作成したレイヤーがアクティブなレイヤーになります。
- レイヤーをクリックしてアクティブにします。非表示のレイヤーをクリックすると、再び表示されます。
- レイヤー名をダブルクリックして名前を変更します。`Enter` で確定、`Esc` でキャンセルします。
- レイヤーにポインターを合わせ、目のアイコンをクリックして非表示または表示にします。
- レイヤーにポインターを合わせ、ゴミ箱をクリックして削除します。最後に残ったレイヤーは削除できません。

<Warning>
  レイヤーを削除すると、そのレイヤーに保存されているストロークとエリアハイライトも削除されます。PDF を開いている間は、取り消し操作で元に戻せます。
</Warning>

レイヤーの下にある **Annotations** の一覧には、すべてのエリアハイライトが、ページ、レイヤー、タイトル、コメントとともに表示されます。クリックすると、そのページに移動します。

### アクティブなレイヤーの役割

アクティブなレイヤーによって、次のことが決まります。

- 新しいストロークを作成する場所
- 新しいエリアハイライトを作成する場所
- 貼り付けたストロークが入る場所
- **Clear Page** で削除されるストローク

消しゴム、なげなわ、選択ツールは、表示されているすべてのレイヤーに対して機能します。アクティブなレイヤーを非表示にすると、表示されている最初のレイヤーがアクティブになります。

### レイヤーの表示

各レイヤーは、個別に表示と非表示を切り替えられます。レイヤーを非表示にすると、次のようになります。

- そのレイヤーのストロークとエリアハイライトがページから消えます
- 印刷時に含まれません
- データはそのまま残り、注釈の一覧にはそのレイヤーのハイライトが引き続き表示されます

次のような場合に便利です。

- 注釈をテーマごとに分ける
- 個人用とチーム用の書き込みを分ける
- 一時的に 1 つの種類の注釈だけに集中する

## 選択と一括操作

選択ツールまたはなげなわでストロークを選択すると、選択範囲の左側に縦長のツールバーが表示されます。

使える操作は次のとおりです。

- **Delete**
- **Copy**
- **Cut**
- **Paste**：コピーまたはカットした後に表示されます。コピーしたストロークを、少しずらしてこのページのアクティブなレイヤーに追加します。
- **Move to Layer**：PDF に複数のレイヤーがあるときに表示されます。

選択範囲の内側をドラッグして、選択したストロークをまとめて移動することもできます。

コピーとカットは、同じ PDF 内で貼り付けるためにストロークを保持するもので、システムのクリップボードは使いません。

### 削除のショートカット

選択ツールまたはなげなわでストロークを選択しているときは、次のどちらかのキーを押すと、

- `Delete`
- `Backspace`

選択したストロークを削除できます。

## 取り消し、やり直し、消去

### 取り消しとやり直し

**Undo** と **Redo** はタイトルバーにあります。すべてのページとレイヤーにわたって、PDF の注釈に加えた変更を 1 つずつ取り消したり、やり直したりできます。対象は次のとおりです。

- ストロークの描画、消去、移動、貼り付け、削除、別のレイヤーへの移動
- エリアハイライトの作成、編集、移動、サイズ変更、削除
- レイヤーの追加、名前の変更、非表示、表示、削除
- **Clear Page**
- PDF を開いている間にエージェントが加えた変更

履歴は PDF を開いている間だけ保持されます。PDF を開き直すと、履歴は新しく始まります。

### 現在のページの消去

**Clear Page**（タイトルバーのゴミ箱。タブの幅が狭いときは **More** の中）は、次の範囲にあるストロークをすべて削除します。

- 現在のページ（左下のページ番号に表示されているページ）
- アクティブなレイヤー

<Warning>
  **Clear Page** で削除されるのはストロークだけです。エリアハイライトと、ほかのレイヤーのストロークは残ります。削除したストロークは、取り消し操作で元に戻せます。
</Warning>

## しおり、検索、移動

### PDF のしおり

PDF に目次やしおりが含まれている場合は、タイトルバーの **Bookmarks** をクリックすると、サイドバーに表示されます。

次の操作ができます。

- 入れ子になったしおりを展開したり、折りたたんだりする
- しおりをクリックして、そのページに移動する（ページ番号はタイトルの横に表示されます）
- 現在のページをサイドバーで確認する（そのページのしおりがハイライト表示されます）

目次のない PDF では、**No bookmarks** と表示されます。

### テキストと注釈のコメントの検索

タイトルバーの **Search** をクリックするか、`Cmd/Ctrl + F` を押します。タイトルバーのボタンの代わりに検索フィールドが表示され、結果はサイドバーに表示されます。

PDF の検索では、PDF の本文だけでなく、エリアハイライトのコメントも検索されます。

検索の動作は次のとおりです。

- 入力を止めると間もなく結果が更新され、ビューアーは最初の結果に移動します
- 大文字と小文字は区別されません
- `Enter` または下矢印のボタンで、次の結果に移動します
- `Shift + Enter` または上矢印のボタンで、前の結果に移動します
- `Esc` または閉じるボタンで、検索とその結果を閉じます

### 検索結果の表示

一致するものが見つかると、次のように表示されます。

- ページ上で一致した部分に印が付きます
- 検索フィールドに、現在の結果の位置が `2/7` のように表示されます
- サイドバーにすべての結果が一覧表示されます。クリックすると、その結果に移動します

結果には 2 つの種類があります。

- **テキストの一致**：ページごとにまとめられ、一致のあるページ 1 つが 1 件の結果として数えられます
- **ハイライトのコメントの一致**：ハイライトごとに 1 件ずつ、ハイライトの色、ページ、コメントとともに表示されます

## ズームと閲覧

PDF ビューアーでは、次の操作ができます。

- 左下の **Zoom In** と **Zoom Out** で拡大・縮小する
- 拡大率をクリックして、ページをビューアーの幅に合わせる
- Mac のトラックパッドでピンチする
- `Ctrl` を押しながらスクロールする
- 40%〜400% の範囲で拡大率を変える
- ページ番号をクリックし、ページを入力して `Enter` を押して、そのページに移動する

### 印刷

タイトルバーの **Print** を使うと、表示されているレイヤーの注釈とともに、PDF の全ページが印刷されます。非表示のレイヤーは印刷されません。

### ダークモード

Zditor がダークな外観のときは、読みやすいように PDF のページの色が反転され、暗いページに明るい文字で表示されます。

<Tip>
  反転されるのは PDF のページだけです。注釈はその上の別の層に描かれるので、色は変わりません。
</Tip>

## エージェントとの連携

組み込みの Native Agent は、タブで開いているかどうかにかかわらず、ワークスペース内のどの PDF でも扱えます。次のような作業を頼めます。

- PDF を目次や既存のハイライトとあわせて、ページごとに読む
- 一節を探す
- ページやその一部（図、表、スキャンしたページなど）を見る
- 一節にタイトルとコメント付きのハイライトを付ける、下線や取り消し線を引く、枠で囲む
- フリーハンドで描く、ハイライトを編集・削除する、ストロークを削除する

動作の概要は次のとおりです。

- 新しい注釈は、自分のレイヤーを使うよう指示しない限り、**Agent** という名前のレイヤーに追加されます。そのため、エージェントの作業をまとめて非表示にしたり削除したりできます。
- PDF を開いている場合、エージェントの変更はすぐに表示され、**Undo** で変更のまとまりごとに一度で取り消せます。
- エージェントは作成したハイライトごとに、そのまま使える PDF カードのリンクを受け取るので、Markdown のノートでハイライトを引用できます。
- エージェントのハイライトのサムネイルは、PDF が開いている間に作成されます。PDF が閉じている間に作成されたハイライトについては、PDF を開いて、注釈の一覧で **Regenerate missing thumbnails** を使ってください。
- 読み取り、検索、ページの確認には承認は不要です。注釈の追加、変更、削除は、エージェントの **Permission mode**（権限モード）に従います。

エージェントを AI サービスに接続するには、**Settings → AI → Agents** を開きます。

## パフォーマンスについて

ページの一覧では、表示領域の周辺のページだけが描画されます。

- 表示中のページと、その前後 1 ページずつが完全に描画されます
- それ以外のページは、スクロールの高さを保つプレースホルダーに置き換えられます

これにより、特にページ数の多い PDF、高い拡大率、高解像度のディスプレイで、描画の負荷が軽くなります。

PDF での最初の検索では全ページのテキストを読み込むため、長いドキュメントでは少し時間がかかることがあります。同じ PDF での 2 回目以降の検索では、そのテキストが再利用されます。

## よくある質問

<AccordionGroup>
  <Accordion title="注釈データはどこに保存されますか？" icon="question">
    PDF の隣にある別のファイルです。`paper.pdf` の注釈は `paper.pdf.zditor-pdf-annotation.json` に保存されます。Zditor が注釈を PDF 自体に書き込むことはありません。
  </Accordion>

  <Accordion title="一部の注釈が見当たらないのはなぜですか？" icon="question">
    まず、レイヤーサイドバーでそのレイヤーが非表示になっていないか確認してください。非表示のレイヤーのデータは残っており、そのエリアハイライトは注釈の一覧に引き続き表示されます。また、アクティブなレイヤーが決めるのは新しい注釈の追加先だけで、ほかのレイヤーのデータもそのまま残っています。
  </Accordion>

  <Accordion title="手書きの注釈が検索で見つからないのはなぜですか？" icon="question">
    検索の対象は、PDF のテキストとエリアハイライトのコメントです。手書きやハイライトのタイトルは検索されません。また、OCR は行わないため、テキストレイヤーのないスキャンした PDF は検索できません。
  </Accordion>

  <Accordion title="サムネイルが作成されなかった場合は？" icon="question">
    PDF を開いてレイヤーサイドバーを開き、注釈の一覧でそのハイライトにポインターを合わせて、**Regenerate missing thumbnails** をクリックします。それでも失敗する場合は、**Settings → Editor → PDF Editor → Highlight thumbnails** で保存先を確認してください。
  </Accordion>

  <Accordion title="レイヤーを削除するとどうなりますか？" icon="question">
    レイヤーを削除すると、そのレイヤーに保存されているストロークとエリアハイライトが削除されます。PDF を開いている間は、取り消し操作で元に戻せます。一部のストロークを残したい場合は、先に **Move to Layer** で別のレイヤーに移動してください。エリアハイライトはレイヤー間で移動できません。
  </Accordion>

  <Accordion title="PDF を閉じた後でも変更を取り消せますか？" icon="question">
    いいえ。取り消しの履歴は、PDF を開いている間だけ保持されます。後からエージェントの作業を取り消すには、**Agent** レイヤーを非表示にするか削除します。
  </Accordion>

  <Accordion title="エリアハイライトと通常の蛍光ペンの違いは何ですか？" icon="question">
    蛍光ペンは、フリーハンドで半透明のストロークを描きます。エリアハイライトは、タイトル、コメント、色、サムネイルを持つ構造化された長方形です。移動やサイズ変更ができ、検索でコメントから見つけられ、Markdown に PDF カードとして引用できます。
  </Accordion>
</AccordionGroup>
