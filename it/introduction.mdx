Zditor è un editor Markdown che lavora direttamente sui file di una cartella scelta da te. Scrivi note con formule, note a piè di pagina e metadati strutturati, annota i PDF senza modificarli, disegna sulle lavagne e lascia che l’agente integrato lavori con i tuoi file.
