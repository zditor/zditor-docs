В Zditor есть встроенный агент. Он работает с файлами рабочего пространства: читает и редактирует заметки, аннотирует PDF, строит холсты, выполняет команды и может управлять самим Zditor. Вы выбираете сервис ИИ, на котором он работает, — Zditor AI через ваш аккаунт Zditor или собственный провайдер — и решаете, что агент может делать без спроса.

  <img src="/images/agent.webp" alt="Беседа с агентом в Zditor ждёт одобрения на изменение файла: кнопки Allow once, Always allow и Reject, а под полем сообщения — режим разрешений Always ask" style={{ borderRadius: '0.5rem' }} />
</Frame>

<Warning>
  Агент может менять файлы, выполнять команды, а на Mac — управлять другими приложениями. Читайте каждый запрос, прежде чем одобрить его, и оставайтесь в режиме разрешений **Always ask**, если не уверены в задаче.
</Warning>

Агент также может поручать части большой задачи субагентам, которые работают параллельно, задавать вам вопрос, когда нужно ваше решение, и открывать созданное — например, страницу HTML, изображение или видео — во вкладке Zditor.

<Note>
  На iPhone и iPad, а также в удалённых рабочих пространствах (SSH, S3, WebDAV или Git) агент читает и записывает файлы через Zditor, но не может выполнять команды терминала или управлять другими приложениями. В удалённых рабочих пространствах он не может работать и с Git.
</Note>

## Подключение сервиса ИИ

Без сервиса ИИ агент ничего не может. Откройте **Settings → AI → Agents** и в разделе **Provider** выберите для **AI service** значение **Zditor** или **Custom provider**.

<Tabs>
<Tab title="Zditor AI">
  Для Zditor AI не нужен ключ API. Он доступен, если вы вошли в аккаунт Zditor и у вас есть либо Pro с ежемесячной квотой ИИ, либо бесплатные токены ИИ на аккаунте. Бесплатные токены расходуются на модель Claude Haiku 5.5.

  1. Откройте **Settings → AI → Agents**.
  2. Если вы не вошли в аккаунт, нажмите **Sign in** и завершите вход в браузере.
  3. Выберите для **AI service** значение **Zditor**.

  Zditor загружает доступные модели и их настройки при каждом запуске; кнопка **Update** в разделе **Service configuration** загружает их сразу. Расход показан в разделе **AI usage** в **Settings → Personal → Account**.
</Tab>

<Tab title="Свой провайдер">
  Подключите сервис, который поддерживает OpenAI Responses API или Claude Messages (Anthropic) API, в том числе работающий на вашем компьютере.

  <Steps>
    <Step title="Выберите протокол">
      Выберите для **AI service** значение **Custom provider**, затем в **API protocol** укажите протокол, который поддерживает ваш сервис: **OpenAI Responses** или **Claude Messages (Anthropic)**.
    </Step>

    <Step title="Введите адрес и ключ">
      Введите **Base URL** — корневой адрес API сервиса, который обычно оканчивается на `/v1` (например, `https://api.openai.com/v1` или `https://api.anthropic.com/v1`). Затем введите **API key**; локальным провайдерам ключ может не требоваться. Ключ хранится на этом устройстве и отправляется только по этому адресу.
    </Step>

    <Step title="Добавьте модели">
      В разделе **Model and generation** нажмите **Fetch models**. Модели провайдера появятся со статусом **Not enabled**: откройте каждую нужную и включите переключатель **Enable**. Чтобы добавить модель, которой нет в списке провайдера, введите её ID в **Add model** и нажмите Enter. Модель, добавленная таким образом, сразу включена.
    </Step>

    <Step title="Проверьте лимиты токенов">
      Для каждой включённой модели нужны **Context window tokens** и **Maximum output tokens**. Если провайдер сообщает эти значения, Zditor заполняет их сам (**Server-reported**). Иначе выберите **Enter manually** и укажите значения из документации провайдера.
    </Step>

    <Step title="Сохраните">
      Нажмите **Save**. **Test connection** проверяет адрес и ключ, запрашивая список моделей.
    </Step>
  </Steps>
</Tab>
</Tabs>

### Настройки модели

Чтобы настроить модель, откройте её в разделе **Model and generation**. С Zditor AI эти настройки видны, но изменить их нельзя.

| Параметр | Что делает |
| :--- | :--- |
| **Reasoning effort** | Насколько глубоко модель рассуждает перед ответом. **Automatic** использует значение модели по умолчанию; более высокие уровни требуют больше времени и токенов. |
| **Temperature** | Низкие значения дают более предсказуемые ответы, высокие — более разнообразные. Оставьте поле пустым, чтобы значение выбирал сервис. |
| **Context window tokens**, **Maximum output tokens** | Лимиты модели, полученные от сервиса или введённые вами. |
| **Automatic compaction threshold** | Когда беседа достигает этого числа токенов, Zditor сжимает предыдущий контекст в сводку, чтобы освободить место. По умолчанию — 90% контекстного окна. |

В беседе меню модели вверху (**Model and reasoning effort**) показывает включённые модели и глубину рассуждений. Модель можно сменить прямо во время беседы, а новые беседы начинаются с последней выбранной модели.

## Начало беседы

### Во вкладке агента

Нажмите **+** на панели вкладок, чтобы открыть новую вкладку. Новые вкладки — это вкладки агента. Агент работает в рабочем пространстве, открытом в Zditor, поэтому сначала откройте его: пустая вкладка агента предлагает **Open Workspace** и **New Workspace**. Без рабочего пространства агент работает во временной папке внутри данных приложения Zditor.

### Рядом с документом

В заметке Markdown нажмите **Document sidebar** в строке заголовка и выберите вкладку **Chat**. Чат начинается с прикреплённой заметкой, так что о ней можно спросить сразу. У холстов на боковой панели есть такая же вкладка **Chat**.

Чтобы спросить о части заметки, выделите её и нажмите кнопку с искорками (**ASK AI**) на панели выделения. Откроется вкладка **Chat** с прикреплённым фрагментом. Промпты, заданные в **Settings → AI → AI Toolbar Prompts**, появляются на панели как дополнительные кнопки и сразу отправляют свои инструкции вместе с выделенным фрагментом.

<Note>
  Чаты на боковой панели документа временные и не сохраняются в истории бесед. Для работы, которую нужно сохранить, используйте вкладку агента.
</Note>

### Запрос

Введите текст в поле сообщения и нажмите **Send message**. Пока агент работает, **Stop current turn** останавливает его, а всё, что вы отправите за это время, ждёт в очереди до конца текущего хода.

- Введите `/`, чтобы выполнить команду (см. таблицу ниже).
- Введите `@`, чтобы прикрепить файл из рабочего пространства.
- Введите `$`, чтобы использовать навык.
- Чтобы прикрепить файлы, нажмите **Upload file** (скрепка) или перетащите их на поле сообщения. Изображения, аудио и текстовые файлы вкладываются в сообщение; остальные файлы, например PDF и документы Office, передаются по пути, чтобы агент открыл их сам.

На iPhone и iPad кнопки **Commands**, **Files** и **Skills** под полем сообщения открывают те же списки, что и `/`, `@` и `$`.

При первой отправке сообщения сервису ИИ Zditor спрашивает разрешения на передачу ему данных. См. раздел «Конфиденциальность» ниже.

### Команды

| Команда | Что делает |
| :--- | :--- |
| `/goal` | Задаёт беседе цель, к которой агент движется ход за ходом, пока она не будет достигнута или работа не упрётся в препятствие. Введите `/goal` и формулировку цели, чтобы задать её, `/goal` без текста — чтобы посмотреть её, или `/goal edit`, `/goal pause`, `/goal resume` либо `/goal clear`. Недоступна во временных чатах. |
| `/side` | Открывает временную побочную беседу, которая начинается с текущего контекста. После команды можно сразу написать вопрос. |
| `/compact` | Сжимает беседу в сводку, чтобы освободить контекст, и сохраняет ключевую информацию. |
| `/export` | Сохраняет беседу в формате Markdown или, с `/export json`, в формате JSON. |
| `/share` | Сохраняет беседу как изображение PNG. |

<Tip>
  С активной целью агент продолжает работу без новых сообщений от вас, а каждый ход расходует токены. Чтобы он остановился, приостановите или сбросьте цель.
</Tip>

### Во время работы

Агент показывает работу по ходу дела: какие файлы читает и редактирует, какие команды выполняет и что отвечает. Когда ход заканчивается, его шаги сворачиваются в **Work details**, которые можно развернуть.

- После хода, изменившего файлы, их перечисляет карточка вроде **Changed 2 files**; разверните файл, чтобы увидеть изменения. В локальном рабочем пространстве **Undo** откатывает текстовые изменения этого хода. Если с тех пор файлы изменились, ничего не отменяется.
- **Usage** под полем сообщения показывает, какую часть контекстного окна модели занимает беседа. Zditor автоматически сжимает предыдущий контекст, когда достигнут порог сжатия модели, а `/compact` делает это по запросу.
- Во вкладке агента откройте меню **More** у сообщения и выберите **Branch in new chat**, чтобы продолжить с этого места в новой беседе. Исходная беседа не меняется.
- Если в рабочем пространстве есть файл `AGENTS.md`, агент следует ему как инструкциям проекта.

## Разрешения и одобрения

Выберите режим разрешений (**Permission mode**) под полем сообщения. Zditor запоминает выбор.

| Режим | Что происходит |
| :--- | :--- |
| **Always ask** | Агент спрашивает вас перед каждым ограниченным действием. Это режим по умолчанию. |
| **AI review** | Отдельный запрос к вашей модели проверяет каждое ограниченное действие на соответствие задаче и разрешает или запрещает его. При сомнениях запрещает. Вас не спрашивают, а каждая проверка — это дополнительный запрос к модели. |
| **Full Access** | Все действия инструментов выполняются без спроса. |

В режиме **Always ask** агент спрашивает, прежде чем выполнить команду (в настольном приложении — даже ту, что только читает файлы), изменить файл, воспользоваться Git, отправить веб-запрос, изменить вкладки или настройки Zditor, аннотировать PDF, отредактировать холст, вызвать инструмент MCP, открыть приложение или щёлкать, печатать и прокручивать в нём. Чтение PDF и холстов, проверка открытых вкладок и снимки экрана одобрения не требуют.

В запросе показано действие и три варианта:

- **Allow once** выполняет это действие.
- **Always allow** выполняет его и до конца беседы разрешает такое же действие без спроса — например, ту же команду или новые правки тех же файлов. Для остальных действий запрос остаётся.
- **Reject** не выполняет действие, а агенту сообщается, что вы отказали.

<Tip>
  Задачи в настольном приложении часто требуют множества команд. Если одобрять каждую утомительно, **AI review** — разумный компромисс. **Full Access** используйте только в рабочем пространстве, которое можно восстановить, например в находящемся под контролем версий.
</Tip>

## Управление компьютером на Mac

На Mac в локальном рабочем пространстве агент может управлять другими приложениями, если этого требует задача. Он видит их окна по снимкам экрана и данным универсального доступа и может открывать приложения, щёлкать, печатать, прокручивать и нажимать клавиши.

- В первый раз macOS попросит выдать Zditor разрешения **Screen Recording** (Запись экрана) и **Accessibility** (Универсальный доступ). Если какого-то из них нет, шаг управления компьютером в беседе показывает «macOS is blocking computer use:» и кнопку для каждого недостающего разрешения — **Open Accessibility** или **Open Screen Recording**, которая открывает нужную страницу Системных настроек. Там же любое из этих разрешений можно в любой момент отключить.
- В режиме **Always ask** открытие приложений, щелчки, ввод текста, прокрутка и нажатия клавиш требуют одобрения, а снимки экрана — нет. **Always allow** для одного из этих действий распространяется на другие действия того же вида в этой беседе.
- Пока агент работает, панель показывает приложение, которым он управляет. Если закрыть панель, **Show computer use window** (кнопка с монитором под полем сообщения) вернёт её.

## Серверы MCP и навыки

### Серверы MCP

Серверы MCP подключают агента к другим приложениям и сервисам, например к трекеру задач или базе данных. Добавляйте их в **Settings → AI → MCP Servers**; каждый включённый сервер доступен во всех беседах с агентом. См. [Серверы MCP](/ru/mcp-guide).

### Навыки

Навык — это набор письменных инструкций для одного вида задач, хранящийся в файле `SKILL.md`. Агент знает название и описание каждого навыка и читает полные инструкции, когда задача им соответствует. Чтобы использовать навык намеренно, введите `$` в поле сообщения и выберите его.

- **Встроенные навыки.** **Canvas**, **Markdown** и **Settings and tabs** входят в Zditor. Они перечислены в разделе **Installed skills** в **Settings → AI → Skills**.
- **Собственные навыки.** В **Settings → AI → Skills** нажмите **Add skill**, заполните **Name** (буквы, цифры, дефисы или подчёркивания), **Description** (для чего нужен навык) и **Skill instructions (Markdown)** и нажмите **Save**. Zditor хранит навык в данных приложения, и он доступен во всех ваших локальных рабочих пространствах.
- **Навыки проекта.** Папка навыка с файлом `SKILL.md`, помещённая в `.zditor/skills` внутри рабочего пространства, доступна только в этом рабочем пространстве.
- **Навыки других агентов.** Zditor также подхватывает навыки из папок навыков других агентов, например `.agents/skills`, `.claude/skills` и `.codex/skills` в рабочем пространстве или в домашней папке. В настройках они не отображаются; изменяйте их там, где они лежат.
- **Установка с GitHub.** В настольном приложении можно попросить агента установить навык из папки на GitHub, в которой есть `SKILL.md`. Как и другие изменения, в режиме **Always ask** это требует вашего одобрения.

## История бесед

Беседы во вкладках агента сохраняются автоматически и получают название. Чтобы найти беседу, нажмите **AI conversations** (значок с искорками) на левой боковой панели, ищите по названию или рабочему пространству и нажмите на беседу, чтобы открыть её во вкладке.

При наведении на беседу доступны **Export session** (JSON), **Export as text**, **Copy session ID** и **Delete session**. **Clear History** удаляет все ваши беседы.

## Конфиденциальность

- **Zditor сначала спрашивает.** Когда вы впервые что-то отправляете сервису ИИ, Zditor показывает окно **Allow data sharing with AI?** с получателем, адресом сервиса и перечнем того, что будет отправлено. Пока вы не нажмёте **Allow and continue**, ничего не отправляется; **Not now** отменяет отправку. Для каждого нового адреса сервиса Zditor спрашивает заново.
- **Что отправляется.** Ваши сообщения, история беседы, выделенный текст, добавленные вами изображения, аудио и вложения, а также файлы рабочего пространства, имена файлов и результаты инструментов, которые агент читает для выполнения задачи.
- **Куда отправляется.** Со своим провайдером запросы идут напрямую с вашего устройства на указанный вами **Base URL**, а ключ API хранится на этом устройстве и отправляется только туда. С Zditor AI запросы проходят через сервис Zditor, в записях об использовании которого хранятся модель, число токенов и стоимость каждого запроса, но не ваши сообщения. Серверы MCP получают то, что агент передаёт их инструментам.
- **Где хранятся беседы.** На этом устройстве, в данных приложения Zditor. Резервные копии, созданные в **Settings → Personal → Sync**, их не включают.
- **Отзыв разрешения.** В **Settings → AI → Agents** в разделе **AI data privacy** нажмите **Withdraw permission**. После этого Zditor снова спросит разрешения, прежде чем что-либо отправить. Уже отправленные данные вернуть нельзя.

## Устранение неполадок

<AccordionGroup>
  <Accordion title="Отправка не удаётся: «No AI service is configured»" icon="circle-xmark">
    У агента ещё нет сервиса ИИ. В **Settings → AI → Agents** войдите в аккаунт и выберите **Zditor** или настройте **Custom provider**.
  </Accordion>

  <Accordion title="Ошибка в Fetch models или Test connection" icon="plug">
    Проверьте, что **API protocol** соответствует сервису, что **Base URL** — это корень его API (часто оканчивается на `/v1`) и что ключ API указан верно. Zditor нужен OpenAI Responses API или Claude Messages API; сервис, который предлагает только более старый Chat Completions API, работать не будет. Если провайдер не показывает ни одной модели, введите ID модели в **Add model**.
  </Accordion>

  <Accordion title="При сохранении требуются лимиты контекстного окна и вывода" icon="ruler">
    Для каждой включённой модели нужны оба лимита. Откройте модель, выберите **Enter manually** и введите **Context window tokens** и **Maximum output tokens** из документации провайдера.
  </Accordion>

  <Accordion title="«This response is incomplete»" icon="scissors">
    Модель достигла лимита вывода для одного ответа. Увеличьте **Maximum output tokens** для модели или разбейте задачу на части поменьше.
  </Accordion>

  <Accordion title="«Your input exceeds this model's context window»" icon="triangle-exclamation">
    Сократите сообщение или вложения, выполните `/compact` или переключитесь на модель с более крупным контекстным окном.
  </Accordion>

  <Accordion title="«Model response timed out»" icon="hourglass-half">
    Сервис слишком долго не начинал отвечать. Повторите попытку; если ошибка повторяется, проверьте сервис или попробуйте позже.
  </Accordion>

  <Accordion title="Агент не может выполнять команды или работать с другими приложениями" icon="terminal">
    Для команд нужны настольное приложение и локальное рабочее пространство, а для управления компьютером — ещё и Mac. На iPhone и iPad и в удалённых рабочих пространствах агент вместо этого работает с файлами через Zditor. На Mac проверьте, что у Zditor есть разрешения **Screen Recording** и **Accessibility** в Системных настройках.
  </Accordion>

  <Accordion title="Запросы одобрения постоянно отвлекают" icon="shield-halved">
    В режиме **Always ask** каждая команда требует одобрения. Выбирайте **Always allow** для команды, которая будет повторяться, или переключитесь на **AI review**. **Full Access** используйте только там, где ошибки можно отменить.
  </Accordion>
</AccordionGroup>
