Zditor는 편집, 서식 지정, 구조 변경, 이동을 위한 다양한 키보드 단축키를 지원합니다. 아래 표에는 Markdown 편집기와 앱의 기본 키 바인딩이 정리되어 있습니다.

<Warning>
  `Mod`는 Windows와 Linux에서는 `Ctrl`, macOS에서는 `Command`를 뜻합니다. macOS에서 `Alt`는 `Option` 키입니다.
</Warning>

## 전역 단축키

### 검색과 저장

| 단축키 | 동작 |
| --- | --- |
| `Mod-K` | 검색 열기 |
| `Mod-S` | 현재 문서 저장 |
| `Mod-F` | 현재 문서에서 검색 |

### 보기 모드

활성 Markdown 문서에서 작동합니다. 같은 단축키를 다시 누르면 서식 보기로 돌아갑니다.

| 단축키 | 동작 |
| --- | --- |
| `Mod-E` | 편집 모드와 읽기 전용 모드 전환 |
| `Mod-/` | 서식 보기와 소스 보기 전환 |
| `Mod-\` | 서식 보기와 분할 보기 전환 |

### 화면 확대/축소

| 단축키 | 동작 |
| --- | --- |
| `Mod-=` | 확대 |
| `Mod--` | 축소 |
| `Mod-0` | 확대/축소 초기화 |

## 편집 작업

### 기본 편집

| 단축키 | 동작 |
| --- | --- |
| `Mod-A` | 문서 전체 선택 |
| `Escape` | 편집기에서 포커스 해제 |
| `Shift-Enter` | 새 문단을 시작하지 않고 줄 바꿈 삽입 |

### 실행 취소와 다시 실행

| 단축키 | 동작 |
| --- | --- |
| `Mod-Z` | 실행 취소 |
| `Mod-Y` | 다시 실행 |
| `Mod-Shift-Z` | 다시 실행(대체 단축키) |
| `Backspace` | Zditor가 입력한 내용을 변환한 직후(예: `## `를 제목으로) 그 변환을 취소 |

## 텍스트 서식

### 서식 적용/해제

| 단축키 | 동작 |
| --- | --- |
| `Mod-B` | 굵게 적용/해제 |
| `Mod-I` | 기울임꼴 적용/해제 |
| `Mod-D` | 취소선 적용/해제 |
| `Mod-H` | 하이라이트 적용/해제 |
| `Mod-Shift-C` | 인라인 코드 적용/해제 |
| `Mod-R` | 수정 표시 적용/해제([텍스트 서식과 표시](/ko/text-marks) 참고) |

### 요소 삽입

| 단축키 | 동작 |
| --- | --- |
| `Mod-Shift-E` | 인라인 수식 삽입 |
| `Mod-Shift-D` | 블록 수식 삽입 |
| `Mod-Shift-H` | 구분선(가로줄) 삽입 |
| `Mod-P` | 페이지 나누기 삽입 |
| `Mod-T` | 3 × 3 표 삽입 |

<Note>
  수정 표시와 수식 단축키를 쓰려면 **Track changes** 및 **Math formulas** 플러그인이 필요합니다. 두 플러그인은 **Settings → Integrations → Plugins**에서 기본적으로 켜져 있습니다.
</Note>

## 제목 설정

| 단축키 | 동작 |
| --- | --- |
| `Mod-1` | 제목 1 |
| `Mod-2` | 제목 2 |
| `Mod-3` | 제목 3 |
| `Mod-4` | 제목 4 |
| `Mod-5` | 제목 5 |
| `Mod-6` | 제목 6 |
| `Mod-Shift-P` | 문단으로 변환 |
| `Backspace` | 제목 맨 앞에서 누르면 제목을 다시 문단으로 변환 |

제목에서 그 제목과 같은 수준의 단축키를 누르면 다시 문단으로 바뀝니다.

## 목록 작업

### 목록 만들기

| 단축키 | 동작 |
| --- | --- |
| `Mod-Shift-8` | 글머리 기호 목록 적용/해제 |
| `Mod-Shift-7` | 번호 매기기 목록 적용/해제 |
| `Mod-Shift-9` | 체크박스 목록 적용/해제 |
| `Mod-Shift-B` | 인용문 적용/해제 |

### 목록 항목 작업

| 단축키 | 동작 |
| --- | --- |
| `Enter` | 목록 항목 나누기 |
| `Tab` | 목록 항목 들여쓰기 |
| `Shift-Tab` | 목록 항목 내어쓰기 |
| `Mod-Shift-Enter` | 현재 목록 항목이나 인용문 안에서 새 문단 시작 |
| `Alt-ArrowUp` | 항목을 위로 이동 |
| `Alt-ArrowDown` | 항목을 아래로 이동 |

### 체크박스 작업

| 단축키 | 동작 |
| --- | --- |
| `Mod-Enter` | 체크박스 선택/해제 |
| `Enter` | 체크박스 항목 나누기 |
| `Tab` | 체크박스 항목 들여쓰기 |
| `Shift-Tab` | 체크박스 항목 내어쓰기 |

## 코드 블록 편집

### 코드 블록 만들기

| 단축키 | 동작 |
| --- | --- |
| `Mod-Shift-\` | 코드 블록 적용/해제 |

### 코드 블록 편집과 이동

| 단축키 | 동작 |
| --- | --- |
| `ArrowUp` | 위로 이동, 첫 줄에서는 코드 블록에서 나가기 |
| `ArrowDown` | 아래로 이동, 마지막 줄에서는 코드 블록에서 나가기 |
| `ArrowLeft` | 왼쪽으로 이동, 맨 앞에서는 코드 블록에서 나가기 |
| `ArrowRight` | 오른쪽으로 이동, 맨 끝에서는 코드 블록에서 나가기 |
| `Tab` | 들여쓰기 |
| `Shift-Tab` | 내어쓰기 |
| `Mod-Enter` | 코드 블록에서 나가 아래의 새 문단에서 계속 쓰기 |
| `Backspace` | 코드 블록 맨 앞에서 누르면 다시 문단으로 변환 |

### 코드 블록 서식 지정

| 단축키 | 동작 |
| --- | --- |
| `Mod-Shift-F` | 코드 블록 서식 지정 |
| `Alt-Shift-F` | 코드 서식 지정 대체 단축키 |

## 수식 편집

### 수식 안에서

| 단축키 | 동작 |
| --- | --- |
| `Tab` | 탭 문자 삽입 |
| `Enter` | 블록 수식에서는 새 줄 시작, 인라인 수식에서는 수식에서 나가기 |
| `Mod-Enter` | 수식에서 나가기 |
| `Backspace` | 빈 수식에서 누르면 수식 삭제 |
| `Mod-Backspace` | 수식을 삭제하고 텍스트로 돌아가기 |
| `Mod-A` | 수식 안의 내용 모두 선택 |
| `Mod-M` | 인라인 수식과 블록 수식 전환 |
| `Mod-P` | 수식을 일반 텍스트로 변환 |

### 수식 안에서 이동

| 단축키 | 동작 |
| --- | --- |
| `ArrowLeft` | 왼쪽으로 이동, 맨 앞에서는 수식에서 나가기 |
| `ArrowRight` | 오른쪽으로 이동, 맨 끝에서는 수식에서 나가기 |
| `ArrowUp` | 위로 이동, 첫 줄에서는 수식에서 나가기 |
| `ArrowDown` | 아래로 이동, 마지막 줄에서는 수식에서 나가기 |

블록 수식을 선택한 상태에서 `Enter`를 누르면 편집할 수 있습니다. [수식](/ko/math-formulas)을 참고하세요.

## 표 작업

### 표 안에서 이동

| 단축키 | 동작 |
| --- | --- |
| `Tab` | 다음 셀로 이동, 마지막 셀에서는 행 추가 |
| `Shift-Tab` | 이전 셀로 이동 |

### 표 편집

| 단축키 | 동작 |
| --- | --- |
| `Mod-Enter` | 아래에 행을 추가하고 그 행으로 이동 |
| `Mod-Shift-Enter` | 오른쪽에 열을 추가하고 그 열로 이동 |
| `Mod-Backspace` | 현재 행 삭제 |
| `Mod-Shift-Backspace` | 현재 열 삭제 |

## 기타 작업

### 기타 요소

| 단축키 | 동작 |
| --- | --- |
| `Mod-Shift-M` | Frontmatter가 없는 문서의 첫 문단에서 Frontmatter 블록 추가([Frontmatter](/ko/frontmatter) 참고) |
| `Mod-Shift-V` | HTML 블록 적용/해제 |

### 제안 메뉴

`/`, `@`, `#` 메뉴에서 쓸 수 있는 키입니다.

| 단축키 | 동작 |
| --- | --- |
| `ArrowUp` | 목록에서 위로 이동 |
| `ArrowDown` | 목록에서 아래로 이동 |
| `Tab` / `Shift-Tab` | 다음 또는 이전 항목으로 이동 |
| `ArrowRight` | 강조 표시된 그룹 열기 |
| `ArrowLeft` | 그룹에서 뒤로 가기 |
| `Enter` | 강조 표시된 항목 선택 또는 강조 표시된 그룹 열기 |
| `Escape` | 그룹에서 뒤로 가기 또는 메뉴 닫기 |
| `Backspace` | 한 글자를 지우고 필터 갱신 |

`:` 기호로 여는 이모지 선택기에서는 화살표 키로 격자 안을 이동하고, `Enter`로 강조 표시된 이모지를 삽입합니다. 필터를 입력하기 전에는 `Mod-ArrowLeft` / `Mod-ArrowRight`로 카테고리를 전환할 수 있습니다.

## 단축키 사용자 지정

데스크톱에서 **Settings → Personal → Keyboard shortcuts**를 여세요.

<Steps>
  <Step title="바인딩 찾기">
    이름으로 검색하거나 카테고리를 고르거나, **All Bindings**, **Commands**, **Semantic Intents** 사이를 전환하세요.
  </Step>
  <Step title="새 키 입력">
    바인딩의 키 입력란을 클릭하고 새 키 조합을 누르세요. 취소하려면 `Escape`를 누르세요.
  </Step>
  <Step title="충돌 확인">
    같은 카테고리의 다른 바인딩과 겹치는 바인딩에는 **Conflict** 배지가 표시됩니다. **Conflicts only**는 그런 바인딩만 보여 줍니다.
  </Step>
</Steps>

변경한 바인딩에는 **Customized** 배지와 **Reset to default** 버튼이 표시됩니다. **Reset All**을 누르면 모든 기본값이 복원됩니다.

<Tip>
  **Readonly**로 표시된 바인딩은 바꿀 수 없습니다. 검색, 저장, 확대/축소, 코드 블록과 수식 안의 키, 그리고 `Enter`, `Tab`, `Backspace` 같은 시맨틱 키가 여기에 해당합니다. 변경 사항은 즉시 적용됩니다.
</Tip>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="단축키가 작동하지 않는 이유는 무엇인가요?" icon="question">
    편집기에 포커스가 있는지, 현재 노드 유형이 해당 동작을 지원하는지, **Settings → Personal → Keyboard shortcuts**에서 바인딩을 바꾸지 않았는지, 운영 체제가 단축키를 먼저 가로채지 않았는지 확인하세요.
  </Accordion>

  <Accordion title="macOS에서는 단축키가 다른가요?" icon="question">
    바인딩은 같습니다. `Mod`를 macOS에서는 `Command`로, 다른 시스템에서는 `Ctrl`로 바꿔 읽고, 단축키에 `Alt`가 있으면 `Option`을 누르세요.
  </Accordion>

  <Accordion title="모든 단축키를 바꿀 수 있나요?" icon="question">
    아니요. 설정에서 **Readonly**로 표시된 바인딩은 기본값이 그대로 유지되며, 일부 단축키는 운영 체제가 예약해 두고 있습니다.
  </Accordion>
</AccordionGroup>
