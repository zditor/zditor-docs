지식 그래프는 Zditor의 대표 기능 중 하나입니다. 작업 공간의 파일과 파일 사이의 링크를 인터랙티브한 힘 기반 그래프로 바꿔 주므로, 구조와 참조 관계, 클러스터를 한눈에 볼 수 있습니다.

## 한눈에 보기

왼쪽 탐색 막대의 **Graph** 버튼으로 그래프를 여세요. 그래프는 탭으로 열리며 현재 작업 공간을 보여 줍니다.

각 Markdown(`.md`) 파일이 노드가 되며, 그 노트가 링크하는 모든 파일도 노드가 됩니다. 각 링크는 링크가 들어 있는 파일에서 링크가 가리키는 파일로 향하는, 방향이 있는 관계가 됩니다. 레이아웃이 노드를 자동으로 배치하므로 화면을 이동하거나 확대/축소하며 관계를 살펴보는 동안에도 그래프를 읽기 쉽게 유지합니다. 점이 클수록 연결이 많은 파일입니다.

## 링크 해석 방식

그래프는 작업 공간에 있는 Markdown 파일 안의 링크로 만들어집니다.

### Markdown 링크 문법

Zditor는 표준 Markdown 링크와 이미지를 인식합니다.

```markdown
[Link Text](file/path.md)
![Alt text](images/diagram.png)
```

오디오, 동영상, PDF 카드, 캔버스, SuperTag 참조(`[text](path|mode=...)`)처럼 Zditor가 삽입 콘텐츠용으로 작성하는 링크도 포함됩니다.

<AccordionGroup>
  <Accordion title="링크 구성 요소" icon="link" defaultOpen>
    **링크 텍스트**
    - `[]` 안의 내용
    - 그래프에서 관계 레이블로 사용됨
    - 관계의 의미를 설명함

    **링크 경로**
    - `()` 안의 내용
    - 대상 파일을 가리킴
    - 대상 노드를 결정함
  </Accordion>

  <Accordion title="링크가 관계로 바뀌는 방식" icon="diagram-project">
    각 링크는 방향이 있는 관계가 됩니다.

    - 링크가 들어 있는 파일이 **소스**입니다
    - 링크된 파일이 **대상**입니다
    - 관계는 소스에서 대상으로 향합니다
    - 링크 텍스트가 관계 레이블로 표시됩니다
  </Accordion>

  <Accordion title="방향 확인" icon="arrow-right">
    파일이나 관계를 선택하면 링크가 어느 쪽을 가리키는지 볼 수 있습니다. **Show directional flow**를 켜 두면 선택한 관계를 따라 작은 점이 소스에서 대상으로 움직입니다.

    파일의 세부 정보 패널에는 나가는 링크가 **References** 아래에, 들어오는 링크가 **Referenced by** 아래에 나열됩니다. 이를 통해 허브 파일, 많이 참조되는 자료, 서로 링크하는 파일을 찾아낼 수 있습니다.
  </Accordion>

  <Accordion title="관계 유형" icon="tags">
    관계는 링크 종류에 따라 **Images**, **Audio**, **Videos**, **PDF Card**, **Attachment**, **Embed**, **Excalidraw**, **Supertag**, **Data Table**, 그리고 일반 링크용 **Other**로 묶입니다. 일부 유형은 파선이나 점선으로 그려집니다.

    SuperTag 레코드에는 클래스의 스키마 파일로 향하는 **Data Table** 관계도 생기며, 이 관계의 레이블은 클래스 이름입니다.
  </Accordion>
</AccordionGroup>

### 같은 파일 사이의 여러 링크

<AccordionGroup>
  <Accordion title="같은 방향의 여러 링크" icon="arrows-turn-right">
    파일 A가 서로 다른 링크 텍스트로 파일 B를 여러 번 링크하면, 그래프는 관계를 각각 별도의 곡선으로 그려 하나의 선으로 합쳐지지 않고 모두 보이게 합니다. 한 파일 안에서 같은 텍스트로 반복된 같은 링크는 한 번으로 셉니다.
  </Accordion>

  <Accordion title="양방향 링크" icon="arrows-left-right">
    A가 B를 링크하고 B도 A를 링크하면 두 관계가 겹치지 않도록 서로 다른 곡선으로 그려집니다. 파일이 자기 자신을 링크하면 고리 모양으로 그려집니다.
  </Accordion>
</AccordionGroup>

### 해석 규칙과 제한

<Warning>
  현재 해석 규칙은 다음과 같습니다.

  - 링크를 찾기 위해 스캔하는 파일은 `.md`로 끝나는 파일뿐입니다. `.mdx`와 `.markdown` 파일을 포함한 다른 파일은 노트가 링크할 때만 나타납니다
  - 표준 링크 `[text](path)`와 이미지 `![alt](path)`를 해석합니다
  - `http://` 또는 `https://`로 시작하는 웹 링크는 무시합니다
  - `[[page]]` 같은 위키 링크, 참조 스타일 링크, `<a>` 같은 HTML 태그는 해석하지 않습니다
  - `/`로 시작하는 경로는 작업 공간 루트를 기준으로, 그 밖의 경로는 링크가 들어 있는 파일의 폴더를 기준으로 해석합니다
  - 경로 끝의 `#heading` 부분은 무시하므로, 제목으로 향하는 링크는 파일로 향하는 링크로 간주합니다
  - 숨김 파일과 폴더는 스캔하지 않으며, `.ignore` 파일이나 Git 저장소의 `.gitignore`로 제외된 파일도 스캔하지 않습니다
</Warning>

<Tip>
  관계 레이블이 그래프에서 유용하고 읽기 쉽도록 링크 텍스트는 간결하고 설명적으로 쓰세요.
</Tip>

존재하지 않는 파일을 가리키는 링크도 노드를 만듭니다. 이런 노드는 속이 빈 파선 원으로 그려지며, 제목 표시줄에 보이는 개수가 **2 missing**처럼 표시됩니다.

그래프는 로컬 작업 공간을 대상으로 합니다. 그래프를 열면 Zditor가 작업 공간 인덱스를 업데이트합니다. **Settings → Personal → General**에서 **Watch workspace files**가 켜져 있으면(기본값) 노트를 저장하는 즉시 변경 사항이 그래프에 반영됩니다. 언제든 다시 스캔하려면 제목 표시줄의 **Refresh file index**를 클릭하세요.

### 예시

```markdown
<!-- docs/README.md -->
- [Quickstart](./quickstart.md)
- [API Docs](./api.md)

<!-- docs/quickstart.md -->
Read [README](./README.md) first
See [API Docs](./api.md)
```

이렇게 하면 다음과 같은 관계가 만들어집니다.

```text
README.md ----[Quickstart]----> quickstart.md
README.md ----[API Docs]-----> api.md
quickstart.md --[README]-----> README.md
quickstart.md --[API Docs]---> api.md
```

## 화면 구성

그래프 보기는 다음 부분으로 구성됩니다.

### 제목 표시줄

제목 표시줄에는 **Graph**와 현재 보이는 파일과 관계의 수(예: **42 files · 57 relations**)가 표시되며, 없는 파일이 있으면 그 수도 표시됩니다. 오른쪽에는 **Search**와 **Refresh file index**가 있습니다.

### 기본 캔버스

캔버스에는 노드와 관계가 표시되며, 자유롭게 이동하고 확대/축소할 수 있습니다.

### 확대/축소 컨트롤

왼쪽 아래 모서리에는 **Zoom out**, 현재 확대 비율, **Zoom in**, **Fit to view**가 있습니다. 확대 비율을 클릭하면 100%로 돌아갑니다.

### 그래프 컨트롤

오른쪽 아래 모서리에는 패널이 세 개 있습니다.

- **Filters**: 파일 유형, 관계 유형, 고립된 파일
- **Color legend**: 사용 중인 색상과 각 개수
- **Display**: 색상, 레이블, 방향 흐름, 관계선 불투명도, 레이아웃

### 세부 정보 패널

파일이나 관계를 선택하면 오른쪽 위 모서리에 세부 정보 패널이 열립니다.

<Tip>
  확대할수록 그래프에 세부 정보가 더해집니다. 연결이 가장 많은 파일부터 파일 레이블이 더 많이 나타나고, 이어서 관계 레이블이 나타나며, 노드가 커지면서 파일 유형 아이콘이 표시됩니다.
</Tip>

## 파일 유형 인식

기본적으로 노드는 파일 유형별로 색이 칠해집니다. 유형별 색상을 보려면 **Color legend**를 여세요.

| 유형 | 확장자 |
| --- | --- |
| **Markdown** | `.md`, `.mdx`, `.markdown` |
| **Images** | `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.webp`, `.avif`, `.heic`, `.bmp`, `.tiff` 및 기타 이미지 형식 |
| **Videos** | `.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`, `.flv`, `.wmv` |
| **Audio** | `.mp3`, `.wav`, `.ogg`, `.flac`, `.aac`, `.m4a`, `.wma` |
| **Code** | `.js`, `.ts`, `.py`, `.json`, `.yaml`, `.html`, `.css`, `.txt` 같은 소스, 웹, 구성, 일반 텍스트 파일 |
| **PDF** | `.pdf` |
| **Documents** | `.doc`, `.docx`, `.rtf`, `.odt`, `.xls`, `.xlsx`, `.ppt`, `.pptx`, `.csv` |
| **Other** | 캔버스(`.excalidraw`)를 포함한 그 밖의 모든 파일 |

노드를 커뮤니티별로 색칠할 수도 있습니다. [표시 설정](#표시-설정)을 참고하세요.

## 검색

### 검색 방법

1. 제목 표시줄의 **Search**를 클릭하거나 `/`를 누릅니다
2. 파일 이름, 폴더, 링크 텍스트의 일부를 입력합니다
3. 마우스나 `↑`, `↓`, `Enter`로 결과를 선택합니다

결과를 선택하면 해당 항목이 선택되고 세부 정보가 열립니다. **Locate in graph**를 클릭하면 화면 가운데로 옮겨집니다.

### 검색 범위

<AccordionGroup>
  <Accordion title="파일 검색" icon="circle-nodes">
    `README`나 `projects`처럼 파일 이름이나 경로에 포함된 폴더로 검색합니다.
  </Accordion>

  <Accordion title="관계 검색" icon="link">
    링크 텍스트나 링크된 파일의 경로로 검색합니다.
  </Accordion>
</AccordionGroup>

검색은 현재 필터로 숨겨진 항목을 포함해 그래프 전체를 대상으로 하며, 결과는 최대 30개까지 표시됩니다. 숨겨진 항목을 선택하면 세부 정보 패널에 **Adjust filters to show this item**이 표시됩니다.

## 필터

필터를 사용해 지금 작업에 필요한 내용만 그래프에 남기세요. 오른쪽 아래 모서리의 **Filters**를 여세요.

### 필터 옵션

- **File types**: Markdown, Images, Videos, Audio, Code, PDF, Documents, Other
- **Relation types**: Images, Audio, Videos, PDF Card, Attachment, Embed, Excalidraw, Supertag, Data Table, Other
- **Show isolated files**: 링크가 하나도 없는 파일 표시 또는 숨기기
- **Reset filters**: 모든 항목 다시 표시

<Tip>
  각 유형에는 파일이나 관계의 수가 표시되며, 여러 유형을 한꺼번에 끌 수 있습니다. **Filters** 버튼에는 몇 개가 숨겨져 있는지 표시됩니다. **Color legend**에서 파일 유형을 클릭해도 표시하거나 숨길 수 있습니다.
</Tip>

<Warning>
  필터를 적용한 뒤에는 소스 파일과 대상 파일이 모두 보일 때만 관계가 표시됩니다.
</Warning>

  </Accordion>

  <Accordion title="Show directional flow" icon="arrow-right">
    선택한 관계, 또는 선택한 파일의 모든 관계의 방향을 애니메이션으로 보여 줍니다. 기본적으로 켜져 있습니다.
  </Accordion>

  <Accordion title="Edge opacity" icon="minus">
    관계선을 얼마나 진하게 그릴지 5%에서 80% 사이로 설정합니다. 기본값은 28%입니다.
  </Accordion>
</AccordionGroup>

### 레이아웃 설정

<AccordionGroup>
  <Accordion title="Pause layout / Resume layout" icon="pause">
    레이아웃을 멈추거나 다시 시작합니다. 그래프가 안정되면 레이아웃은 저절로 멈춥니다.
  </Accordion>

  <Accordion title="Reset layout and pinned positions" icon="arrows-rotate">
    고정된 노드를 모두 풀고 그래프를 처음부터 다시 배치합니다.
  </Accordion>
</AccordionGroup>

<Note>
  **Resume layout**을 누르면 노드가 안정될 때까지 다시 움직이며, 레이아웃이 일시 정지되지 않은 상태에서 노드를 드래그해도 마찬가지입니다. 필터와 표시 설정은 그래프 탭에 속하므로 탭을 닫으면 저장되지 않습니다.
</Note>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="그래프가 비어 있는 이유는 무엇인가요?" icon="question">
    그래프는 로컬 작업 공간의 `.md` 파일을 색인합니다. 로컬 작업 공간이 열려 있는지, 노트가 `.md`로 끝나는지, 숨겨진 폴더나 제외된 폴더에 있지 않은지 확인한 다음 **Refresh file index**를 클릭하세요. 화면에 **No files match these filters**가 표시되면 **Reset filters**를 선택하세요.
  </Accordion>

  <Accordion title="일부 노드가 캔버스 밖에 있는 이유는 무엇인가요?" icon="question">
    **Fit to view**를 클릭하거나, 축소하거나, 파일을 검색한 뒤 **Locate in graph**를 클릭하세요.
  </Accordion>

  <Accordion title="고정된 노드 위치를 초기화하려면 어떻게 하나요?" icon="question">
    **Display**를 열고 **Reset layout and pinned positions**를 선택하세요.
  </Accordion>

  <Accordion title="더블클릭해도 파일이 열리지 않는 이유는 무엇인가요?" icon="question">
    파일이 존재하지 않을 수 있습니다. 없는 파일은 속이 빈 파선 원으로 그려지며 열 수 없습니다. 두 번 클릭하는 사이에 노드를 드래그하지 않았는지도 확인하세요.
  </Accordion>

  <Accordion title="관계선이 겹치는 이유는 무엇인가요?" icon="question">
    확대하거나, 먼저 파일을 선택하거나, 노드를 더 멀리 떨어뜨리세요. **Edge opacity**를 낮추면 복잡한 영역도 더 읽기 쉬워집니다.
  </Accordion>

  <Accordion title="그래프를 내보내거나 공유할 수 있나요?" icon="question">
    아직 내장된 내보내기 기능은 없습니다. 현재 화면을 캡처해야 한다면 시스템의 스크린샷 도구를 사용하세요.
  </Accordion>

  <Accordion title="그래프가 계속 움직이는 이유는 무엇인가요?" icon="question">
    레이아웃은 안정될 때까지 움직이며, 노드를 드래그하면 다시 움직이기 시작합니다. 멈추려면 **Display**에서 **Pause layout**을 선택하고, 기준 노드 몇 개를 고정해 배치를 안정적으로 유지하세요.
  </Accordion>
</AccordionGroup>

## 키보드 단축키

그래프가 키보드 포커스를 받도록 먼저 캔버스를 클릭하세요.

| 단축키 | 기능 |
| --- | --- |
| `/` | 검색 열기 |
| `Esc` | 현재 노드 또는 관계 선택 해제 |
| `+` 또는 `=` | 확대 |
| `-` | 축소 |
| `Enter` | 선택한 파일 열기 |
| 화살표 키 | 선택한 노드를 조금씩 이동(노드가 고정됨) |

<Note>
  그래프는 그래픽 카드로 그려지며, 편집을 방해하지 않도록 레이아웃은 백그라운드에서 계산됩니다. 시스템에서 동작 줄이기가 설정되어 있으면 레이아웃이 일시 정지된 상태로 시작하고 방향 흐름도 애니메이션으로 표시되지 않습니다. 그래프를 그릴 수 없으면 **Unable to load the graph. Please retry.** 메시지와 **Retry** 버튼이 표시됩니다.
</Note>
