Zditor supports standard Markdown footnote syntax, so you can add references, notes, and supporting details without interrupting the main text.

## Overview

<CardGroup cols={2}>
  <Card title="Standard syntax" icon="hashtag">
    Use standard Markdown footnote references such as `[^1]`.
  </Card>

  <Card title="Bottom summary" icon="list-ol">
    All footnotes are collected automatically at the end of the document.
  </Card>

  <Card title="Floating editor" icon="pen-to-square">
    Click a footnote reference to review or edit the matching content quickly.
  </Card>

  <Card title="Synced updates" icon="arrows-rotate">

  </Card>

## Create footnotes

<AccordionGroup>
  <Accordion title="Markdown syntax" icon="code" defaultOpen>
    Insert a footnote reference such as:

    ```markdown
    This paragraph has a footnote[^1], and it can have another one[^2].
    ```

    After you enter `[^1]`, Zditor converts it into a superscript footnote number.
  </Accordion>

  <Accordion title="Auto-conversion rules" icon="sparkles">
    Footnotes convert automatically when you type `[^` + number + `]`.

    **Notes**
    - Typing converts numeric labels only, such as `[^1]` and `[^2]`
    - The same label always points to the same footnote content
    - If the label is already used in the document, the new reference shares its existing text
  </Accordion>
</AccordionGroup>

## Edit footnote content

A new footnote starts with empty content unless its label is already in use. You can edit the content in two ways.

### Edit from the floating toolbar

<Steps>
  <Step title="Select a reference">
    Click a footnote number in the document.
  </Step>
  <Step title="Open the editor">
    The floating toolbar shows the label, such as `[^1]`, and the current content, or **No corresponding footnote** when it is empty. Click **Edit**.
  </Step>
  <Step title="Save or cancel">
    Press `Enter` or click **Save** to keep the new content, or click **Cancel**.
  </Step>
</Steps>

Clicking the label in the toolbar jumps to the matching entry in the bottom list.

### Edit from the bottom list

<Steps>
  <Step title="Scroll to the bottom">
    When a document contains footnotes, Zditor renders a footnote list below the main body.
  </Step>
  <Step title="Click the content">
    Click an entry's text to edit it inline.
  </Step>
  <Step title="Save changes">
    Press `Enter` or click elsewhere to save.
  </Step>
</Steps>

<Tip>
  Editing one footnote updates every reference that uses the same label.
</Tip>

## Display behavior

### Inline references

Footnotes appear as superscript references in the body. Hovering over a reference shows the current footnote content in a tooltip.

### Bottom list

The document bottom shows an ordered list of all distinct footnotes:

- Each item shows the label and content; bold, italics, inline code, and link text in the content appear formatted
- Repeated labels are deduplicated automatically
- Numeric labels are sorted in numeric order
- Clicking an item's label jumps to the first reference with that label

### In the Markdown file

When Zditor saves the document, it writes each footnote's content once, as a standard definition at the end of the file:

```markdown
This paragraph has a footnote[^1].

[^1]: The footnote content.
```

A reference in Markdown source only becomes a footnote when the file has a matching definition. When you type `[^1]` in rich text, Zditor adds the definition for you on save.

## Example

```markdown
Quantum computing uses quantum mechanics for information processing[^1],
and in some problems it can outperform classical systems[^2].

Common hardware approaches include superconducting qubits[^1] and trapped ions.

[^1]: An introduction to quantum hardware.
[^2]: The advantage depends on the problem.
```

In that example:

- `[^1]` appears twice and shares one footnote body
- `[^2]` remains independent
- The bottom list contains two entries, `1` and `2`

## FAQ

<AccordionGroup>
  <Accordion title="Can footnotes use text labels?">
    Typing in the editor only converts numeric labels such as `[^1]`. A text label such as `[^source]` still works when the file defines it with a line such as `[^source]: …`, which is how footnotes often arrive from other Markdown editors.
  </Accordion>

  <Accordion title="How do I delete a footnote?">
    Select the footnote reference and press `Delete` or `Backspace`. Once all references with the same label are removed, the bottom entry disappears automatically, and Zditor no longer writes its definition when saving.
  </Accordion>

  <Accordion title="What if two references with the same label show different content?">
    Zditor keeps them synchronized. Editing any instance updates all references that share that label.
  </Accordion>

  <Accordion title="How do footnotes behave in read-only mode?">
    References, their tooltips, and the bottom list still render, and clicking a label in the list still jumps to its reference, but editing is disabled.
  </Accordion>
</AccordionGroup>
