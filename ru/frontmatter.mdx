Frontmatter — это блок метаданных YAML в начале документа. В Zditor его можно редактировать в наглядной таблице — диалоге **Document properties**, — так что не придётся править каждое поле вручную. Кроме того, Zditor показывает свойства в шапке над документом.

## Базовый синтаксис

Frontmatter заключается между строками `---` в самом начале файла:

```yaml
---
title: "My document"
date: 2024-01-15
tags: [product, notes]
draft: true
---

Document content starts here...
```

## Поддерживаемые форматы

<AccordionGroup>
  <Accordion title="Краткий формат" icon="bolt" defaultOpen>
    Пишите простые пары «ключ: значение», а тип поля редактор определит сам.

    ```yaml
    ---
    title: "Document title"
    count: 42
    done: true
    tags: [tag-1, tag-2]
    ---
    ```

    **Правила определения типа**
    - Списки вида `[a, b]` становятся `array`
    - `true` и `false` становятся `checkbox`
    - Числа становятся `number`
    - Даты вида `2024-01-15` остаются `text`; для поля даты используйте полный формат с `type: date`
    - Остальные строки становятся `text`
    - Ключи без значения игнорируются
  </Accordion>

  <Accordion title="Полный формат" icon="sliders">
    Явно задаёт тип, подпись, описание и значение поля, а для полей `select` и `multiselect` — ещё и варианты.

    ```yaml
    ---
    status:
      type: select
      label: "Status"
      description: "Current document status"
      value: "In Progress"
      options: [Todo, In Progress, Done]
    priority:
      type: number
      label: "Priority"
      value: 3
    ---
    ```

    Поле в полном формате должно иметь один из типов, перечисленных ниже. Вложенную запись без `type` или с неизвестным типом Zditor игнорирует.
  </Accordion>
</AccordionGroup>

## Типы полей

| Тип | Как отображается в редакторе | Описание | Пример |
|------|------|------|--------|
| `text` | Text | Текстовая строка | `"Hello"` |
| `number` | Number | Числовое значение | `42` |
| `checkbox` | Toggle | Логическое значение | `true` / `false` |
| `date` | Date | Дата | `2024-01-15` |
| `datetime` | Date and time | Дата и время | `2024-01-15T10:30` |
| `time` | Time | Время | `10:30` |
| `array` | List | Массив строк | `[tag-1, tag-2]` |
| `select` | Select | Один вариант из `options` | `"Option A"` |
| `multiselect` | Multi-select | Несколько вариантов из `options` | `[Option A, Option B]` |
| `progress` | Progress | Прогресс от 0 до 100 | `75` |
| `asset` | Image | Путь к изображению или URL | `"cover.png"` |

## Визуальный редактор

В Zditor есть табличный редактор Frontmatter, поэтому не нужно править YAML вручную при каждом изменении. Чтобы открыть его, нажмите **Edit properties** (значок тега) в строке заголовка документа Markdown в режиме форматированного текста или в разделённом виде. Документ должен быть доступен для редактирования.

### Таблица свойств

На вкладке **Properties** диалога **Document properties** поля перечислены в таблице со столбцами:

- **Property** — отображаемое имя поля и под ним ключ, если они различаются
- **Type** — вид поля
- **Value** — текущее значение; его редактируют элементом управления, подходящим к типу

Кнопка с шестерёнкой в конце строки открывает настройки свойства:

- **Property key** — имя поля; чтобы переименовать его, нажмите **Update key**
- **Display name** — подпись, которая показывается в редакторе
- **Field description** — дополнительный контекст
- **Options** — варианты для `select` и `multiselect`
- **Delete property** — удаление поля

Над таблицей можно искать по свойствам и нажать **Export CSV**, а кнопка **Layout fields** дополнительно показывает скрытые по умолчанию настройки шапки `row`, `col`, `warm`, `warmDark` и `display`.

Если вы меняете тип поля, а значение нельзя преобразовать, Zditor спрашивает, что сделать: **Keep value** или **Reset value and change type**.

Изменения сохраняются, только когда вы нажимаете **Apply** или `Cmd + Enter` (`Ctrl + Enter` в Windows и Linux). **Cancel** отменяет их.

### Добавление полей

<AccordionGroup>
  <Accordion title="Своё поле" icon="plus" defaultOpen>
    Нажмите **Add property**, введите **Property key**, выберите **Type** и при желании укажите **Display name** и **Field description**. Затем нажмите **Add property** на панели.
  </Accordion>

  <Accordion title="Готовые поля" icon="ellipsis">
    На той же панели выберите **Property preset**, чтобы подставить ключ и тип распространённого поля. Пресеты, которые уже есть в документе, не предлагаются.

    **Text**
    - Title, Subject, Description, Author

    **Image**
    - Avatar, Cover, `coverDark`

    **Date**
    - Created, Updated

    **List**
    - Tags
    - Information row (`row`) и Title area (`col`)

    **Toggle**
    - Favorite, Template
    - Show property summary (`display`), Warm tone (`warm`), `warmDark`
  </Accordion>
</AccordionGroup>

### Макет шапки

Вкладка **Header layout** определяет, как свойства выглядят над документом:

- **Cover image**: изображение за шапкой. Без него шапка оформляется только текстом.
- **Title area**: свойства, которые показываются как **Eyebrow**, **Title** и **Description**. Сохраняются в `col`.
- **Information row**: свойства, которые показываются строкой под заголовком в заданном вами порядке. Меняйте порядок перетаскиванием или кнопками со стрелками, а новые свойства добавляйте через **Add to information row…**. Сохраняются в `row`.
- Переключатели **Show property summary** и **Warm tone**, которые сохраняются в `display` и `warm`.

Пока вы их не настроили, в области заголовка показываются `subject`, `title` и `description`, а в информационной строке — `avatar`, `author`, `updated`, `created` и `tags`, если у них есть значения. До четырёх других заполненных свойств выводятся сводкой под шапкой.

## Обложка

Обложка документа задаётся полем `cover`.

<Steps>
  <Step title="Добавьте поле обложки">
    Откройте **Document properties**, перейдите на вкладку **Header layout** и нажмите **Choose image** в разделе **Cover image**. Можно также ввести в поле путь или URL. Zditor сохранит его в поле `cover` типа `asset`.
  </Step>
  <Step title="Выберите изображение">
    В окне выбора изображения три вкладки: **Upload** — загрузить изображение с компьютера, **Library** — найти изображение в рабочем пространстве, **Link** — вставить URL изображения и нажать **Apply**.
  </Step>
  <Step title="Настройте оформление">
    Наведите указатель на обложку, чтобы появилась её панель, и нажмите **Toggle Tone**, чтобы переключиться между тёплым и холодным тоном. Тёплый тон — это тёмный текст для светлых изображений, холодный — белый текст для тёмных. На той же панели есть **Change Cover**, **Edit properties**, **Copy Meta Information**, **Refresh** и **Delete Meta Information**.
  </Step>
</Steps>

<Tip>
  Чтобы в тёмном режиме показывалась другая обложка, добавьте пресет `coverDark`. Её тон хранится в `warmDark`.
</Tip>

## Специальные поля

| Поле | Значение |
|------|------|
| `class` | Категория или имя таблицы для SuperTag; должно быть текстовым полем |
| `field` | В файле схемы SuperTag — список полей, которые есть у записей класса |
| `row` | Поля в информационной строке шапки |
| `col` | Поля в области заголовка шапки, не более трёх |
| `cover` | Путь к обложке или её URL |
| `coverDark` | Обложка для тёмного режима |
| `warm` | Тон обложки: `true` — тёплый, `false` — холодный |
| `warmDark` | Тон для `coverDark` |
| `display` | `false` скрывает сводку свойств под шапкой |
| `template` | `true` добавляет документ в **Templates** в меню `/` и на боковой панели **Calendar**. Выбор шаблона в меню `/` заменяет текущий документ его копией |
| `favorites` | `true` добавляет документ на вкладку **Favorites** боковой панели **Calendar**. Обратите внимание на множественное число: пресет **Favorite** добавляет поле `favorite`, которое эта вкладка не читает |

## Частые вопросы

<AccordionGroup>
  <Accordion title="Отображается ли Frontmatter в тексте документа?">
    В режиме форматированного текста — нет: Zditor скрывает блок YAML и вместо него показывает свойства в шапке над документом. В режиме исходного текста виден сам YAML, и его можно редактировать там.
  </Accordion>

  <Accordion title="Как экспортировать данные Frontmatter?">
    В **Document properties** нажмите **Export CSV**, чтобы сохранить свойства текущего документа в файл CSV со столбцами Property, Type, Value, Label, Description и Options.
  </Accordion>

  <Accordion title="Можно ли сочетать краткий и полный формат?">
    Да. Zditor читает оба формата в одном документе и сам определяет типы полей краткого формата. Когда вы применяете изменения в **Document properties** или с панели обложки, Zditor переписывает весь блок в полном формате, а записи, которые он не смог прочитать (например, ключи без значения), удаляются.
  </Accordion>

  <Accordion title="Как удалить весь Frontmatter?">
    В режиме исходного текста удалите блок YAML между открывающей и закрывающей строками `---`. Если у документа есть обложка, можно также нажать **Delete Meta Information** на панели обложки.
  </Accordion>
</AccordionGroup>
