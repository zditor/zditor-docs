侧边文件树是 Zditor 的核心功能之一，让你可以直接浏览、新建、重命名、移动和整理当前工作区中的文件。

## 界面概览

文件树就是侧边栏中的 **文件** 面板。点击左侧导航栏顶部的文件夹图标即可显示它。未启用筛选时，它会显示工作区中的所有文件和文件夹，包括名称以点开头的项目。

### 顶部工具栏

文件树顶部显示当前工作区的名称，点击它可以切换工作区（见 [工作区管理](#工作区管理)）。名称旁边有三个按钮：

- **新建文件**：在工作区根目录新建文件
- **新建文件夹**：在工作区根目录新建文件夹
- **更多**：打开一个菜单，其中包括：
  - **筛选**：只显示特定类型的文件
  - **刷新**：重新扫描工作区
  - **收起**：收起所有展开的文件夹
  - **清理剪切板**：取消尚未粘贴的复制或剪切（仅在有内容被复制或剪切时显示）
  - **打开文件夹**：在系统文件管理器中打开工作区

文件树加载、刷新或导入文件时，工具栏下方会出现一条细细的进度条。

### 文件列表

主列表显示文件和文件夹，并用缩进表示层级关系。把鼠标悬停在某一项上，可以查看它的完整路径。

### 底部栏

面板底部的栏分为三部分：

- 左侧的 **+** 按钮会在工作区根目录新建一个名为 `untitled1.md`（或下一个可用编号）的空 Markdown 文件并打开它。
- 中间的工作区名称会打开系统的文件夹选择器，让你切换到另一个本地文件夹。
- 右侧的 **⋮** 按钮会打开一个面板，其中有排序选项、最近打开的文件夹，以及你设置过的远程工作区。

## 基础操作

<AccordionGroup>
  <Accordion title="单击操作" icon="mouse">
    - 单击文件，在标签页中打开它
    - 单击文件夹，展开或折叠它
  </Accordion>

  <Accordion title="右键菜单" icon="bars">
    - 右键点击文件，可以执行 **右侧分屏打开**、**重命名**、**复制** 等操作
    - 右键点击文件夹，可以在其中新建项目或粘贴内容
    - 右键点击列表下方的空白区域，可以打开工作区根目录的菜单
  </Accordion>
</AccordionGroup>

### 选择文件

单击文件或文件夹即可选中，选中项会高亮显示。

### 重命名

<AccordionGroup>
  <Accordion title="重命名方法" icon="pen">
    1. 右键点击文件或文件夹，选择 **重命名**
    2. 或者把鼠标悬停在该项上，点击它的 **…** 按钮，再选择 **重命名**
    3. 按 `Enter` 确认，按 `Esc` 取消。点击其他位置也会确认新名称。
  </Accordion>
</AccordionGroup>

<Tip>
  重命名文件时，只会选中扩展名之前的部分，你可以直接输入新名称并保留扩展名。
</Tip>

## 文件与文件夹管理

### 新建文件和文件夹

<AccordionGroup>
  <Accordion icon="plus" title="方式一：使用顶部工具栏">
    点击工具栏中的 **新建文件** 或 **新建文件夹**，在工作区根目录中新建项目。
  </Accordion>

  <Accordion icon="folder-plus" title="方式二：使用悬停快捷按钮">
    鼠标悬停在文件夹上时，会出现快捷操作按钮。

    - `+`：在此文件夹中新建文件
    - 文件夹图标：新建子文件夹
  </Accordion>

  <Accordion icon="computer-mouse" title="方式三：右键菜单">
    右键点击目标文件夹（或者右键点击列表下方的空白区域，在工作区根目录中新建），选择 **新建文件** 或 **新建文件夹**。
  </Accordion>
</AccordionGroup>

新建文件时，Zditor 会显示一个名称输入框，后面跟着一个扩展名输入框。扩展名一开始是你的默认扩展名（如果没有改过，就是 `.md`）：

- 按 `↑` 或 `↓` 切换到列表中的其他扩展名
- 在名称末尾输入列表中的某个扩展名（例如 `notes.txt`），即可切换到该扩展名
- 在名称末尾按 `→`，光标会移到扩展名输入框

你可以在 **设置 → 个人 → 通用 → 文件类型** 中修改默认扩展名和扩展名列表。

### 删除文件和文件夹

1. 右键点击要删除的文件或文件夹
2. 选择 **删除**

如果该文件（或文件夹中的任何内容）已在标签页中打开，Zditor 会先询问是否关闭这些标签页并删除；否则会立即删除。

<Warning>
  删除不会把项目移到系统的废纸篓或回收站，并且无法撤销。删除文件或文件夹前请仔细确认。
</Warning>

### 复制、剪切和粘贴

<AccordionGroup>
  <Accordion icon="copy" title="复制">
    1. 右键点击文件或文件夹，选择 **复制**
    2. 该项会显示黄色边框和 **复制** 标记
  </Accordion>

  <Accordion icon="scissors" title="剪切">
    1. 右键点击文件或文件夹，选择 **剪切**
    2. 该项会显示青色边框和 **剪切** 标记
  </Accordion>

  <Accordion icon="paste" title="粘贴">
    1. 右键点击目标文件夹，或者右键点击列表下方的空白区域（粘贴到工作区根目录）
    2. 选择 **粘贴**
    3. 该项会被复制或移动到目标位置
  </Accordion>
</AccordionGroup>

<Tip>
  剪贴板一次只能存放一个项目，粘贴后会被清空。你不能把项目粘贴到它自身中，不能把它移动到它自己的子文件夹中，也不能把它粘贴到已有同名项目的文件夹中。
</Tip>

## 排序与筛选

### 按文件类型筛选

在顶部工具栏中打开 **更多 → 筛选**，可以只显示特定类型的文件：

| 筛选项 | 显示内容 |
| --- | --- |
| **全部** | 所有文件和文件夹 |
| **Markdown** | `.md`、`.mdx`、`.markdown` |
| **文档** | `.pdf`、`.doc`、`.docx`、`.txt`、`.csv`、`.xls`、`.xlsx`、`.ppt`、`.pptx` |
| **资源** | 图片、视频和音频文件 |
| **代码** | 源代码、网页和配置文件，例如 `.ts`、`.js`、`.py`、`.json`、`.yaml`、`.html` 和 `.css` |
| **Excalidraw** | 画布文件（`.excalidraw`） |
| **隐藏** | 名称以点开头的文件和文件夹 |
| **其他** | 不属于以上任何类别的文件 |

可以同时启用多个筛选项。选择 **全部** 会关闭其他筛选项。启用筛选时，**筛选** 菜单项会显示已选类型的数量，**更多** 按钮上会出现一个圆点。

文件夹始终保留在列表中，方便你找到其中符合条件的文件。只要启用了筛选，名称以点开头的项目都会被隐藏，除非所选筛选项中包括 **隐藏**。

### 排序选项

点击底部栏中的 **⋮** 按钮，排序按钮位于面板顶部：

#### 排序方式

- **按字母顺序排序**：按名称排列
- **按创建时间排序**：按文件的创建时间排列
- **按修改时间排序**：按文件的最后修改时间排列

#### 排序方向

- 箭头按钮可以在 **升序排列** 和 **降序排列** 之间切换

#### 文件夹分组

- **按文件夹分组**：把文件夹排在文件前面

默认情况下，文件树按字母顺序升序排列，并把文件夹排在前面。名称以点开头的项目排在其他项目之前。

## 拖拽操作

文件树支持通过拖拽管理文件。

<AccordionGroup>
  <Accordion icon="file-import" title="移动文件或文件夹">
    1. 拖动要移动的文件或文件夹
    2. 把它拖到目标文件夹上
    3. 松开鼠标完成移动
  </Accordion>

  <Accordion icon="upload" title="从外部导入文件">
    把系统文件管理器中的文件或文件夹拖到文件树中的某个文件夹上（或者拖到空白区域，放入工作区根目录），即可把它们复制到工作区中。拖入的文件会替换该文件夹中的同名文件。文件树底部会短暂显示一行状态，告诉你添加了多少个文件。
  </Accordion>

  <Accordion icon="home" title="拖拽到根目录">
    把项目拖到文件树的空白区域，即可把它们移动到工作区根目录。
  </Accordion>
</AccordionGroup>

<Tip>
  拖拽时，目标文件夹会高亮显示。在折叠的文件夹上悬停约 600 毫秒，它会自动展开。拖到列表顶部或底部边缘附近时，列表会自动滚动。
</Tip>

## 右键菜单

文件和文件夹都提供了丰富的右键菜单。把鼠标悬停在某一项上时出现的 **…** 按钮，也能打开同样的菜单。

### 文件右键菜单

| 选项 | 功能说明 |
| --- | --- |
| **打开** | 在左侧窗格打开文件 |
| **右侧分屏打开** | 在右侧窗格打开文件 |
| **重命名** | 重命名文件 |
| **复制** | 复制文件到剪贴板 |
| **剪切** | 剪切文件到剪贴板 |
| **粘贴** | 在文件上不可用；请粘贴到文件夹或工作区根目录 |
| **在文件夹中打开** | 在系统文件管理器中显示该文件 |
| **复制文件路径** | 复制文件的完整路径到剪贴板 |
| **另存为** | 把文件的副本保存到这台电脑上你选择的位置 |
| **删除** | 删除文件 |

### 文件夹右键菜单

文件夹菜单包含 **重命名**、**复制**、**剪切**、**粘贴**、**在文件夹中打开**、**复制文件路径** 和 **删除**，此外还有：

| 选项 | 功能说明 |
| --- | --- |
| **新建文件** | 在该文件夹中新建文件 |
| **新建文件夹** | 新建子文件夹 |

### 根目录右键菜单

在文件树的空白区域右键点击，可以打开工作区根目录的菜单：

- **新建文件** 和 **新建文件夹**：在根目录中新建项目
- **粘贴**：把复制或剪切的项目粘贴到根目录
- **刷新**：重新扫描工作区
- **折叠所有**：折叠所有展开的文件夹
- **在文件夹中打开**：在系统文件管理器中打开工作区
- **复制文件路径**：复制工作区的路径

## 工作区管理

工作区就是文件树所显示的那个文件夹。在空白标签页中，你也可以选择 **打开工作区** 打开一个已有的文件夹，或者选择 **新建工作区** 创建一个空文件夹并打开它。

### 切换工作区

1. 点击文件树顶部的工作区名称
2. 从菜单中选择一个工作区，或者选择 **打开目录**，在系统文件夹选择器中挑选文件夹
3. Zditor 会加载新的工作区

如果打开了智能体标签页，Zditor 会请你确认切换，因为这些标签页与当前工作区的连接会被关闭。标签页和会话历史会保留，回到该工作区时会重新连接。

<Tip>
  每个工作区都可以拥有自己的窗口。选择 **在新窗口中打开文件夹…**，或者在菜单中按住 `Cmd` 点击某个工作区（Windows 和 Linux 上按住 `Ctrl`），即可在新窗口中打开它。如果某个工作区已在另一个窗口中打开，选择它会把那个窗口切换到最前面。
</Tip>

### 远程工作区

工作区不一定要在这台电脑上。在 **设置 → 集成 → 连接** 中添加连接：

- **S3** 存储、**WebDAV** 服务器和 **SSH** 主机上的文件夹，会在工作区菜单和 **⋮** 面板中各自成组显示。
- **Git** 连接会在本地保留仓库的克隆，并像普通文件夹一样打开它。

在 S3、WebDAV 和 SSH 工作区中，**在文件夹中打开** 不可用；服务器上的文件发生变化时，文件树也不会自动刷新。请使用 **刷新** 查看最新的文件。

### 最近文件夹

工作区菜单会列出你最近使用的本地文件夹。底部栏的 **⋮** 面板中也会列出它们，并且可以在那里管理：

<AccordionGroup>
  <Accordion icon="thumbtack" title="固定文件夹">
    点击图钉图标，可以把重要的文件夹固定在最近列表的顶部。
  </Accordion>

  <Accordion icon="trash" title="删除最近记录">
    对于未固定的文件夹，点击垃圾桶图标可以把它从最近列表中移除。
  </Accordion>
</AccordionGroup>

列表最多保留五个文件夹，固定的文件夹始终保留在列表中。启动时，Zditor 会重新打开你上次使用的工作区；如果希望启动时不打开工作区，请在 **设置 → 个人 → 通用** 中关闭 **重新打开上次工作区**。

### 自动刷新

在本地工作区中，文件树会监视工作区根目录和每个展开的文件夹：

- 无论是在 Zditor 还是在其他应用中新建、删除或重命名文件，文件树都会随之更新
- 重新展开的文件夹会被重新扫描，因此它折叠期间发生的变化也会显示出来

## 常见问题

<AccordionGroup>
  <Accordion title="为什么某些文件在文件树中不显示？" icon="question">
    检查是否启用了文件类型筛选：启用时，**更多** 按钮上会显示一个圆点。把 **更多 → 筛选** 改回 **全部** 即可。启用其他任何筛选项时，名称以点开头的文件和文件夹都会保持隐藏，除非你同时选择了 **隐藏**。
  </Accordion>

  <Accordion title="拖拽文件时没有反应？" icon="question">
    在折叠的文件夹上多停留一会儿，等它展开。你不能把项目移动到它自身、它的子文件夹或它当前所在的文件夹中；如果目标位置已有同名项目，移动也会被拒绝。
  </Accordion>

  <Accordion title="如何快速找到最近修改的文件？" icon="question">
    在 **⋮** 面板中选择 **按修改时间排序**，并把排序方向设为降序。
  </Accordion>

  <Accordion title="可以同时打开多个文件吗？" icon="question">
    可以。每次点击文件，它都会在自己的标签页中打开。使用 **右侧分屏打开** 可以并排查看两个文件。
  </Accordion>

  <Accordion title="为什么“在文件夹中打开”不可用？" icon="question">
    S3、WebDAV 和 SSH 工作区不在这台电脑上，因此没有可以在系统文件管理器中显示的本地文件夹。
  </Accordion>
</AccordionGroup>
