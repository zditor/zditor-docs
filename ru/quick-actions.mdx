## Перетаскивание

### Пять сценариев перетаскивания

Zditor поддерживает несколько сценариев перетаскивания.

#### 1. Внутри дерева файлов

Файлы и папки в дереве файлов слева можно перетаскивать внутри дерева, чтобы изменить их расположение в рабочем пространстве.

Это пригодится, когда нужно:

- Перестроить структуру папок
- Перенести файлы в другую папку
- Навести порядок в рабочем пространстве

#### 2. Из дерева файлов в документ Markdown

Файлы из дерева слева можно перетащить прямо в документ Markdown.

Перетащенный файл вставляется как **узел вложения** со ссылкой на файл там, где он уже лежит в рабочем пространстве. Копию Zditor не создаёт.

Чтобы вместо этого показать файл как изображение, видео, аудиоплеер или холст:

1. Нажмите на вложение, откройте его меню **More** и выберите **Convert to Link**.
2. Нажмите на появившуюся ссылку и выберите нужную кнопку на панели ссылки: **Convert to image**, **Convert to video**, **Convert to audio** или **Convert to canvas**. Показываются только кнопки, подходящие к типу файла.

Для файла холста (`.excalidraw`) в меню **More** вложения есть и прямой пункт **Convert to Canvas**.

Это удобно, если вы хотите сначала вставить файл, а уже потом решить, как его показать.

#### 3. Внешние файлы в документ Markdown

Файлы из системного файлового менеджера можно перетаскивать прямо в документ Markdown.

Zditor вставляет их в зависимости от типа:

- Изображения → узлы изображений
- Видеофайлы → узлы видео
- Аудиофайлы → узлы аудио
- Файлы холстов (`.excalidraw`) → узлы холстов
- Прочие файлы → узлы вложений

Копию каждого перетащенного файла Zditor сохраняет в место, заданное в **Settings → Integrations → Image hosting & uploads**. Это самый быстрый способ добавить локальные материалы в заметки и документы.

#### 4. Узлы между документами Markdown

Узлы можно перетаскивать между разными документами Markdown, например между левой и правой панелями разделённого окна.

Между документами по умолчанию выполняется **копирование**: целевой документ получает копию, а оригинал остаётся в исходном документе.

Это пригодится, когда нужно:

- Перенести черновик в итоговый документ
- Повторно использовать блоки в соседних панелях
- Перераспределить содержимое между несколькими заметками

#### 5. Внутри одного документа

Внутри одного документа блоки можно перетащить на новое место без вырезания и вставки.

В пределах одного документа по умолчанию выполняется **перемещение**.

Это пригодится, когда нужно:

- Изменить порядок абзацев
- Перестроить разделы
- Переместить текст, изображения или блоки кода в более подходящее место

### Маркеры перетаскивания в редакторе

Когда при редактировании вы наводите указатель на блок, Zditor показывает на левом поле маркер перетаскивания. На маркере рядом со значком захвата указан тип блока (для заголовков — от `H1` до `H6`). Перетаскивание маркера перемещает весь блок.

Такой маркер есть у каждого блока верхнего уровня, например:

- Абзацы
- Заголовки
- Списки
- Цитаты
- Изображения
- Видео
- Блоки кода
- Вложения
- Выноски
- Таблицы
- Блочные формулы

Список перемещается целиком. Чтобы переместить отдельный пункт списка, используйте `Alt-ArrowUp` и `Alt-ArrowDown`.

<Warning>
  **Сообщите о проблемах с перетаскиванием**

  Если какой-то тип узла перетаскивается неправильно, например:

  - Его не удаётся перетащить
  - Он оказывается не на том месте
  - После перетаскивания его содержимое искажается

  сообщите об ошибке, и мы продолжим устранять недочёты.
</Warning>

### Где обычно появляются маркеры перетаскивания

Начать перетаскивание можно из двух мест:

- **Левое поле**: маркер, который появляется при наведении, — для любого блока верхнего уровня
- **Панель инструментов**: кнопка **Drag** на панели выбранного изображения, видео, аудиофайла, вложения, холста, встраивания, блока кода, таблицы, блока HTML или формулы

<Tip>
  Главная польза перетаскивания — в структурном редактировании. Когда вы перестраиваете длинные заметки, черновики или планы, оно гораздо быстрее, чем вырезание и вставка.
</Tip>

## Сочетания клавиш

Сочетания клавиш — один из самых быстрых способов ускорить работу в Zditor.

Чаще всего они нужны, чтобы:

- Сохранить документ
- Найти текст
- Задать уровень заголовка
- Включить или снять полужирный, курсив, выделение цветом и код в строке
- Создать список, цитату, таблицу, блок кода или формулу

### Самые полезные сочетания

| Сочетание | Действие |
| --- | --- |
| `Mod-K` | Открыть поиск |
| `Mod-S` | Сохранить текущий документ |
| `Mod-F` | Найти в текущем документе |
| `Mod-/` | Переключение между форматированным и исходным текстом |
| `Mod-B` | Полужирный |
| `Mod-I` | Курсив |
| `Mod-H` | Выделение цветом |
| `Mod-Shift-C` | Код в строке |
| От `Mod-1` до `Mod-6` | Уровень заголовка |
| `Mod-Shift-8` | Маркированный список |
| `Mod-Shift-7` | Нумерованный список |
| `Mod-Shift-9` | Список с флажками |
| `Mod-Shift-\` | Блок кода |
| `Mod-T` | Создать таблицу |

<Warning>
  `Mod` означает:
  <ul>
    <li><strong>macOS</strong>: `Command`</li>
    <li><strong>Windows / Linux</strong>: `Ctrl`</li>
  </ul>
</Warning>

### Когда сочетания клавиш особенно полезны

Сочетания клавиш особенно удобны, когда:

- Вы уже знаете, какое форматирование или какая структура вам нужны
- Не хочется отвлекаться на мышь и сбиваться с ритма
- Вы много раз повторяете одно и то же действие

Полный список сочетаний и инструкции по изменению привязок в **Settings → Personal → Keyboard shortcuts** — на странице [Сочетания клавиш](/ru/keyboard-shortcuts).

## Меню по символам

Меню по символам — самый быстрый способ вызвать структурированные действия с клавиатуры.

### Меню команд `/`

В документе Markdown введите `/` в начале строки или после пробела, чтобы открыть меню команд. Продолжайте вводить текст, чтобы отфильтровать пункты: фильтр ищет во всех группах. Выберите пункт клавишами со стрелками и `Enter`.

В меню есть:

- От **Heading 1** до **Heading 3**, а также **Heading 4-6**
- **List**: список с флажками, маркированный и нумерованный списки
- **Media**: изображение, видео, аудио, холст и вложение — каждое выбирается через окно выбора файла
- **MetaInfo**: блок Frontmatter в начале документа
- **Code Block**: таблица, HTML, цитата, блок кода, блочная формула, разделитель, разрыв страницы и диаграмма Mermaid
- **Info**: выноски пяти типов — информация, заметка, предупреждение, совет и ошибка
- **Templates**: появляется, если у вас есть документы с `template: true` во Frontmatter. Выбор шаблона заменяет содержимое текущего документа этим шаблоном.

Это помогает:

- Не набирать одно и то же снова и снова
- Быстро находить доступные команды
- Работать более структурированно

В поле сообщения агента `/` показывает другой список — команды беседы: `/share`, `/export`, `/goal`, `/compact` и `/side`. Там же `@` упоминает файл рабочего пространства, а `$` выбирает навык. Подробнее — в [руководстве по агенту](/ru/agent-guide).

### Другие меню в редакторе

Помимо `/`, в редакторе есть ещё несколько распространённых меню, вызываемых символами:

- `@`: ссылка на файл Markdown или PDF в рабочем пространстве. Если в PDF есть выделения, можно выбрать одно из них и вставить его как карточку PDF.
- `#`: вставка или создание элементов SuperTag
- `:`: окно выбора эмодзи; продолжайте вводить, чтобы отфильтровать эмодзи по названию

Каждое меню можно отключить в **Settings → Editor → Markdown Editor**: за них отвечают параметры **Command menu (/)**, **Link menu (@)**, **Object menu (#)** и **Emoji menu (:)**.

<Tip>
  Если вы часто повторяете одни и те же действия в редакторе, меню по символам обычно быстрее и надёжнее, чем каждый раз набирать один и тот же синтаксис.
</Tip>

## Панели инструментов

В Zditor нет одной постоянной панели форматирования. Вместо неё появляются контекстные панели, которые зависят от того, что вы выделили.

### Панели выделения

Когда вы выделяете текст или узел, редактор может показать подходящую панель, например:

- Панель форматирования текста
- Панель ссылки
- Панели изображения, видео и аудио
- Панель вложения
- Панель холста
- Панель встраивания
- Панели блока кода и блока HTML
- Панель формулы
- Панель таблицы
- Панель выноски
- Панель сноски
- Панель пояснений и правок
- Панель SuperTag
- Панель карточки PDF

Поэтому весь синтаксис не обязательно помнить заранее. Обычно достаточно:

1. Сначала выделить нужный фрагмент
2. Применить или настроить действие на панели

Чтобы скрыть эти панели, отключите **Selection toolbar** в **Settings → Editor → Markdown Editor**.

### Как работают панели

<AccordionGroup>
  <Accordion title="Зависят от выделенного объекта" icon="arrows-rotate" defaultOpen>
    Для разных объектов — разные панели: для текста — инструменты форматирования, для изображений — инструменты изображения, для карточек PDF — собственная панель карточки PDF.
  </Accordion>

  <Accordion title="Могут открывать дополнительные панели" icon="layer-group">
    Некоторые кнопки открывают вторую плавающую панель с более детальными параметрами или вариантами.
  </Accordion>

  <Accordion title="Редактирование на месте" icon="pen-to-square">
    Панели появляются рядом с выделенным фрагментом, так что взгляд не уходит от того, что вы редактируете.
  </Accordion>

  <Accordion title="Могут передать выделенное агенту" icon="sparkles">
    На многих панелях есть кнопка **ASK AI**: она открывает агента рядом с документом и прикрепляет выделенный фрагмент. Промпты, добавленные в **Settings → AI → AI Toolbar Prompts**, появляются на панелях как дополнительные кнопки.
  </Accordion>
</AccordionGroup>

### Когда панели особенно удобны

Панели обычно удобнее, когда:

- Вы знаете, что нужно отредактировать, но не хотите вспоминать синтаксис
- Хочется сначала увидеть доступные действия, а потом решить
- Вы работаете с визуальными узлами: изображениями, вложениями, карточками PDF или SuperTag

## Рекомендуемый порядок освоения

Если вы только начинаете работать с Zditor, удобно осваивать его в таком порядке:

1. Освойте перетаскивание для структурного редактирования
2. Запомните несколько самых полезных сочетаний клавиш
3. Начните пользоваться меню `/`, `@`, `#` и `:`
4. Привыкните к панелям разных объектов в реальной работе над текстом
