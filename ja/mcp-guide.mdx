MCP（Model Context Protocol）は、AI エージェントをツールやデータに接続するためのオープンな標準規格です。Zditor に MCP サーバーを追加すると、エージェントは組み込みのツールに加えて、そのサーバーのツールをすべての会話で使えるようになります。

<Warning>
  信頼できるサーバーだけを接続してください。**Stdio** サーバーは、あなたのアクセス権限でパソコン上で動くプログラムです。また、どのサーバーも、エージェントがそのツールに送る内容を受け取ります。
</Warning>

## MCP が必要な場面

エージェントはもともと、ファイル、PDF、キャンバスを扱い、コマンドを実行し、Zditor 自体を操作できます（[エージェントガイド](/ja/agent-guide)を参照）。課題管理ツール、データベース、ナレッジベース、ほかのアプリのデータなど、それ以上のものがタスクに必要なときに MCP サーバーを追加します。

## サーバーの追加

<Steps>
  <Step title="MCP の設定を開く">
    **Settings → AI → MCP Servers** を開き、**Add server** をクリックします。
  </Step>

  <Step title="サーバーに名前を付ける">
    **Server name** を入力します。この名前は、一覧、状態の表示、ツールの呼び出しでサーバーを識別するために使われるので、ほかと重複しない名前にする必要があります。`zditor` という名前は予約されています。
  </Step>

  <Step title="接続方法を選ぶ">
    **Transport** で、Zditor にパソコン上のプログラムとしてサーバーを起動させる場合は **Stdio** を、Web アドレスにあるサーバーに接続する場合は **HTTP** または **SSE** を選びます。続けて、そのトランスポート用の項目を入力します（下の表を参照）。
  </Step>

  <Step title="テストして保存する">
    **Test connection** をクリックします。接続に成功すると、見つかったツールの数が表示されます。その後、**Save** をクリックします。
  </Step>
</Steps>

| 項目 | トランスポート | 入力する内容 |
| :--- | :--- | :--- |
| **Command** | Stdio | サーバーを起動するプログラム（`npx` や実行ファイルのフルパスなど）。必須です。 |
| **Arguments** | Stdio | プログラムに渡すコマンドライン引数。スペースを含む値は引用符で囲みます。 |
| **Environment variables** | Stdio | サーバーのプロセスに設定する名前と値（API トークンなど）。 |
| **Endpoint URL** | HTTP、SSE | `http://` または `https://` で始まる、サーバーの完全なアドレス。必須です。 |
| **Request headers** | HTTP、SSE | すべてのリクエストと一緒に送る名前と値。一般的には、ベアラートークンを指定した `Authorization` です。 |

<Tip>
  MCP サーバーの追加、変更、削除をエージェントに頼むこともできます。**Always ask** モードでは、設定の変更にあなたの承認が必要です。
</Tip>

## サーバーのオンとオフ

一覧の各サーバーにはスイッチがあります。オフにしたサーバーは **Disabled** と表示され、会話からは接続されず、そのツールも読み込まれません。サーバーのフォームの **Status** にも同じスイッチがあります。

変更は、すでに開いている会話も含め、エージェントの次のターンから反映されます。サーバーを変更するには **Edit** をクリックします。**Discard** を選ぶと保存していない変更が破棄され、**Delete** に続けて **Confirm delete** を選ぶとサーバーが削除されます。

## 会話での MCP ツールの使用

会話ごとにサーバーを選ぶ必要はありません。有効なサーバーはすべて、エージェントとのどの会話でも使えます。エージェントはタスクに必要なときにサーバーのツールを探します。依頼の中でサーバー名やツール名を挙げると、エージェントが選びやすくなります。

- **Always ask** モードでは、MCP ツールを呼び出すたびにあなたの承認が必要です。サーバーが提供するリソースの読み取りには承認は不要です。
- サーバーが作業中に情報の入力を求めることがあります。その場合、会話にそのサーバーのフォームが表示されるので、入力して **Submit** をクリックするか、**Decline** をクリックします。サーバーが Web ページへのアクセスを求めた場合は、**Open and continue** でそのページを開けます。

## iPhone と iPad の場合

iPhone と iPad では Zditor がプログラムを起動できないため、**HTTP** または **SSE** のサーバーを使ってください。

## 以前の組み込み Zditor MCP サービス

<Note>
  以前のバージョンの Zditor には、`open_file`、`list_supertag_classes`、`list_agent_sessions`、`generate_image` などのツールを提供する組み込みの MCP サービスがありました。このサービスは、現在の Zditor には含まれていません。代わりに、エージェントには Zditor を操作するための独自のツールがあり、ワークスペースと開いているタブの読み取り、ファイルを開く操作、タブの切り替えと終了、設定の変更、PDF とキャンバスの操作ができます。SuperTag、セッション履歴、画像のツールには、組み込みの代替機能はありません。以前の設定から残っている `zditor` という名前のサーバーは自動的に削除され、この名前は予約されています。
</Note>

## 権限と安全性

- タスクに必要なサーバーだけを有効にし、使っていないサーバーはオフにしてください。
- ツールで何かを変更できるサーバーには、**Always ask** を使い続けてください。
- トークンやキーは、メッセージではなく **Environment variables** または **Request headers** に入力してください。フォームでは、表示を選ぶまで値は伏せられます。
- これらの値を含むサーバーの設定は、このデバイスに保存されます。**Settings → Personal → Sync** で **Connections and credentials** をバックアップしている場合は、暗号化されたバックアップに含まれます。
- トークンは権限の範囲が限られたものを使い、定期的に更新してください。

## よくある質問

<AccordionGroup>
  <Accordion title="Stdio サーバーで Test connection が失敗する" icon="terminal">
    Zditor はサーバー自身のエラー出力を表示しないため、ターミナルで同じコマンドを実行して原因を確認してください。プログラムが見つからない場合は、**Command** にフルパスを入力します。Dock や Finder から開いたアプリには、ターミナルと同じ `PATH` が渡らないことがあります。サーバーがほかのプログラム（`npx` に必要な Node.js など）を使う場合は、ターミナルで `echo $PATH` を実行した出力を値として、`PATH` 環境変数を追加してください。
  </Accordion>

  <Accordion title="HTTP または SSE のサーバーで Test connection が失敗する" icon="globe">
    **Endpoint URL** と **Request headers** に、期限切れのトークンなどの問題がないか確認してください。Zditor はすべてのリクエストをエンドポイント URL に HTTP POST で送り、JSON またはイベントストリームの応答を受け付けます。そのため、イベントストリーム用に別のアドレスを使う古い SSE トランスポートにしか対応していないサーバーには、接続できないことがあります。サーバーに Streamable HTTP 用のアドレスがあれば、そちらを使ってください。
  </Accordion>

  <Accordion title="サーバーに接続できているのに、エージェントが使わない" icon="question">
    サーバーのスイッチがオンになっていること、**Test connection** でツールが見つかることを確認してください。そのうえで、依頼の中でサーバー名やツール名を挙げてください。エージェントは、タスクに必要だと判断したときに MCP ツールを探します。
  </Accordion>

  <Accordion title="サーバーを追加したら応答が遅くなった" icon="hourglass-half">
    Zditor は、会話でのエージェントの最初のターンの前と、サーバーの一覧を変更した後に、有効なサーバーをすべて起動します。そのため、起動の遅いサーバーがあると応答も遅れます。不要なサーバーはオフにしてください。
  </Accordion>
</AccordionGroup>
