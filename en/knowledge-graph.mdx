The knowledge graph is one of Zditor's standout features. It turns the files in your workspace and the links between them into an interactive force-directed graph, so you can see structure, references, and clusters at a glance.

## Overview

Open the graph with the **Graph** button in the navigation rail on the left. It opens in a tab and shows the current workspace.

Each Markdown (`.md`) file becomes a node, and so does every file those notes link to. Each link becomes a directed relation from the file that contains it to the file it points to. The layout places nodes automatically and keeps the graph readable while you pan, zoom, and inspect relationships. Larger dots are files with more connections.

  </Card>

  <Card title="Navigate faster" icon="compass">

## How links are parsed

The graph is built from the links inside the Markdown files of your workspace.

### Markdown link syntax

Zditor recognizes standard Markdown links and images:

```markdown
[Link Text](file/path.md)
![Alt text](images/diagram.png)
```

Links that Zditor writes for embedded content, such as audio, video, PDF cards, canvases, and SuperTag references (`[text](path|mode=...)`), count as well.

<AccordionGroup>
  <Accordion title="Link parts" icon="link" defaultOpen>
    **Link text**
    - The content inside `[]`
    - Used as the relation label in the graph
    - Describes the meaning of the relationship

    **Link path**
    - The content inside `()`
    - Points to the target file
    - Determines the target node
  </Accordion>

  <Accordion title="How links map to relations" icon="diagram-project">
    Each link becomes a directed relation:

    - The file that contains the link is the **source**
    - The linked file is the **target**
    - The relation points from source to target
    - The link text is shown as the relation label
  </Accordion>

  <Accordion title="Seeing the direction" icon="arrow-right">
    Select a file or a relation to see which way links point. With **Show directional flow** turned on, small dots move along the selected relations from source to target.

    The details panel of a file lists its outgoing links under **References** and its incoming links under **Referenced by**. This helps you spot hub files, heavily referenced resources, and files that link to each other.
  </Accordion>

  <Accordion title="Relation types" icon="tags">
    Relations are grouped by the kind of link: **Images**, **Audio**, **Videos**, **PDF Card**, **Attachment**, **Embed**, **Excalidraw**, **Supertag**, **Data Table**, and **Other** for plain links. Some types are drawn with dashed or dotted lines.

    SuperTag records also get a **Data Table** relation to their class's schema file, labeled with the class name.
  </Accordion>
</AccordionGroup>

### Multiple links between the same files

<AccordionGroup>
  <Accordion title="Multiple links in the same direction" icon="arrows-turn-right">
    If file A links to file B several times with different link text, the graph draws each relation as its own curve so they remain visible instead of collapsing into one line. The same link repeated with the same text in one file counts once.
  </Accordion>

  <Accordion title="Links in both directions" icon="arrows-left-right">
    When A links to B and B links back to A, the two relations are drawn on separate curves so they do not overlap. A link from a file to itself is drawn as a loop.
  </Accordion>
</AccordionGroup>

### Parsing rules and limits

<Warning>
  Current parsing rules:

  - Only files ending in `.md` are scanned for links. Other files, including `.mdx` and `.markdown` files, appear only when a note links to them
  - Standard links `[text](path)` and images `![alt](path)` are parsed
  - Web links starting with `http://` or `https://` are ignored
  - Wiki links like `[[page]]`, reference-style links, and HTML tags such as `<a>` are not parsed
  - A path starting with `/` is resolved from the workspace root; other paths are resolved from the folder of the file that contains the link
  - A `#heading` part at the end of a path is ignored, so links to a heading count as links to the file
  - Hidden files and folders are not scanned, nor are files excluded by an `.ignore` file or, in a Git repository, by `.gitignore`
</Warning>

<Tip>
  Use concise, descriptive link text so relation labels remain useful and readable in the graph.
</Tip>

A link to a file that does not exist still creates a node. These nodes are drawn as hollow, dashed circles, and the title bar shows how many are visible, for example **2 missing**.

The graph covers local workspaces. When you open it, Zditor updates its index of the workspace. While **Watch workspace files** is on in **Settings → Personal → General** (the default), changes to your notes appear in the graph as you save them. Click **Refresh file index** in the title bar to rescan at any time.

### Example

```markdown
<!-- docs/README.md -->
- [Quickstart](./quickstart.md)
- [API Docs](./api.md)

<!-- docs/quickstart.md -->
Read [README](./README.md) first
See [API Docs](./api.md)
```

That produces relationships like:

```text
README.md ----[Quickstart]----> quickstart.md
README.md ----[API Docs]-----> api.md
quickstart.md --[README]-----> README.md
quickstart.md --[API Docs]---> api.md
```

## Interface layout

The graph view has these parts:

### Title bar

The title bar shows **Graph** and how many files and relations are currently visible, for example **42 files · 57 relations**, plus the number of missing files when there are any. On the right are **Search** and **Refresh file index**.

### Main canvas

The canvas displays nodes and relations and supports free panning and zooming.

### Zoom controls

The lower-left corner has **Zoom out**, the current zoom level, **Zoom in**, and **Fit to view**. Click the zoom level to return to 100%.

### Graph controls

The lower-right corner has three panels:

- **Filters** for file types, relation types, and isolated files
- **Color legend** for the colors in use, with counts
- **Display** for colors, labels, directional flow, edge opacity, and the layout

### Details panel

Selecting a file or a relation opens a details panel in the upper-right corner.

<Tip>
  The graph adds detail as you zoom in: more file labels appear, busiest files first, then relation labels, and the nodes grow and show an icon for their file type.
</Tip>

## File type recognition

By default, nodes are colored by file type. Open **Color legend** to see the color of each type.

| Type | Extensions |
| --- | --- |
| **Markdown** | `.md`, `.mdx`, `.markdown` |
| **Images** | `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.webp`, `.avif`, `.heic`, `.bmp`, `.tiff`, and other image formats |
| **Videos** | `.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`, `.flv`, `.wmv` |
| **Audio** | `.mp3`, `.wav`, `.ogg`, `.flac`, `.aac`, `.m4a`, `.wma` |
| **Code** | Source, web, configuration, and plain text files, such as `.js`, `.ts`, `.py`, `.json`, `.yaml`, `.html`, `.css`, and `.txt` |
| **PDF** | `.pdf` |
| **Documents** | `.doc`, `.docx`, `.rtf`, `.odt`, `.xls`, `.xlsx`, `.ppt`, `.pptx`, `.csv` |
| **Other** | Everything else, including canvases (`.excalidraw`) |

You can also color nodes by community instead. See [Display settings](#display-settings).

## Basic interaction

### View controls

<AccordionGroup>
  <Accordion title="Pan the canvas" icon="hand">
    Drag on empty canvas space to move the whole view.
  </Accordion>

  <Accordion title="Zoom" icon="magnifying-glass">
    Scroll with the mouse wheel or the trackpad to zoom in and out around the pointer, or use the zoom controls in the lower-left corner. **Fit to view** brings every visible node into view.
  </Accordion>
</AccordionGroup>

### Node interaction

<AccordionGroup>
  <Accordion title="Click a node" icon="mouse-pointer" defaultOpen>
    Clicking a node selects it, highlights its relations, fades the rest of the graph, and opens its details: **Open file**, **Locate in graph**, and its links under **References** and **Referenced by**. Click a related file in the list to move to its details, and use the back arrow to return.
  </Accordion>

  <Accordion title="Double-click a node" icon="hand-pointer">
    Double-click opens the matching file in the editor.
  </Accordion>

  <Accordion title="Drag a node" icon="arrows-alt">
    Dragging a node moves it manually. When you release it, that node stays pinned at the new position while the files around it settle.
  </Accordion>
</AccordionGroup>

### Edge interaction

<AccordionGroup>
  <Accordion title="Click a relation" icon="link">
    Clicking a relation selects it, highlights the line, shows its label, and opens its details: the relation type and its **Source** and **Target** files, each with a button to open it.
  </Accordion>

  <Accordion title="Hover for label details" icon="tag">
    Hover over a relation to highlight it and show its link text as a tooltip.
  </Accordion>
</AccordionGroup>

## Search

### How to search

1. Click **Search** in the title bar, or press `/`
2. Enter part of a file name, a folder, or link text
3. Choose a result with the mouse, or with `↑`, `↓`, and `Enter`

Choosing a result selects it and opens its details. Click **Locate in graph** to center it in the view.

### Search scope

<AccordionGroup>
  <Accordion title="File search" icon="circle-nodes">
    Search by file name or by a folder in its path, for example `README` or `projects`.
  </Accordion>

  <Accordion title="Relation search" icon="link">
    Search by link text or by the paths of the linked files.
  </Accordion>
</AccordionGroup>

Search covers the whole graph, including items that the current filters hide, and shows up to 30 results. If you choose a hidden item, the details panel offers **Adjust filters to show this item**.

## Filtering

Use filters to narrow the graph down to the content that matters for the current task. Open **Filters** in the lower-right corner.

### Filter options

- **File types**: Markdown, Images, Videos, Audio, Code, PDF, Documents, Other
- **Relation types**: Images, Audio, Videos, PDF Card, Attachment, Embed, Excalidraw, Supertag, Data Table, Other
- **Show isolated files**, to show or hide files without any links
- **Reset filters**, to show everything again

<Tip>
  Each type shows how many files or relations it has, and you can turn several types off at once. The **Filters** button shows how many are hidden. In **Color legend**, clicking a file type also shows or hides it.
</Tip>

<Warning>
  After filtering, relations are shown only when both the source and target files are still visible.
</Warning>

## Configuration

### Display settings

Open **Display** in the lower-right corner.

<AccordionGroup>
  <Accordion title="Color" icon="palette">
    **By file type** colors each node by its type. **By community** colors groups of files that link closely to each other. Communities are found automatically from the links; the **Color legend** lists them, largest first, named after their most connected file. Files without links are grouped as **Ungrouped**. Click a community in the legend to show only that community.
  </Accordion>

  <Accordion title="Show file and relation labels" icon="text-size">
    Shows or hides the names of files and the link text of relations. On by default.
  </Accordion>

  <Accordion title="Show directional flow" icon="arrow-right">
    Animates the direction of the selected relations, or of all relations of the selected file. On by default.
  </Accordion>

  <Accordion title="Edge opacity" icon="minus">
    Sets how strongly relation lines are drawn, from 5% to 80%. The default is 28%.
  </Accordion>
</AccordionGroup>

### Layout settings

<AccordionGroup>
  <Accordion title="Pause layout / Resume layout" icon="pause">
    Stops or restarts the layout. The layout also stops by itself once the graph settles.
  </Accordion>

  <Accordion title="Reset layout and pinned positions" icon="arrows-rotate">
    Releases every pinned node and lays out the graph again from the start.
  </Accordion>
</AccordionGroup>

<Note>
  **Resume layout** sets the nodes moving again until they settle, and so does dragging a node while the layout is not paused. Filters and display settings belong to the graph tab and are not saved when you close it.
</Note>

## Performance tips

<Steps>
  <Step title="Hide what you do not need">
    Turn off file types, relation types, or isolated files in **Filters** so the graph shows only what you are working on.
  </Step>

  <Step title="Pause the layout">
    Once the arrangement looks right, choose **Pause layout** in **Display** so nodes stop moving.
  </Step>

  <Step title="Pin anchor nodes">
    Fixing a few important nodes reduces layout churn and improves readability.
  </Step>

  <Step title="Turn off labels">
    Turn off **Show file and relation labels** to draw only dots and lines in a very large graph.
  </Step>
</Steps>

## FAQ

<AccordionGroup>
  <Accordion title="Why is the graph empty?" icon="question">
    The graph indexes `.md` files in local workspaces. Make sure a local workspace is open, that your notes end in `.md`, and that they are not in hidden or ignored folders, then click **Refresh file index**. If the view says **No files match these filters**, choose **Reset filters**.
  </Accordion>

  <Accordion title="Why are some nodes outside the visible canvas?" icon="question">
    Click **Fit to view**, zoom out, or search for the file and click **Locate in graph**.
  </Accordion>

  <Accordion title="How do I reset pinned node positions?" icon="question">
    Open **Display** and choose **Reset layout and pinned positions**.
  </Accordion>

  <Accordion title="Why does double-click not open the file?" icon="question">
    The file may not exist: missing files are drawn as hollow, dashed circles and cannot be opened. Also make sure you did not drag the node between the clicks.
  </Accordion>

  <Accordion title="Why do relations overlap?" icon="question">
    Zoom in, select the file first, or drag the nodes farther apart. Lowering **Edge opacity** also makes busy areas easier to read.
  </Accordion>

  <Accordion title="Can I export or share the graph?" icon="question">
    There is no built-in export yet. Use your system screenshot tool if you need to capture the current view.
  </Accordion>

  <Accordion title="Why does the graph keep moving?" icon="question">
    The layout moves until it settles, and dragging a node starts it again. Choose **Pause layout** in **Display** to stop it, and pin a few anchor nodes to keep the arrangement stable.
  </Accordion>
</AccordionGroup>

## Keyboard shortcuts

Click the canvas first so the graph has keyboard focus.

| Shortcut | What it does |
| --- | --- |
| `/` | Open search |
| `Esc` | Clear the current node or relation selection |
| `+` or `=` | Zoom in |
| `-` | Zoom out |
| `Enter` | Open the selected file |
| Arrow keys | Nudge the selected node, which pins it |

## Technical notes

<Note>
  The graph is drawn with your graphics card, and its layout is calculated in the background so that it does not hold up editing. If your system is set to reduce motion, the layout starts paused and the directional flow is not animated. If the graph cannot be drawn, the view shows **Unable to load the graph. Please retry.** with a **Retry** button.
</Note>
