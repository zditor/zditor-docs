サイドバーのファイルツリーは、Zditor の中核となる機能の 1 つです。現在のワークスペース内のファイルを、その場で閲覧、作成、名前変更、移動、整理できます。

## 画面の概要

ファイルツリーは、サイドバーの **Files** パネルです。表示するには、左端のナビゲーションレールの一番上にあるフォルダーアイコンをクリックします。フィルターを使っていないときは、名前がドットで始まるものも含め、ワークスペース内のすべてのファイルとフォルダーが表示されます。

### 上部のツールバー

ファイルツリーの上部には、現在のワークスペースの名前が表示されます。クリックすると、ワークスペースを切り替えられます（[ワークスペースの管理](#ワークスペースの管理)を参照）。その横には 3 つのボタンがあります。

- **New File**：ワークスペースのルートにファイルを作成します。
- **New Folder**：ワークスペースのルートにフォルダーを作成します。
- **More**：次の項目があるメニューを開きます。
  - **Filter**：特定の種類のファイルだけを表示します。
  - **Refresh**：ワークスペースを再スキャンします。
  - **Collapse**：展開しているフォルダーをすべて閉じます。
  - **Clear clipboard**：保留中のコピーまたはカットを取り消します（コピーやカットをしている間だけ表示されます）。
  - **Open Folder**：システムのファイルマネージャーでワークスペースを開きます。

ツリーの読み込み、更新、ファイルのインポート中は、ツールバーの下に細い進行状況バーが表示されます。

### ファイルリスト

メインのリストには、ファイルとフォルダーが階層に応じたインデント付きで表示されます。項目にポインターを合わせると、フルパスが表示されます。

### 下部のバー

パネル下部のバーは、3 つの部分に分かれています。

- 左側の **+** ボタンは、ワークスペースのルートに `untitled1.md`（または空いている次の番号）という名前の空の Markdown ファイルを作成して開きます。
- 中央のワークスペース名をクリックすると、システムのフォルダー選択ダイアログが開き、別のローカルフォルダーに切り替えられます。
- 右側の **⋮** ボタンは、並べ替えのオプション、最近使ったフォルダー、設定済みのリモートワークスペースを表示するパネルを開きます。

## 基本操作

<AccordionGroup>
  <Accordion title="シングルクリック" icon="mouse">
    - ファイルをクリックすると、タブで開きます
    - フォルダーをクリックすると、展開または折りたたみます
  </Accordion>

  <Accordion title="コンテキストメニュー" icon="bars">
    - ファイルを右クリックすると、**Open in Right Split**、**Rename**、**Copy** などの操作を選べます
    - フォルダーを右クリックすると、その中に項目を作成したり、貼り付けたりできます
    - リストの下の空いている部分を右クリックすると、ワークスペースのルート用のメニューが開きます
  </Accordion>
</AccordionGroup>

### 項目の選択

ファイルやフォルダーをクリックすると選択されます。選択した項目はハイライト表示されます。

### 名前の変更

<AccordionGroup>
  <Accordion title="名前を変更する方法" icon="pen">
    1. ファイルやフォルダーを右クリックし、**Rename** を選びます
    2. または、項目にポインターを合わせて **…** ボタンをクリックし、**Rename** を選びます
    3. `Enter` で確定、`Esc` でキャンセルします。ほかの場所をクリックしても、新しい名前が確定します。
  </Accordion>
</AccordionGroup>

<Tip>
  ファイル名を変更するときは、拡張子より前の部分だけが選択されるので、拡張子を残したまま新しい名前を入力できます。
</Tip>

## ファイルとフォルダーの管理

### ファイルとフォルダーの作成

<AccordionGroup>
  <Accordion icon="plus" title="方法 1：上部のツールバー">
    ツールバーの **New File** または **New Folder** をクリックすると、ワークスペースのルートに作成されます。
  </Accordion>

  <Accordion icon="folder-plus" title="方法 2：ポインターを合わせると表示されるボタン">
    フォルダーにポインターを合わせると、クイックアクションのボタンが表示されます。

    - `+`：そのフォルダー内に新しいファイルを作成します
    - フォルダーアイコン：サブフォルダーを作成します
  </Accordion>

  <Accordion icon="computer-mouse" title="方法 3：右クリックメニュー">
    対象のフォルダー（ワークスペースのルートの場合はリストの下の空いている部分）を右クリックし、**New File** または **New Folder** を選びます。
  </Accordion>
</AccordionGroup>

ファイルを作成するときは、名前の入力欄と、その後ろに拡張子の入力欄が表示されます。拡張子の初期値は既定の拡張子（変更していなければ `.md`）です。

- `↑` または `↓` を押すと、リストにある別の拡張子に切り替わります
- 名前の末尾にリストにある拡張子を入力すると（`notes.txt` など）、その拡張子に切り替わります
- 名前の末尾で `→` を押すと、拡張子の入力欄に移動します

既定の拡張子と拡張子のリストは、**Settings → Personal → General → File types** で変更できます。

### ファイルとフォルダーの削除

1. 対象のファイルまたはフォルダーを右クリックします
2. **Delete** を選びます

そのファイル、またはフォルダー内のいずれかの項目がタブで開いている場合は、それらのタブを閉じて削除するかどうかを先に確認されます。それ以外の場合は、すぐに削除されます。

<Warning>
  削除した項目はシステムのゴミ箱に移動されず、元に戻すこともできません。ファイルやフォルダーを削除する前に、よく確認してください。
</Warning>

### コピー、カット、ペースト

<AccordionGroup>
  <Accordion icon="copy" title="コピー">
    1. ファイルやフォルダーを右クリックし、**Copy** を選びます
    2. 項目に黄色の枠線と **Copy** ラベルが付きます
  </Accordion>

  <Accordion icon="scissors" title="カット">
    1. ファイルやフォルダーを右クリックし、**Cut** を選びます
    2. 項目に青緑色の枠線と **Cut** ラベルが付きます
  </Accordion>

  <Accordion icon="paste" title="ペースト">
    1. 貼り付け先のフォルダー（ワークスペースのルートの場合はリストの下の空いている部分）を右クリックします
    2. **Paste** を選びます
    3. 項目がその場所にコピーまたは移動されます
  </Accordion>
</AccordionGroup>

<Tip>
  クリップボードに保持できる項目は一度に 1 つだけで、貼り付けると空になります。項目をそれ自体の中に貼り付けたり、自身のサブフォルダーに移動したり、同じ名前の項目がすでにあるフォルダーに貼り付けたりすることはできません。
</Tip>

## 並べ替えとフィルター

### ファイルの種類のフィルター

特定の種類のファイルだけを表示するには、上部のツールバーで **More → Filter** を開きます。

| フィルター | 表示されるもの |
| --- | --- |
| **All** | すべてのファイルとフォルダー |
| **Markdown** | `.md`、`.mdx`、`.markdown` |
| **Documents** | `.pdf`、`.doc`、`.docx`、`.txt`、`.csv`、`.xls`、`.xlsx`、`.ppt`、`.pptx` |
| **Assets** | 画像、動画、音声のファイル |
| **Code** | `.ts`、`.js`、`.py`、`.json`、`.yaml`、`.html`、`.css` などのソースコード、Web、設定のファイル |
| **Excalidraw** | キャンバスファイル（`.excalidraw`） |
| **Hidden** | 名前がドットで始まるファイルとフォルダー |
| **Other** | 上のどの分類にも当てはまらないファイル |

複数のフィルターを同時にオンにできます。**All** を選ぶと、ほかのフィルターはオフになります。フィルターが有効な間は、**Filter** の項目に選択中の種類の数が表示され、**More** ボタンにドットが付きます。

フォルダーは常にリストに残るので、その中にある該当ファイルにたどり着けます。フィルターが有効なときは、**Hidden** を選択していない限り、名前がドットで始まる項目は非表示になります。

### 並べ替えのオプション

下部のバーにある **⋮** ボタンをクリックします。並べ替えのボタンはパネルの上部にあります。

#### 並べ替えの基準

- **Sort alphabetically**：名前順に並べ替えます
- **Sort by creation time**：各ファイルの作成日時順に並べ替えます
- **Sort by modification time**：各ファイルの最終変更日時順に並べ替えます

#### 並べ替えの方向

- 矢印ボタンで **Sort ascending** と **Sort descending** を切り替えます

#### フォルダーのグループ化

- **Group by folder**：フォルダーをファイルより上にまとめて表示します

既定では、ツリーは名前の昇順で並び、フォルダーが先にまとめて表示されます。名前がドットで始まる項目は、ほかの項目より前に表示されます。

## ドラッグ＆ドロップ

ファイルツリーでは、ドラッグ＆ドロップでファイルを管理できます。

<AccordionGroup>
  <Accordion icon="file-import" title="ファイルやフォルダーの移動">
    1. 対象のファイルやフォルダーをドラッグします
    2. 移動先のフォルダーの上にドロップします
    3. ボタンを離すと移動が完了します
  </Accordion>

  <Accordion icon="upload" title="外部からのファイルの取り込み">
    システムのファイルマネージャーからファイルやフォルダーを、ツリー内のフォルダー（ワークスペースのルートの場合は空いている部分）にドラッグすると、ワークスペースにコピーされます。ドロップしたファイルは、そのフォルダー内の同じ名前のファイルを置き換えます。ツリーの下部に短いステータスが表示され、追加されたファイルの数がわかります。
  </Accordion>

  <Accordion icon="home" title="ルートへのドロップ">
    項目をツリーの空いている部分にドロップすると、ワークスペースのルートに移動します。
  </Accordion>
</AccordionGroup>

<Tip>
  ドラッグ中は、ドロップ先のフォルダーがハイライト表示されます。閉じたフォルダーの上に約 600 ミリ秒とどまると、自動的に展開されます。リストの上端や下端の近くまでドラッグすると、リストがスクロールします。
</Tip>

## コンテキストメニュー

ファイルとフォルダーには、多機能なコンテキストメニューがあります。項目にポインターを合わせると表示される **…** ボタンからも、同じメニューを開けます。

### ファイルのコンテキストメニュー

| 項目 | 機能 |
| --- | --- |
| **Open** | ファイルを左側のペインで開く |
| **Open in Right Split** | ファイルを右側のペインで開く |
| **Rename** | ファイル名を変更 |
| **Copy** | ファイルをクリップボードにコピー |
| **Cut** | ファイルをクリップボードにカット |
| **Paste** | ファイルでは使えません。フォルダーかワークスペースのルートに貼り付けてください |
| **Open in Folder** | システムのファイルマネージャーでファイルを表示 |
| **Copy File Path** | ファイルのフルパスをクリップボードにコピー |
| **Save As** | ファイルのコピーを、このパソコン上の選んだ場所に保存 |
| **Delete** | ファイルを削除 |

### フォルダーのコンテキストメニュー

フォルダーのメニューには、**Rename**、**Copy**、**Cut**、**Paste**、**Open in Folder**、**Copy File Path**、**Delete** に加えて、次の項目があります。

| 項目 | 機能 |
| --- | --- |
| **New File** | そのフォルダー内にファイルを作成 |
| **New Folder** | サブフォルダーを作成 |

### ルートのコンテキストメニュー

ファイルツリーの空いている部分を右クリックすると、ワークスペースのルート用のメニューが開きます。

- **New File** と **New Folder**：ルートに項目を作成します
- **Paste**：コピーまたはカットした項目をルートに貼り付けます
- **Refresh**：ワークスペースを再スキャンします
- **Collapse All**：展開しているフォルダーを閉じます
- **Open in Folder**：システムのファイルマネージャーでワークスペースを開きます
- **Copy File Path**：ワークスペースのパスをコピーします

## ワークスペースの管理

ワークスペースとは、ツリーにファイルが表示されるフォルダーのことです。空のタブで **Open Workspace** を選んで既存のフォルダーを開いたり、**New Workspace** を選んで空のフォルダーを作成して開いたりすることもできます。

### ワークスペースの切り替え

1. ファイルツリーの上部にあるワークスペース名をクリックします
2. メニューからワークスペースを選ぶか、**Open Directory** を選んでシステムのフォルダー選択ダイアログでフォルダーを選びます
3. 新しいワークスペースが読み込まれます

Agent タブが開いている場合は、現在のワークスペースへの接続が閉じられるため、切り替えの確認を求められます。タブとセッション履歴は保持され、そのワークスペースに戻ると再接続されます。

<Tip>
  ワークスペースごとに専用のウィンドウを使えます。新しいウィンドウで開くには、**Open Folder in New Window…** を選ぶか、メニューでワークスペースを `Cmd` キーを押しながらクリックします（Windows と Linux では `Ctrl` キーを押しながらクリック）。ほかのウィンドウですでに開いているワークスペースを選ぶと、そのウィンドウが手前に表示されます。
</Tip>

### リモートワークスペース

ワークスペースは、このパソコン上になくてもかまいません。**Settings → Integrations → Connections** で接続を追加します。

- **S3** ストレージ、**WebDAV** サーバー、**SSH** ホスト上のフォルダーは、ワークスペースメニューと **⋮** パネルにそれぞれのグループとして表示されます。
- **Git** 接続では、リポジトリのローカルクローンを保持し、ほかのフォルダーと同じように開きます。

S3、WebDAV、SSH のワークスペースでは、**Open in Folder** は使えません。また、サーバー上でファイルが変更されても、ツリーは自動的には更新されません。最新のファイルを表示するには **Refresh** を使います。

### 最近使ったフォルダー

ワークスペースメニューには、最近使ったローカルフォルダーが表示されます。下部のバーの **⋮** パネルにも表示され、そこで管理もできます。

<AccordionGroup>
  <Accordion icon="thumbtack" title="フォルダーのピン留め">
    ピンのアイコンをクリックすると、重要なフォルダーを最近使った項目のリストの一番上に固定できます。
  </Accordion>

  <Accordion icon="trash" title="最近使った項目からの削除">
    ピン留めしていないフォルダーは、ゴミ箱のアイコンをクリックすると、最近使った項目のリストから削除できます。
  </Accordion>
</AccordionGroup>

リストには最大 5 つのフォルダーが保持され、ピン留めしたフォルダーは常に残ります。起動時には、最後に使ったワークスペースが再び開きます。ワークスペースを開かずに起動するには、**Settings → Personal → General** で **Reopen previous workspace** をオフにします。

### 自動更新

ローカルのワークスペースでは、ファイルツリーがワークスペースのルートと展開中のすべてのフォルダーを監視します。

- Zditor でもほかのアプリでも、ファイルを作成、削除、名前変更すると、ツリーが更新されます
- フォルダーを再び展開すると再スキャンされるので、折りたたんでいた間の変更も表示されます

## よくある質問

<AccordionGroup>
  <Accordion title="ツリーに一部のファイルが表示されないのはなぜですか？" icon="question">
    ファイルの種類のフィルターが有効になっていないか確認してください。有効な場合は **More** ボタンにドットが表示されます。**More → Filter** を **All** に戻してください。ほかのフィルターが有効な間は、**Hidden** も選択しない限り、名前がドットで始まるファイルやフォルダーは非表示のままです。
  </Accordion>

  <Accordion title="ドラッグできないのはなぜですか？" icon="question">
    閉じたフォルダーは、展開されるまでその上にポインターをとどめてください。項目をそれ自体の中、自身のサブフォルダー、すでに入っているフォルダーへ移動することはできません。また、移動先に同じ名前の項目がすでにある場合も移動できません。
  </Accordion>

  <Accordion title="最近変更したファイルをすばやく見つけるには？" icon="question">
    **⋮** パネルで **Sort by modification time** を選び、並べ替えの方向を降順にします。
  </Accordion>

  <Accordion title="複数のファイルを同時に開けますか？" icon="question">
    はい。ファイルをクリックすると、それぞれ別のタブで開きます。2 つのファイルを並べて表示するには、**Open in Right Split** を使います。
  </Accordion>

  <Accordion title="Open in Folder が使えないのはなぜですか？" icon="question">
    S3、WebDAV、SSH のワークスペースはこのパソコン上にないため、システムのファイルマネージャーで表示できるローカルフォルダーがありません。
  </Accordion>
</AccordionGroup>
