知识图谱是 Zditor 的特色功能之一。它把工作区中的文件以及文件之间的链接变成一张交互式力导向图，让你一眼看清结构、引用关系和文件集群。

## 功能概览

点击左侧导航栏中的 **关系图** 按钮即可打开知识图谱。它会在标签页中打开，显示当前工作区。

每个 Markdown（`.md`）文件都会成为一个节点，这些笔记链接到的每个文件也会成为节点。每条链接都会成为一条有向关系，从包含链接的文件指向它所指的文件。布局会自动摆放节点，在你平移、缩放和查看关系时保持图谱清晰易读。圆点越大，表示该文件的连接越多。

## 链接语法解析

知识图谱根据工作区内 Markdown 文件中的链接构建。

### Markdown 链接语法

Zditor 能识别标准的 Markdown 链接和图片：

```markdown
[Link Text](file/path.md)
![Alt text](images/diagram.png)
```

Zditor 为嵌入内容写入的链接也会被计入，例如音频、视频、PDF 卡片、画布和 SuperTag 引用（`[text](path|mode=...)`）。

<AccordionGroup>
  <Accordion title="链接组成部分" icon="link" defaultOpen>
    **链接文本**
    - 方括号 `[]` 中的内容
    - 在图谱中用作关系标签
    - 描述这条关系的含义

    **链接路径**
    - 圆括号 `()` 中的内容
    - 指向目标文件
    - 决定目标节点
  </Accordion>

  <Accordion title="链接如何转换为关系" icon="diagram-project">
    每条链接都会成为一条有向关系：

    - 包含链接的文件是**来源**
    - 被链接的文件是**目标**
    - 关系从来源指向目标
    - 链接文本显示为关系标签
  </Accordion>

  <Accordion title="查看链接方向" icon="arrow-right">
    选中一个文件或一条关系，即可看出链接的指向。开启 **显示方向流动** 后，会有小圆点沿选中的关系从来源流向目标。

    文件的详情面板会在 **引用** 下列出它的出链，在 **被引用** 下列出它的入链。这有助于你发现枢纽文件、被大量引用的资源，以及相互链接的文件。
  </Accordion>

  <Accordion title="关系类型" icon="tags">
    关系按链接的种类分组：**图片**、**音频**、**视频**、**PDF 卡片**、**附件**、**嵌入**、**Excalidraw**、**超级标签**、**数据表**，普通链接则归入 **其他**。部分类型以虚线或点线绘制。

    SuperTag 记录还会有一条指向其 class 的 Schema 文件的 **数据表** 关系，标签为 class 名称。
  </Accordion>
</AccordionGroup>

### 同一对文件之间的多条链接

<AccordionGroup>
  <Accordion title="同向多重链接" icon="arrows-turn-right">
    如果文件 A 用不同的链接文本多次链接到文件 B，图谱会把每条关系画成一条独立的曲线，让它们都清晰可见，而不是叠成一条线。同一文件中链接文本相同的重复链接只计一次。
  </Accordion>

  <Accordion title="双向链接" icon="arrows-left-right">
    当 A 链接到 B、B 也链接回 A 时，两条关系会画在不同的曲线上，不会重叠。文件链接到自身时，会画成一个环。
  </Accordion>
</AccordionGroup>

### 解析规则与限制

<Warning>
  当前的解析规则：

  - 只有以 `.md` 结尾的文件会被扫描链接。其他文件（包括 `.mdx` 和 `.markdown` 文件）只有在被笔记链接时才会出现
  - 会解析标准链接 `[text](path)` 和图片 `![alt](path)`
  - 以 `http://` 或 `https://` 开头的网页链接会被忽略
  - 不解析 `[[page]]` 这样的 Wiki 链接、引用式链接，以及 `<a>` 等 HTML 标签
  - 以 `/` 开头的路径从工作区根目录解析，其他路径从包含该链接的文件所在的文件夹解析
  - 路径末尾的 `#heading` 部分会被忽略，因此链接到某个标题也算作链接到该文件
  - 不会扫描隐藏的文件和文件夹，也不会扫描被 `.ignore` 文件（在 Git 仓库中还有 `.gitignore`）排除的文件
</Warning>

<Tip>
  使用简洁、有描述性的链接文本，让图谱中的关系标签既有用又易读。
</Tip>

链接到不存在的文件时，仍会生成一个节点。这类节点画成空心虚线圆，标题栏会显示当前可见的数量，例如 **2 个不存在**。

知识图谱适用于本地工作区。打开它时，Zditor 会更新工作区的索引。只要 **设置 → 个人 → 通用** 中的 **监听工作区文件** 处于开启状态（默认开启），你保存笔记时，修改就会反映到图谱中。你也可以随时点击标题栏中的 **刷新文件索引** 重新扫描。

### 实际应用示例

```markdown
<!-- docs/README.md -->
- [Quickstart](./quickstart.md)
- [API Docs](./api.md)

<!-- docs/quickstart.md -->
Read [README](./README.md) first
See [API Docs](./api.md)
```

这会生成如下关系：

```text
README.md ----[Quickstart]----> quickstart.md
README.md ----[API Docs]-----> api.md
quickstart.md --[README]-----> README.md
quickstart.md --[API Docs]---> api.md
```

## 界面布局

知识图谱视图由以下几部分组成：

### 标题栏

标题栏显示 **关系图谱** 以及当前可见的文件数和关系数，例如 **42 个文件 · 57 条关系**；有不存在的文件时，还会显示它们的数量。右侧是 **搜索** 和 **刷新文件索引**。

### 主画布

画布显示节点和关系，支持自由平移和缩放。

### 缩放控件

左下角有 **缩小**、当前缩放比例、**放大** 和 **适应视图**。点击缩放比例可以回到 100%。

### 图谱控件

右下角有三个面板：

- **筛选**：文件类型、关系类型和无连接文件
- **颜色图例**：当前使用的颜色及对应数量
- **显示**：颜色、标签、方向流动、连线深浅和布局

### 详情面板

选中文件或关系后，右上角会打开详情面板。

<Tip>
  放大时，图谱会逐步显示更多细节：先出现更多文件名称（连接最多的文件优先），然后是关系标签，节点也会变大，并显示文件类型图标。
</Tip>

## 文件类型识别

默认情况下，节点按文件类型着色。打开 **颜色图例** 可以查看每种类型的颜色。

| 类型 | 扩展名 |
| --- | --- |
| **Markdown** | `.md`、`.mdx`、`.markdown` |
| **图片** | `.png`、`.jpg`、`.jpeg`、`.gif`、`.svg`、`.webp`、`.avif`、`.heic`、`.bmp`、`.tiff` 及其他图片格式 |
| **视频** | `.mp4`、`.mov`、`.avi`、`.mkv`、`.webm`、`.flv`、`.wmv` |
| **音频** | `.mp3`、`.wav`、`.ogg`、`.flac`、`.aac`、`.m4a`、`.wma` |
| **代码** | 源代码、网页、配置和纯文本文件，例如 `.js`、`.ts`、`.py`、`.json`、`.yaml`、`.html`、`.css` 和 `.txt` |
| **PDF** | `.pdf` |
| **文档** | `.doc`、`.docx`、`.rtf`、`.odt`、`.xls`、`.xlsx`、`.ppt`、`.pptx`、`.csv` |
| **其他** | 其余所有文件，包括画布（`.excalidraw`） |

你也可以改为按连接簇为节点着色，见 [显示设置](#显示设置)。

## 基础交互操作

### 视图控制

<AccordionGroup>
  <Accordion title="平移画布" icon="hand">
    在画布空白处拖动，即可移动整个视图。
  </Accordion>

  <Accordion title="缩放画布" icon="magnifying-glass">
    用鼠标滚轮或触控板滚动，即可以指针为中心放大或缩小；也可以使用左下角的缩放控件。**适应视图** 会让所有可见节点都进入视野。
  </Accordion>
</AccordionGroup>

### 节点交互

<AccordionGroup>
  <Accordion title="单击节点" icon="mouse-pointer" defaultOpen>
    单击节点会选中它，高亮它的关系，淡化图谱的其余部分，并打开它的详情：**打开文件**、**在图中定位**，以及 **引用** 和 **被引用** 下的链接。点击列表中的相关文件可以跳转到它的详情，使用返回箭头可以回到上一项。
  </Accordion>

  <Accordion title="双击节点" icon="hand-pointer">
    双击节点会在编辑器中打开对应的文件。
  </Accordion>

  <Accordion title="拖拽节点" icon="arrows-alt">
    拖动节点可以手动移动它。松开后，该节点会固定在新位置，周围的文件则会重新稳定下来。
  </Accordion>
</AccordionGroup>

### 连线交互

<AccordionGroup>
  <Accordion title="单击关系" icon="link">
    单击一条关系会选中它，高亮这条连线并显示其标签，同时打开它的详情：关系类型，以及 **来源** 和 **指向** 两个文件，每个文件旁都有一个打开按钮。
  </Accordion>

  <Accordion title="悬停查看标签" icon="tag">
    把鼠标悬停在关系上，会高亮这条关系，并以提示框显示它的链接文本。
  </Accordion>
</AccordionGroup>

## 搜索功能

### 如何搜索

1. 点击标题栏中的 **搜索**，或按 `/`
2. 输入文件名的一部分、文件夹名或链接文本
3. 用鼠标选择结果，或使用 `↑`、`↓` 和 `Enter`

选择结果后会选中它并打开详情。点击 **在图中定位** 可以把它移到视图中央。

### 搜索范围

<AccordionGroup>
  <Accordion title="文件搜索" icon="circle-nodes">
    按文件名或路径中的文件夹搜索，例如 `README` 或 `projects`。
  </Accordion>

  <Accordion title="关系搜索" icon="link">
    按链接文本或被链接文件的路径搜索。
  </Accordion>
</AccordionGroup>

搜索覆盖整个图谱，包括被当前筛选隐藏的项目，最多显示 30 条结果。如果你选择了一个被隐藏的项目，详情面板会提供 **调整筛选以显示此项**。

## 筛选功能

用筛选把图谱缩小到当前任务需要关注的内容。打开右下角的 **筛选**。

### 筛选选项

- **文件类型**：Markdown、图片、视频、音频、代码、PDF、文档、其他
- **关系类型**：图片、音频、视频、PDF 卡片、附件、嵌入、Excalidraw、超级标签、数据表、其他
- **显示无连接文件**：显示或隐藏没有任何链接的文件
- **重置筛选**：重新显示全部内容

<Tip>
  每种类型都会显示它包含的文件或关系数量，你可以同时关闭多种类型。**筛选** 按钮会显示有多少类型被隐藏。在 **颜色图例** 中点击某个文件类型，也可以显示或隐藏它。
</Tip>

<Warning>
  筛选后，只有来源文件和目标文件都仍然可见时，关系才会显示。
</Warning>

## 配置选项

### 显示设置

打开右下角的 **显示**。

<AccordionGroup>
  <Accordion title="颜色" icon="palette">
    **按文件类型** 根据类型为每个节点着色。**按连接分簇** 为彼此链接紧密的文件组着色。连接簇根据链接自动识别；**颜色图例** 会按规模从大到小列出它们，并以每个簇中连接最多的文件命名。没有链接的文件归为 **未分簇**。在图例中点击某个连接簇，就只显示这个簇。
  </Accordion>

  <Accordion title="显示名称与关系文字" icon="text-size">
    显示或隐藏文件名称和关系的链接文本。默认开启。
  </Accordion>

  <Accordion title="显示方向流动" icon="arrow-right">
    以动画显示选中关系的方向，或选中文件所有关系的方向。默认开启。
  </Accordion>

  <Accordion title="连线深浅" icon="minus">
    设置关系连线的深浅，范围为 5% 到 80%，默认值为 28%。
  </Accordion>
</AccordionGroup>

### 布局设置

<AccordionGroup>
  <Accordion title="暂停布局 / 继续布局" icon="pause">
    停止或重新开始布局。图谱稳定后，布局也会自行停止。
  </Accordion>

  <Accordion title="重置布局与固定位置" icon="arrows-rotate">
    释放所有固定的节点，并从头重新布局。
  </Accordion>
</AccordionGroup>

<Note>
  **继续布局** 会让节点重新运动，直到稳定下来；在布局未暂停时拖动节点也会如此。筛选和显示设置属于当前的图谱标签页，关闭标签页后不会保存。
</Note>

## 性能优化建议

<Steps>
  <Step title="隐藏不需要的内容">
    在 **筛选** 中关闭不需要的文件类型、关系类型或无连接文件，让图谱只显示你正在处理的内容。
  </Step>

  <Step title="暂停布局">
    排列看起来合适后，在 **显示** 中选择 **暂停布局**，让节点停止运动。
  </Step>

  <Step title="固定锚点节点">
    固定几个重要节点，可以减少布局变动，提高可读性。
  </Step>

  <Step title="关闭标签">
    在非常大的图谱中，关闭 **显示名称与关系文字**，只绘制圆点和连线。
  </Step>
</Steps>

## 常见问题

<AccordionGroup>
  <Accordion title="为什么知识图谱是空的？" icon="question">
    知识图谱索引的是本地工作区中的 `.md` 文件。请确认打开的是本地工作区、笔记以 `.md` 结尾，并且不在隐藏或被忽略的文件夹中，然后点击 **刷新文件索引**。如果视图显示 **当前筛选下没有文件**，请选择 **重置筛选**。
  </Accordion>

  <Accordion title="为什么有些节点在画布外看不到？" icon="question">
    点击 **适应视图**、缩小视图，或者搜索该文件后点击 **在图中定位**。
  </Accordion>

  <Accordion title="如何重置节点的固定位置？" icon="question">
    打开 **显示**，选择 **重置布局与固定位置**。
  </Accordion>

  <Accordion title="双击节点打开文件没有反应？" icon="question">
    文件可能不存在：不存在的文件画成空心虚线圆，无法打开。另外，请确认两次点击之间没有拖动节点。
  </Accordion>

  <Accordion title="为什么关系连线会重叠？" icon="question">
    放大视图、先选中文件，或者把节点拖得更开一些。调低 **连线深浅** 也能让密集区域更易读。
  </Accordion>

  <Accordion title="可以导出或分享知识图谱吗？" icon="question">
    目前还没有内置的导出功能。如果需要保存当前视图，请使用系统的截图工具。
  </Accordion>

  <Accordion title="为什么图谱一直在动？" icon="question">
    布局会一直运动到稳定为止，拖动节点会让它重新开始。在 **显示** 中选择 **暂停布局** 可以让它停下来；固定几个锚点节点可以让排列保持稳定。
  </Accordion>
</AccordionGroup>

## 键盘快捷键

先点击画布，让图谱获得键盘焦点。

| 快捷键 | 功能 |
| --- | --- |
| `/` | 打开搜索 |
| `Esc` | 取消当前选中的节点或关系 |
| `+` 或 `=` | 放大 |
| `-` | 缩小 |
| `Enter` | 打开选中的文件 |
| 方向键 | 微调选中节点的位置，并将其固定 |

## 技术细节

<Note>
  知识图谱由显卡绘制，布局在后台计算，不会拖慢编辑。如果系统设置了减少动态效果，布局会以暂停状态开始，方向流动也不会以动画显示。如果图谱无法绘制，视图会显示 **无法加载关系图，请重试。** 和一个 **重试** 按钮。
</Note>
