Здесь перечислены пути по умолчанию к папкам конфигурации и журналов Zditor в разных операционных системах. Это пригодится, если нужно перенести настройки, собрать журналы для диагностики или быстро открыть нужную папку.

<Warning>
  Это пути по умолчанию. В Linux они зависят от переменной окружения `XDG_DATA_HOME`, если она задана.
</Warning>

## Пути по умолчанию

Zditor хранит настройки и другие данные приложения в одной папке, названной по идентификатору приложения `com.zditor.ai`, а файлы журналов записывает в отдельную папку.

| Система | Путь к конфигурации | Путь к журналам |
| :--- | :--- | :--- |
| macOS | `~/Library/Application Support/com.zditor.ai` | `~/Library/Logs/com.zditor.ai` |
| Windows | `%APPDATA%\com.zditor.ai` | `%LOCALAPPDATA%\com.zditor.ai\logs` |
| Linux | `~/.local/share/com.zditor.ai` | `~/.local/share/com.zditor.ai/logs` |

В папке конфигурации хранятся ваши настройки, конфигурация моделей агента, навыки, добавленные для всех рабочих пространств, беседы с агентом и данные сохранённых подключений, включая их пароли, ключи и токены.

Текущий журнал — `zditor.log`. Когда он разрастается, Zditor начинает новый, а старый файл переименовывает в `zditor_` с датой и временем. Такие старые файлы журналов Zditor удаляет, когда им исполняется больше 30 дней.

<Tip>
  Чтобы быстро открыть текущий журнал, нажмите значок Zditor в строке меню (macOS) или в системном трее (Windows и Linux) и выберите **Open log file**.
</Tip>

## Как быстро открыть папки

<Tabs>
<Tab title="mac/linux">
  ```bash
  # macOS config directory
  open ~/Library/Application\ Support/com.zditor.ai

  # macOS log directory
  open ~/Library/Logs/com.zditor.ai

  # Linux config directory
  xdg-open ~/.local/share/com.zditor.ai

  # Linux log directory
  xdg-open ~/.local/share/com.zditor.ai/logs
  ```
</Tab>

<Tab title="windows">
  ```powershell
  # Config directory
  explorer "$env:APPDATA\com.zditor.ai"

  # Log directory
  explorer "$env:LOCALAPPDATA\com.zditor.ai\logs"
  ```
</Tab>
</Tabs>

## Резервное копирование

1. Перед копированием папки конфигурации полностью закройте Zditor, чтобы избежать конфликтов при записи файлов. Если просто закрыть окно, Zditor может продолжать работать в фоне; выберите **Quit zditor** в меню его значка в строке меню или в трее.
2. Журналы нужны в основном для диагностики, и долговременные полные резервные копии для них обычно не требуются.
3. Делайте резервную копию папки конфигурации перед обновлением или переустановкой.
4. Не передавайте копии папки конфигурации посторонним: в ней хранятся учётные данные сохранённых подключений. Сообщая о проблеме, отправляйте файлы журналов, а не папку конфигурации.

<Tip>
  Чтобы узнать, сколько места занимают данные приложения Zditor, и очистить кэш, откройте **Settings → Personal → Storage & data** в настольном приложении.
</Tip>

## Частые вопросы

### Не удаётся найти папку

- Запустите Zditor хотя бы раз: папки создаются при первом запуске
- В Windows вставьте `%APPDATA%` или `%LOCALAPPDATA%` прямо в адресную строку Проводника
- В macOS папка `~/Library` скрыта в Finder. Нажмите в Finder `Cmd + Shift + G` и введите путь, например `~/Library/Logs/com.zditor.ai`

### Как узнать фактический путь на моём компьютере

В Linux пути зависят от `XDG_DATA_HOME`, если эта переменная задана. Сначала выведите её значение в терминале:

```bash
# Linux
echo $XDG_DATA_HOME
```

Если вывод пуст, Zditor использует `~/.local/share`. В macOS и Windows эти пути не меняются никакими переменными окружения, поэтому используйте пути из таблицы.

### Почему в Linux есть ещё папка в ~/.config?

В `~/.config/com.zditor.ai` (или в `XDG_CONFIG_HOME`, если эта переменная задана) Zditor сохраняет размер и положение окна. Всё остальное находится в `~/.local/share/com.zditor.ai`.
