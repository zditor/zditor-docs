Zditor 内置了 PDF 查看器，可以阅读和批注 PDF。你可以在页面上书写绘画，用带标题和评论的区域高亮标记某个区域，用图层把不同组的批注分开，还可以在 Markdown 笔记中引用高亮。批注保存在单独的文件中，PDF 本身始终不会被修改。

## 批注如何保存

PDF 批注永远不会写入 PDF 文件本身。Zditor 会把它们保存在同一文件夹中的一个独立 JSON 文件里，文件以该 PDF 命名：

```text
example.pdf.zditor-pdf-annotation.json
```

第一次批注某个 PDF 时，Zditor 会创建这个文件，之后的每次修改都会自动保存。文件中保存着：

- 图层，包括名称和可见性
- 笔触，包括所在页面、图层、点坐标、颜色、线宽和笔触设置
- 区域高亮，包括所在页面、图层、区域、颜色、标题、评论，以及对其缩略图的引用
- 对于智能体根据引文创建的高亮，还会保存所引用的文字

<Tip>
  由于 PDF 本身从不被修改，你的批注很容易同步、备份和纳入版本管理。
</Tip>

## 界面结构

在桌面版中，PDF 查看器分为四个区域。

### 标题栏

PDF 上方的标题栏包含：

- 左侧的 **撤销** 和 **重做**
- 右侧的 **打印**、**搜索**、**书签**、**图层** 和 **清除本页标注**

标签页较窄时，**书签**、**图层** 和 **清除本页标注** 会收进 **更多** 菜单。搜索时，搜索框会取代这些按钮的位置。

### 批注工具栏

一条圆角工具栏悬浮在页面顶部，从左到右依次是：

- **保持当前工具**
- 各种批注工具
- 六种颜色
- **线宽** 滑块
- **笔触参数**

标签页太窄、放不下全部内容时，线宽滑块和颜色会依次收进笔触参数按钮，这时该按钮会显示当前颜色，名称变为 **画笔设置**。如果空间仍然不够，工具会收进 **更多** 菜单，先收起 **激光笔**、**直线** 等不常用的工具。菜单中会显示每个工具的快捷字母。

### 缩放与页码控件

左下角有 **缩小**、缩放百分比、**放大** 和当前页码。

### 左侧边栏

**书签**、**图层** 和 **搜索** 会在页面左侧打开侧边栏，显示以下内容之一：

- PDF 的书签
- 图层，以及区域高亮列表
- 搜索结果

再次点击 **书签** 或 **图层** 即可关闭侧边栏。

## 批注工具

在批注工具栏中选择工具，或按下对应的字母键。

### 选择

快捷键：`V`。**选择** 工具用于选中和移动批注，而不是绘制。打开 PDF 时默认使用这个工具。

使用选择工具，你可以：

- 点击笔触将其选中；按住 `Shift` 点击笔触，可以把它加入选区或从选区中移除
- 拖动选中的笔触或选区内的任意位置，即可移动
- 点击区域高亮显示它的卡片；拖动它可以移动位置，拖动角上的手柄可以调整大小

点击空白处会取消选择。

### 钢笔

快捷键：`P`。钢笔用于自由绘制，包括手写笔记、圈画、箭头和任意轨迹。可以从六种颜色中选择一种，并设置 **线宽**。

**笔触参数** 决定每一笔的形态：

- **细化**：根据笔的压力改变线宽。使用鼠标时没有效果。
- **平滑**：柔化每一笔的轮廓
- **流线**：让线条稍稍滞后于笔尖，使快速书写的笔画更稳
- **起始锥度** 和 **末端锥度**：让笔画在起笔或收笔处逐渐收细成尖
- **起始端帽** 和 **末端帽**：让未收细的笔画在起点或终点呈圆头
- **重置**：恢复默认的笔触参数

<Tip>
  线宽和笔触参数只作用于新画的笔触，已有笔触会保留绘制时的设置。Zditor 会把你的选择记为绘制默认值，你也可以在 **设置 → 编辑器 → PDF 编辑器** 中设置这些默认值。
</Tip>

### 荧光笔

快捷键：`M`。荧光笔同样是自由绘制，但与钢笔有所不同：

- 它是半透明的，下面的文字仍然清晰可读
- 它像荧光记号笔一样与页面融合
- 它的线宽不随笔的压力变化

### 橡皮擦

快捷键：`E`。拖动橡皮擦，划过要删除的笔触。

- 它会整体删除路径碰到的每一条笔触，包括直线和矩形
- 它的大小取决于 **线宽** 设置
- 笔触在拖动时就会消失，松开后修改才会保存
- 它对所有可见图层中的笔触都有效

<Warning>
  橡皮擦不会删除区域高亮。请通过区域高亮的卡片、编辑框，或图层侧边栏中的批注列表删除它们。
</Warning>

### 直线与矩形

需要更规整的标记时，可以使用：

- **直线**（`L`）：从按下的位置到松开的位置画一条直线段
- **矩形**（`R`）：在两个对角之间画一个矩形边框

画完一个图形后，Zditor 会切回 **选择** 工具并选中这个新图形，方便你立即移动它。如果要连续画多个，请开启 **保持当前工具**。

### 套索

快捷键：`S`。围绕笔触画一个圈即可选中它们，只要笔触有一个点落在圈内就会被选中。之后可以使用选区工具栏或拖动选区，详见 [选择与批量操作](#选择与批量操作)。

<Tip>
  套索只能选择笔触，不能选择区域高亮或 PDF 中的文字。
</Tip>

### 激光笔

快捷键：`K`。激光笔是一个临时指示工具，适合演示、教学或共享屏幕时使用：

- 一个当前颜色的圆点会取代光标，并留下在一秒内消失的拖尾
- 不会向批注数据中保存任何内容
- 切换到其他工具会立即清除拖尾

### 浏览

快捷键：`H`。拖动即可向任意方向滚动页面，而不是进行批注。放大页面后尤其好用。

### 保持当前工具

快捷键：`Q`。画完直线、矩形或区域高亮后，Zditor 通常会切回 **选择** 工具。开启 **保持当前工具** 后，当前工具会一直保持选中。钢笔、荧光笔、橡皮擦、套索、激光笔和浏览工具则始终保持选中。

### 键盘快捷键

| 按键 | 操作 |
| --- | --- |
| `V` | 选择 |
| `H` | 浏览 |
| `P` | 钢笔 |
| `M` | 荧光笔 |
| `A` | 区域高亮 |
| `E` | 橡皮擦 |
| `L` | 直线 |
| `R` | 矩形 |
| `S` | 套索 |
| `K` | 激光笔 |
| `Q` | 开启或关闭 **保持当前工具** |
| `Cmd/Ctrl + Z` | 撤销 |
| `Shift + Cmd/Ctrl + Z` | 重做（在 Windows 和 Linux 上也可以用 `Ctrl + Y`） |
| `Delete` 或 `Backspace` | 删除选中的笔触 |
| `Cmd/Ctrl + F` | 搜索 PDF |

工具字母键以及撤销、重做按键，需要先点击 PDF 查看器才能使用；在输入框中输入文字时，它们不会生效。

## 区域高亮

区域高亮是 PDF 查看器中最结构化的批注类型：页面上的一个矩形，带有颜色、标题、评论和该区域的缩略图。

### 创建区域高亮

<Steps>
  <Step title="切换到区域高亮工具">
    在批注工具栏中选择 **区域高亮**，或按 `A`。
  </Step>

  <Step title="在 PDF 上拖出一个矩形">
    在要批注的区域上拖动。
  </Step>

  <Step title="填写标题和评论">
    松开指针后，区域旁会打开一个小编辑框。从五种颜色中选择一种（默认为黄色），再填写可选的标题和评论。在标题中按 `Enter` 会跳到评论。
  </Step>

  <Step title="确认保存">
    点击 **确认** 或按 `Cmd/Ctrl + Enter`，把高亮保存到当前图层。点击 **取消** 或按 `Esc` 则放弃。
  </Step>
</Steps>

确认后，除非开启了 **保持当前工具**，Zditor 会切回 **选择** 工具并选中这条新高亮。带有评论的高亮会在右上角显示一个小圆点。

### 编辑区域高亮

#### 使用选择工具

点击高亮会显示它的卡片，其中有标题和评论。点击 **编辑批注**（铅笔图标）或卡片上的文字可以打开编辑框，点击 **删除批注**（垃圾桶图标）可以删除这条高亮。同时会打开图层侧边栏，并在其中的批注列表里标出这条高亮。

#### 使用区域高亮工具

点击已有的高亮，会直接打开它的编辑框。

#### 在编辑框中

- 选择新颜色会立即生效
- 修改标题或评论后，点击 **保存** 或按 `Cmd/Ctrl + Enter`
- 点击 **关闭** 或按 `Esc` 会直接离开，不保存标题和评论
- 垃圾桶图标会删除这条高亮

### 移动和调整区域高亮

使用选择工具时，拖动高亮即可移动它。选中的高亮四个角上各有一个手柄，拖动手柄即可调整大小。

编辑框打开时，高亮框周围会出现 8 个手柄：

- 左上、上、右上
- 左、右
- 左下、下、右下

这意味着高亮框支持精确的尺寸修正，而不是只能删除重画。

### 删除区域高亮

区域高亮可以通过以下方式删除：

- 点击卡片上的 **删除批注**
- 点击编辑框中的垃圾桶图标
- 在图层侧边栏的批注列表中，点击它旁边的 **删除批注**
- 在使用区域高亮工具时，右键点击它

撤销可以恢复被删除的高亮。

### 高亮缩略图

保存区域高亮时，Zditor 会截取该区域的图像，并保存到 **设置 → 编辑器 → PDF 编辑器 → 高亮缩略图** 中选定的位置。**设置 → 集成 → 图床与上传** 中也有同样的选项。存储位置可以是本地文件夹，也可以是你设置好的 S3 兼容存储、WebDAV 或 GitHub 存储。

如果某条高亮缺少缩略图，请在图层侧边栏的批注列表中把鼠标悬停在它上面，点击 **重新生成缺失缩略图**。

## 在 Markdown 中引用 PDF 卡片

区域高亮不只能在 PDF 查看器中使用。你可以把它们作为 PDF 卡片插入 Markdown 文档，把阅读批注整理成可复用的笔记。

在 Markdown 文档中输入 `@` 后，Zditor 会打开一个引用列表，其中包括：

- 工作区中的 Markdown 文件
- 你批注过的 PDF

选择一个带有区域高亮的 PDF 后，Zditor 会打开二级菜单，其中有两类条目：

- **PDF 本身**：插入指向整个 PDF 的链接
- **它的每一条区域高亮**：插入对应区域的 PDF 卡片

没有区域高亮的 PDF 会直接以链接形式插入。高亮按标题列出；没有标题的，则按页码和评论列出。在 `@` 后继续输入，可以搜索文件名、高亮标题、评论和页码（例如 `page 3`）。

PDF 卡片会显示高亮的标题（如果有）和 PDF 的文件名。

### 典型流程

<Steps>
  <Step title="先在 PDF 中做好区域高亮">
    给重要区域添加区域高亮，最好写上标题或评论，以便之后在列表中容易辨认。
  </Step>

  <Step title="回到 Markdown 文档输入 @">
    这会打开工作区的引用列表。
  </Step>

  <Step title="选择目标 PDF">
    在一级列表中选中该 PDF，打开它的二级菜单。
  </Step>

  <Step title="选择整份 PDF 或某条高亮">
    选择 PDF 本身，插入指向整个文件的链接；选择某条高亮，插入指向该区域的卡片。
  </Step>

  <Step title="插入到 Markdown 中">
    Zditor 会把链接或 PDF 卡片插入当前的 Markdown 文档。
  </Step>
</Steps>

### 点击 Markdown 中的 PDF 卡片

点击 PDF 卡片会选中它并打开工具栏。这个工具栏把你的写作和原始 PDF 连接起来：

- **询问 AI**：在智能体中打开这张卡片，并附上高亮的页码、标题和评论
- **PDF 的文件名**：打开 PDF，滚动到这条高亮并选中它
- **使用系统默认应用打开**、**打开所在文件夹** 和 **复制文件路径**：对 PDF 文件执行相应操作（桌面版）
- 高亮所在的页码
- **编辑标题**：修改这张卡片在笔记中显示的标题
- **刷新**：重新加载高亮的详细信息和缩略图
- **更多选项**：显示高亮的页码、标题、评论和缩略图。点击缩略图可以查看原尺寸图片。

这意味着 PDF 卡片不只是一个静态引用。你可以在 Markdown 笔记里根据整理好的内容写作，需要核对原文上下文时，随时跳回 PDF 原文。

<Tip>
  这种工作流特别适合论文阅读和研究笔记。Markdown 这边保留可复用的卡片，PDF 那边保留原始的批注区域。
</Tip>

这个用法适合：

- 把论文中的高亮整理成笔记
- 在 Markdown 文档里保留 PDF 缩略图和评论上下文
- 一边阅读 PDF，一边沉淀结构化研究笔记

## 图层管理

图层是 PDF 批注管理的核心功能之一。点击标题栏中的 **图层**，即可在侧边栏中打开它们。每个 PDF 一开始都有一个 **默认图层**。

### 图层支持的操作

图层侧边栏支持：

- 点击 **新建图层**（加号）创建图层，新图层会成为当前图层
- 点击某个图层，将其设为当前图层。点击隐藏的图层也会让它重新显示。
- 双击图层名称进行重命名。按 `Enter` 确认，按 `Esc` 取消。
- 把鼠标悬停在图层上，点击眼睛图标即可隐藏或显示它
- 把鼠标悬停在图层上，点击垃圾桶图标即可删除它。最后剩下的一个图层无法删除。

<Warning>
  删除图层时，该图层中的笔触和区域高亮也会一起被删除。在 PDF 仍处于打开状态时，可以通过撤销恢复它们。
</Warning>

图层下方的 **批注** 列表会显示所有区域高亮及其页码、图层、标题和评论。点击某一条即可跳转到它所在的页面。

### 当前图层的意义

当前图层决定：

- 新笔触创建在哪个图层
- 新区域高亮创建在哪个图层
- 粘贴的笔触放到哪个图层
- **清除本页标注** 删除哪些笔触

橡皮擦、套索和选择工具对所有可见图层都有效。如果隐藏了当前图层，第一个可见图层会成为当前图层。

### 图层显隐

每个图层都可以单独隐藏或显示。图层被隐藏时：

- 它的笔触和区域高亮会从页面上消失
- 打印时不会包含它们
- 数据仍然保留，批注列表中仍会显示该图层的高亮

这很适合：

- 按主题拆分批注
- 区分个人笔记和团队批注
- 临时聚焦某一类标记

## 选择与批量操作

用选择工具或套索选中笔触后，Zditor 会在选区左侧显示一条竖向工具栏。

可执行的操作包括：

- **删除**
- **复制**
- **剪切**
- **粘贴**：复制或剪切后才会出现。它会把复制的笔触粘贴到当前页的当前图层上，并稍作偏移。
- **移至图层**：PDF 有多个图层时才会出现

你也可以在选区内拖动，把选中的笔触作为一个整体移动。

复制和剪切的笔触只能在同一个 PDF 内粘贴，不会使用系统剪贴板。

### 删除快捷键

使用选择工具或套索时，如果当前有选中的笔触，可以按：

- `Delete`
- `Backspace`

将它们删除。

## 撤销、重做与清除

### 撤销与重做

**撤销** 和 **重做** 位于标题栏中。它们会逐步回退或重做对该 PDF 批注的每一次修改，涵盖所有页面和图层：

- 绘制、擦除、移动、粘贴和删除笔触，以及把笔触移到其他图层
- 创建、编辑、移动、调整大小和删除区域高亮
- 新建、重命名、隐藏、显示和删除图层
- **清除本页标注**
- PDF 打开期间智能体所做的修改

历史记录在 PDF 保持打开期间有效。重新打开 PDF 后，历史记录会重新开始。

### 清除当前页

**清除本页标注**（标题栏中的垃圾桶图标；标签页较窄时位于 **更多** 中）会删除以下范围内的所有笔触：

- 当前页，即左下角页码所显示的页面
- 当前图层

<Warning>
  **清除本页标注** 只作用于笔触。区域高亮和其他图层上的笔触都会保留。撤销可以恢复被清除的笔触。
</Warning>

## 书签、搜索与导航

### PDF 书签

如果 PDF 自带目录或书签，点击标题栏中的 **书签** 即可在侧边栏中显示它们。

你可以：

- 展开和折叠多级书签
- 点击书签跳转到对应页面，页码显示在书签标题旁边
- 在侧边栏中看到当前位置：当前页对应的书签会高亮显示

没有目录的 PDF 会显示 **还没有书签**。

### 搜索正文和批注评论

点击标题栏中的 **搜索** 或按 `Cmd/Ctrl + F`。搜索框会取代标题栏中的按钮，搜索结果在侧边栏中打开。

PDF 搜索不只会查正文，也会查区域高亮中的评论内容。

搜索行为特点：

- 停止输入片刻后结果就会更新，查看器会跳到第一个结果
- 搜索不区分大小写
- 按 `Enter` 或点击向下箭头按钮，跳到下一个结果
- 按 `Shift + Enter` 或点击向上箭头按钮，跳到上一个结果
- 按 `Esc` 或点击关闭按钮，关闭搜索及其结果

### 搜索结果显示

搜索命中后：

- 页面上会标出匹配的区域
- 搜索框会显示当前是第几个结果，例如 `2/7`
- 侧边栏会列出所有结果，点击即可跳转

结果分为两类：

- **正文匹配**按页分组：每个有匹配的页面算作一个结果
- **高亮评论匹配**每条高亮列为一项，显示高亮的颜色、页码和评论

## 缩放与阅读

PDF 查看器支持：

- 左下角的 **放大** 和 **缩小**
- 点击缩放百分比，让页面适合查看器的宽度
- 在 Mac 触控板上双指捏合
- 按住 `Ctrl` 滚动
- 缩放范围为 40% 到 400%
- 点击页码，输入页数并按 `Enter` 跳转

### 打印

标题栏中的 **打印** 会打印 PDF 的所有页面，以及可见图层上的批注。隐藏的图层不会被打印。

### 深色模式

Zditor 使用深色外观时，PDF 页面会反色显示，变成深色页面上的浅色文字，阅读更舒适。

<Tip>
  反色只作用于 PDF 页面本身。批注绘制在页面上方单独的一层中，会保持原有的颜色。
</Tip>

## 与智能体协作

内置智能体可以处理工作区中的任何 PDF，无论它是否已在标签页中打开。你可以让它：

- 逐页阅读 PDF，以及它的目录和你已有的高亮
- 查找某段内容
- 查看某一页或页面的一部分，例如图、表格或扫描页
- 高亮一段内容并附上标题和评论，或者给它加下划线、删除线，或在它周围画框
- 自由绘制，编辑或删除高亮，以及删除笔触

需要了解的是：

- 除非你要求智能体使用你的某个图层，否则新批注会放在名为 **Agent** 的图层上，你可以一步隐藏或删除它的全部成果
- 如果 PDF 已打开，智能体的修改会立即显示，**撤销** 会一次撤回一批修改
- 智能体每创建一条高亮，都会得到一个现成的 PDF 卡片链接，可以用它在 Markdown 笔记中引用这条高亮
- 智能体所做高亮的缩略图会在 PDF 打开时生成。对于 PDF 关闭期间创建的高亮，请打开 PDF，在批注列表中使用 **重新生成缺失缩略图**。
- 阅读、搜索和查看页面无需批准。添加、修改或删除批注则遵循智能体的 **权限模式**。

要为智能体连接 AI 服务，请打开 **设置 → AI → 智能体**。

## 性能说明

页面列表只渲染视口附近的页面：

- 可见页面及其前后各一页会完整渲染
- 其他页面用占位块代替，以保持滚动高度

这样可以降低渲染开销，在长篇 PDF、较高缩放比例和高分辨率屏幕上尤为明显。

在一个 PDF 中第一次搜索时，需要读取每一页的文字，因此长文档可能要稍等片刻。之后在同一 PDF 中搜索会复用这些文字。

## 常见问题

<AccordionGroup>
  <Accordion title="批注数据保存在哪里？" icon="question">
    保存在 PDF 旁边的一个独立文件中：`paper.pdf` 的批注保存在 `paper.pdf.zditor-pdf-annotation.json` 中。Zditor 从不把批注写入 PDF 本身。
  </Accordion>

  <Accordion title="为什么看不到某些批注？" icon="question">
    先在图层侧边栏中检查它们所在的图层是否被隐藏。隐藏的图层仍保留数据，其区域高亮也仍会出现在批注列表中。另外请注意，当前图层只决定新批注放在哪里，其他图层的数据依然存在。
  </Accordion>

  <Accordion title="为什么搜索不到我的手写批注？" icon="question">
    搜索范围是 PDF 的文字和区域高亮的评论。它不会搜索手写内容或高亮标题，也不会进行 OCR，因此没有文字层的扫描版 PDF 无法搜索。
  </Accordion>

  <Accordion title="缩略图没有生成怎么办？" icon="question">
    打开 PDF 和图层侧边栏，在批注列表中把鼠标悬停在该高亮上，点击 **重新生成缺失缩略图**。如果仍然失败，请检查 **设置 → 编辑器 → PDF 编辑器 → 高亮缩略图** 中的存储位置。
  </Accordion>

  <Accordion title="删除图层会发生什么？" icon="question">
    删除图层会同时删除其中的笔触和区域高亮。在 PDF 仍处于打开状态时，可以通过撤销恢复它们。如果想保留部分笔触，请先用 **移至图层** 把它们移到其他图层；区域高亮无法在图层之间移动。
  </Accordion>

  <Accordion title="关闭 PDF 后还能撤销修改吗？" icon="question">
    不能。撤销历史只在 PDF 打开期间有效。如果之后想撤回智能体的修改，请隐藏或删除它的 **Agent** 图层。
  </Accordion>

  <Accordion title="区域高亮和荧光笔有什么区别？" icon="question">
    荧光笔画出的是自由手绘的半透明笔触；区域高亮则是一个结构化的矩形，带有标题、评论、颜色和缩略图。你可以移动它、调整它的大小，在搜索中通过评论找到它，还可以在 Markdown 中把它作为 PDF 卡片引用。
  </Accordion>
</AccordionGroup>
